# Intent: SymSync — macOS 软链接同步工具

- 状态：已接受
- 作者：jiaqiao
- 日期：2026-09-02

## 问题

在多个目录之间共享同一份文件（如 AI 工具的 skills、配置、脚本）时，手动创建软链接繁琐、易漏、易重复。需要一个 macOS 图形工具，把"源目录 → 多个目标目录"的软链接关系保存下来，一键重复执行，且重复执行不会产生重复或破坏已有内容。

## 期望结果

- 用户选择或输入一个源目录和一个或多个目标目录，工具在每个目标目录里为源目录的子项创建软链接。
- 支持整目录（源的每个直接子项各建一链）或只同步指定的子项。
- 重复执行同一条记录时是增量的：已存在且指向正确的链接跳过，目标里已有的同名真实文件或指向别处的链接不覆盖，只报告。
- 源已删除、目标里残留的坏链接被报告，并可由用户确认后清理。
- 同步记录持久化，下次打开直接选择执行。
- 可上架 Mac App Store。

## 影响的用户与系统

- 用户：作者本人，单人开发、单人使用；上架后为普通 macOS 用户。
- 系统：用户文件系统；macOS App Sandbox；Mac App Store 审核。

## 约束

- 单人项目：产品负责人、工程师、评审人为同一人。playbook 的 artifact 链和阶段门禁保留，跨角色审批改为自评 + AI 评审。
- 必须开启 App Sandbox，目录访问通过 security-scoped bookmark 持久化。
- 技术栈：Swift 6.3、SwiftUI、Xcode 26.6，部署目标 macOS 15。
- 永不静默覆盖或删除用户数据。
- 本项目同时作为实践 AI-native SDLC playbook 的载体，每个阶段产出提交到 git。

## 不在范围内

- 菜单栏常驻、后台监听源目录变化自动同步。
- 双向同步、文件复制、硬链接。
- 相对路径软链接。

## 待解决问题

- 沙盒内在已授权目录创建指向未授权路径的软链接是否被允许，需在 Xcode 工程建好后第一时间真机验证。
