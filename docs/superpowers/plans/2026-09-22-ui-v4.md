## 全局约束（每个任务都适用）

- 七个中性灰：`#ffffff #000000 #f2f2f2 #e2e2e2 #c8c8c8 #9a9a9a #5a5a5a`，只在 `src/tokens.css` 出现；零阴影零渐变零 rgba。
- 圆角只有 `0 / 2px / 32px / 50%`；形状语义：2px 矩形＝动作、胶囊＝片与开关、圆＝只读状态、直角＝容器。有框的都能点；标签无框。
- 字号只有 28 / 20 / 15 / 13 / 12；汉字零字距零大写，Condensed 大写 + 字距只给纯拉丁（页签 `SKILLS` `MCP`、agent 列头）。
- 计数等宽 tabular，不零填充、不写别处已有的分母。
- 线三档：表头底 2px ink（每页至多一处）、分组 1px ink、行 1px hairline；顶栏 / 二级页头底 hairline。
- 实心黑只给显示窗（提示条、待处理窗、错误横幅、行内待重启）、路径铭牌、主动作键、点亮的键。
- 动效：80–120ms `cubic-bezier(.2,.8,.2,1)`；转盘 1.2s 线性、停转 600ms 减速 + 2° 回弹；刚点亮 120ms 反色；按下 1px 行程；`prefers-reduced-motion` 下关掉。**不退化成默认 transition。**
- 新图形都有 `title` 与 `aria-label`；读屏文本不减。
- 验证：改 core → `make test-core && make lint`；改 src / src-tauri → `make build-web && make test-web && cargo check --workspace`；lint-ui 在 `make lint` 里。提交前 `make test` 全绿。**测试失败改代码，不改测试**——但钉住旧设计（胶囊按钮、带框标签、旧文案）的断言属于被新规范推翻的行为，按新规范重写，并在提交说明里写明。
- 用户看得到的文字说「原件」不说「本体」、说「同名」不说「撞名」（DESIGN.md 2026-09-22 第 9 轮）；lint-ui 的旧词表加这两个词。代码标识符不动。
- `tests/issue-key-contract.test.ts` 与 `crates/core/src/store.rs` 的 key 格式是跨语言契约，不许动。

3. 组件（照 `States.dc.html` / `Marks.dc.html` 与 KIT-v3/v4 写法）：

   - `Checkbox` 12px（未选 / 已选 / 不可选 / 半选）。
   - `Chip`（胶囊 28，筛选片；计数 mono）；`ModelChip`（24，可移除，显示友好名、title 放 id）。
   - `Tag`（无框：`strong` ink 600 / `weak` ink-faint 400），**替换并删除 `TagSquare`**。
   - `StateDot`：10px 家族——`linked` 实心 / `missing` 1.5 环 / `own` 环 + 4px 芯 / `none` 8px 短横 / 异常 `broken` 虚线环（4 段，段间 1.5）/ `readOnly` 斜杠环 / `blocked` 环内短横 / `wholeLinked` 环内向右箭头；另有 16px 版本给待处理页与待处理窗。
   - `Rotor`：≤ 20px 盘面 + 偏心点（r1.9）；64px 加轴毂；`spinning` 时 1.2s 线性，停止时 600ms 减速 + 2° 回弹；reduced-motion 下每 400ms 跳 45°。
   - `Toast`（黑显示窗）：props `kind`（success / cannot / partial）、`verb`（必填，失败态用否定动词）、`agents?: {id,name}[]`（白色图标）、`names?: string[]`（>2 个时显示 `+N`）、`reason?`（做不成 / 部分失败的一句）、`stats?`（等宽副行）、`action?`（白描边紧凑键）、`onClose`。左侧 40px 指示窗（✓ / ⊘ / !）。**位置由调用方定（右沿对齐面板右沿）**，组件只负责形制。
   - `PendingWindow`（左下内容宽黑窗）：`mark`（异常记号种类）、`name`、`index/total`、`onJump`、`onNext`。
   - `ErrorBanner`（黑）、`BlackNotice`（行内待重启 / 托盘：`!` + 一句 + 白描边键 + 可选文字链；替代 `RowNotice`）。

   - `Confirm`：无外框白板 460，`#f2f2f2` 实色遮罩；`title`、`children`（示意图 / 正文插槽）、`nameplate?: {path, meta}`（黑底等宽白字铭牌）、`safetyNote?`、`confirmLabel`、`onCancel`（取消是文字链）、`onConfirm`（主动作反色）。
   - `SubPage` 头（84 = 28 + 56，页面名 28/700 不大写，底 hairline）。
   - `Cap`：把文本切成拉丁 / 汉字 run，只给拉丁 run 套 Condensed 大写 + 字距（页签、agent 列头用）。
   - `AgentMark`：列头三层（图标 / Condensed 大写名 / 等宽计数），Claude Code 星形描边 1.2、小 1px。
4. `Dot` 扩展：`cellState.ts` / `mcpCellState.ts` 的 `viewOf` 输出新的 `dot`（区分 broken / readOnly / blocked(foreign|duplicate) / wholeLinked），测试跟进。
5. `tests/ui.test.ts`：按新组件重写断言（旧的「ghost pill」「inverse 按钮当开关」「ss-tag 带框」断言按新规范改写）。

**验收**：`make build-web && make test-web && make lint` 全绿；导出的组件与 `States.dc.html` 并排截图比对（主会话看）。页面可以暂时编译不过吗？**不可以**——T0 期间页面仍用旧 props 的地方，要么保留兼容别名（在 index.ts 标注 `@deprecated`，T1 删），要么顺手改掉调用点的 props 名；保证每个提交 `make build-web` 通过。
