# Sophia 组件规格

每个组件的精确规格：尺寸、状态、token、行为细节。**什么时候用哪个组件**（一件事 / 何时用 / 不要用在 / 和谁容易混）见 `docs/DESIGN.md`「组件使用指南」；token 的值在 `docs/DESIGN.md` 的 front-matter，代码里只从 `src/tokens.css` 取；规则为什么是这样见 `docs/DESIGN-decisions.md`。这份文件也是 `/design-sync` 把 `src/ui` 同步到 Claude Design 时的输入。

组件名是 `src/ui` 的导出名。数字一律是 1x 像素；「紧凑」指 24 高的一档。改组件先改这里，再改代码。

## 通用

### 尺寸、焦点与动效

| 项 | 取值 |
|---|---|
| 可点元素高度 | `--control-h: 28px` / `--control-h-compact: 24px` / 页面级 32 / 胶囊 26（`--control-h-chip`），**一律偶数**——奇数高会让端帽只有 75% 覆盖，同一圈边一半实一半虚，读起来就是「锯齿」 |
| 命中区下限 | `--hit-min: 24px` |
| 焦点 | 只认 `:focus-visible`：1px `ink` 外框、偏移 2px；墨面上转 `face`。**不用橙**（橙只表示在生效），**不要系统默认的蓝色焦点环** |
| 动效 | 过渡、按下与松开、滑块位移、减少动效见下「控件有重量 › 重量与惯性」；值见 `DESIGN.md` front-matter `motion` |
| 层（z-index） | 只引用 `src/tokens.css` 里从低到高的层级 token（滚动渐隐 < 推入页 < 小浮层 < 提示条 < 确认框 < 提示框），组件不写字面量 |
| 数字 | `font-variant-numeric: tabular-nums`，计数跳动时不抖 |
| 字形渲染 | `-webkit-font-smoothing: antialiased`，关掉 macOS 次像素渲染的彩边 |

### 控件有重量：抬起的东西三态

抬起的东西三态：**静止＝离机面一点点，悬停＝手靠近（影子略重、不位移），按下＝贴近机面（影子收紧、键面下沉 0.5px 并微缩）**。按压变形统一为 `translateY(0.5px) scale(.985)`（`--press-transform`）。

| 控件 | 静止 | 悬停 | 按下 | 焦点 |
|---|---|---|---|---|
| 主动作键（墨键） | `ink` 底、`face` 字、`raise-ink` | 键面内缩 1px 的 `ink-mute` 内描边（墨已最深，影子不变） | `raise-ink-pressed` + 按压变形 | 外 2px 处 1px `ink` 环 |
| 默认键 | `paper` 面、`raise`（不画描边） | `raise-hover` | `surface` 面 + `raise-pressed` + 按压变形 | 同上 |
| 页签 | 未选中：槽里的字；选中：`paper` 滑块 + `raise` | 未选中字转 `ink`；指针在滑块上 `raise-hover` | 按下即切：滑块弹簧滑到按下的页签，按住期间 `raise-pressed` + 按压变形 | 同上 |
| 开关 | 见「开关 Switch」：滑块 `raise` | 滑块 `raise-hover` | 按住：滑块 `raise-pressed` + 按压变形；可拖 | 同上 |
| 浅键（离开 Sophia） | 平贴的 `surface` 浅面、`ink-mute` 字（不抬起） | 底转 `paper`、`raise` 抬起、字转 `ink` | `raise-pressed` + 按压变形 | 同上 |
| 勾选框 | 14 方、`paper` 白面 + 1px `ink-faint` 内环（平贴） | `raise-hover` 抬起迎手（抬起的唯一例外：只在手靠近时） | 勾上：`ink` 底、`face` 对勾；按下 `press-transform` | 同上 |
| 不可用 | **平贴**：1px 实线 `hairline`、`ink-faint` 字、透明底、**无投影**、按下不动（D20：不用虚线——虚线在本产品是「目标不在」） | 不变 | 不动（按下即出原因，见「提示框 Tooltip」） | 同上 |

- **紧凑开关**（尺寸见「开关 Switch」）给行内的规则状态——来源管理页每行的「以后新出现的自动加到」。它是一条规则的状态，不是本页主角；标准开关只给能力的总开关（Codex 页「第三方模型」、托盘）。
- **开关保持一眼认得出是开关的形态**：横向滑槽 + 滑块，位置＝状态（⑥）；物性做在重量、拖动与停靠上，不做在纹理上。

**重量与惯性（动效）**：
- **会移动的实物用阻尼弹簧**：页签滑块、开关滑块的位移用 `--spring-slide`——阻尼比 0.8 的弹簧（过冲 1.5%，≤ 位移的 3%；肉眼是「停稳」不是「弹」），用 CSS `linear()` 近似。**越重越慢**：页签滑块（宽）`--dur-slide-tab` 260ms，开关滑块（小）`--dur-slide-knob` 200ms——同一条曲线、不同时长。
- **按下有重量**：按下 `--dur-press` 70ms 内（`--ease-mech`）影子收成 `raise-pressed`、键面按压变形；松开 `--dur-release` 180ms 用同一条 `--spring-slide` 回到静止（指针还在键上时回到悬停态）。按压只有 0.5px 与 1.5%，回位的过冲（1.5% × 0.5px）肉眼不可见，读作「弹回来」而不是「晃」。墨键同理。
- **颜色、透明度、底色不用弹簧**：它们不是有质量的东西，仍是 `--motion-fast` 120ms `--ease-mech`；悬停时影子变重也用它。刚点亮反色 120ms 不变。不要 300ms 淡入淡出。
- **拖**：开关滑块可按住拖动（见「开关 Switch」）；页签滑块不拖——两个选项，点就够（⑩）。
- **`prefers-reduced-motion`**：全部即时，无位移动画、无按压变形；影子与颜色的状态变化照常（即时），拖动时滑块仍跟手（那是直接操作，不是动画），松手即时落位。

## 键

### 按钮 `Button`

控件矩形（`control` 7），`button` 档文字（Barlow 13 / 600、字距 0、不大写）。三档高度：常规 28、左右 12；紧凑 24、左右 10（行内、提示条、灰面板、抽屉里）；页面级 32、左右 16（确认框、页面级提交、`选择文件夹…`）。**键分三档，外加禁用**（D14；2026-09-25 外链并入浅键）：

| 变体 | 形 | 给谁 |
|---|---|---|
| 主键 `variant="primary"`（墨键） | `ink` 底、`face` 字、抬起 `raise-ink` | 一个面里**至多一个**：确认框的主动作、添加来源页的 `添加 N 个来源`、表单的 `保存` |
| 默认键 `Button` | `paper` 面、抬起 `raise`（边由投影的 1px 环给，不画描边） | **其余一切能点的字**：`重启生效` `启动 Codex` `+ 来源` `+ 网关` `管理来源` `再试一次` `清除` `拆开` `撤销` `只留这份` `清除筛选` `恢复` `检查更新`；**`取消` 与 `稍后` 也是默认键**（确认框、选择行、网关表单、行内待办条；macOS 惯例：取消是一颗正经的键，不是一行字）。行内、提示条、纸窗、抽屉里用紧凑 24 |
| 浅键 `variant="quiet"` | **静止是平贴在机面上的一小块键面**：`surface` 底、无边无投影、13 `ink-mute` 字、高 24、左右 8、`control` 7，**末尾一律 10px `↗`**（1.4 描边、左间距 3）；手靠近底转 `paper`、抬起 `raise`、字转 `ink`；按下 `raise-pressed` + 按压变形 | **只给离开 Sophia 的动作**（2026-09-25 产品负责人：「跳转到外部的确实可以用不同的按钮样式，并统一加上 ↗」）：`打开 ↗`（访达）、`在访达中显示 ↗`、`在访达中显示备份 ↗`、`打开目录 ↗`、`去发布页 ↗`。形与 ↗ 一起说「这一下会把你带到 Sophia 外面」，应用内的键没有这一档。**放在 `surface` 底上时**（灰面板）键面改用 `paper`、仍然平贴——同色的浅面看不出是键（⑧）；抽屉不垫底色（2026-09-25），抽屉里照常 |
| 禁用 | **平贴**：1px 实线 `hairline`、`ink-faint` 字、透明底、**无投影、按下不动**（D20） | **必须同时说明原因**（`disabledReason`，类型上强制），按下即出原因 |

**三档靠材质分开**（③）：墨 / 抬起的纸 / 平贴的浅面，一眼读得出哪个是主动作；三档各自的意思见 `DESIGN.md`「组件使用指南 › 键」。**能点的一律有键面**（⑧，2026-09-25 产品负责人定稿「字和键分开」）：浅键静止时也是一小块键面，不再是一行灰字——界面上没有「看起来是字、其实能点」的东西；手靠近才抬起，按下有按压（⑪⑰）。

**全应用没有下划线**（⑥：下划线与手形光标是网页超链接的语言，mac 应用里「在访达中显示」从不画线；① `↗` 已经说了「会离开 Sophia」，下划线把同一件事再说一遍）。离开 Sophia 只由末尾的 `↗` 说，一个意思一个记号。

**抬起＝能按，平贴＝按不下**（⑧，D20）：键离不离开机面，本身就说明能不能按——禁用键同形，但平贴在机面上：实线 `hairline` 边、没有投影、按下不动（按不下的东西不离开机面）。不用虚线：虚线在本产品已经是「目标不在」（链接失效的虚线环、还没有目录的虚线列头、会建出来的虚线文件夹），按钮再用它就是一形两义（⑤）。不可用也不只靠变浅一档（那会读成「次级」）。浅键与禁用键不撞：浅键（只给离开 Sophia）是实心的浅面、带 ↗、没有边，禁用键是透明底加一圈实线 `hairline`。四态见「控件有重量」。

**同一行里的控件同高。** 页面头是 28 的一行：输入框、键、图标按钮全是 28（页签滑槽连槽 34）。表格行、提示条、灰面板里是 24 的一行：键 24。胶囊（筛选片、模型片）一律 26。胶囊片和矩形键并排时靠形状区分，不靠高度差。

**没有第四种键。** 线上画布一度有一档更浅描边的「次级按钮」，评审指出它读起来像禁用态；禁用态本身就是一圈浅框、平贴，所以不能再有一档浅描边键。浅键是实心浅面、没有框，所以不撞。

**按钮里的专名不靠空格断词**：`删通用仓库的`、`删 WeiboAP 的`（中西文之间一个普通空格是排版惯例，汉字之间不加）。按钮是 `inline-flex` 时，专名的 `<span>` 两侧空格写 `&nbsp;`，否则会被吃掉。

**按钮上只写动词，不写宾语。** 宾语是它所在的那一页或那一行：Codex 页上写 `重启生效`，确认框里写 `重启`。宾语只在按钮离开了它的对象、或单一个动词说不清去哪时才回来——`启动 Codex`、`卸下后台服务`、`+ 来源`、`+ 网关`。

**能画出来的动作不写字**，见「图标 icons.tsx」的词表。

**忙碌不是键的状态**：由包在键外面的 `BusySlot` 负责，键原位换成刻度 + 一句「正在…」（见「忙碌 BusySlot + Spinner」）。

### 添加键 `AddButton`

默认键 + `+` 图标 + 名词：`+ 来源` `+ 网关`。`+` 用图标词表里的 `IconPlus`，12px、1.4 描边，与名词间距 6（2026-09-25 梳理：不再另画一枚）。它是独立的创建动作，不是次级——不用灰色文字链，也不用光秃秃的图标按钮。**提交**一次添加（`添加 6 个` `保存`）是主键，不是它。侧栏的 `+ 项目` 不是添加键，是项目列表的最后一行（见 `DESIGN.md`「产品裁决 › 壳」）。

### 图标键 `IconButton`

16px 图形、**1.4 描边**、**28×28** 命中区（与按钮同高）、无边无底，图形 `ink-mute`；悬停 `surface` 底（`control` 7）、图形转 `ink`。它不是键，不抬起、按下不动——**图标按钮是「工具」，键是「动作」**。放在灰面板上时悬停底退到 `hairline`（`surface` 上看不见 `surface`）。不可用：图形 `ctl-edge`、没有悬停底，按下即出原因。**必须带提示框文字**（同时是 `aria-label`）。侧栏 `设置` 项里的齿轮是同一个图形，但那一项是导航项、不是图标按钮。

## 提示与反馈

反馈的形态、锚点、停留时长是一套总规则，只在 `DESIGN.md`「Patterns › 反馈」；这里是各组件自己的长相与行为。

### 提示框 `Tooltip`

原生 `title` 是系统灰底小框、约 1 秒延迟、位置不受控、无法排版——**不再作为唯一说明**，只作 aria 兜底。提示框是组件：

- **材质**：`ink` 底（全应用唯一的墨色浮窗）、无边，`face` 字 12/400，重点词 600，次字 `ctl-border`；`control` 7 圆角；浮层投影 `float`；无箭头；内边距 6 8；最大宽 240，超出换行。
- **内容**：表格格子只一行 = **动词**：`加到 Claude Code` / `从 Claude Code 移除`——agent 由列头说明、能点由悬停光晕表示。**快捷键只在键盘焦点唤起提示框时写**（`加到 Claude Code · 空格`）：鼠标悬停时手就在鼠标上，`空格` 对他没有意义（产品负责人）；用方向键走到这一格的人才需要它。表格外元素同理。表格外元素：一行「是什么」+ 可选一行「按下会怎样」+ 可选快捷键（12 `ctl-border`——墨面上的次字，右对齐）。例：禁用键 `Claude Code · User` / `已选的都定义在这里`；待处理记号 `同名：有两份`。
- **位置**（② 就近）：**锚点是触发它的控件，间距 ≤ 16px**。**列表行（模型勾选列表、添加页列表、下拉里的行）的提示框放在该行同一行的右侧空白处**（行尾对齐、不越出列表框），不放到上一行——放到上一行会被读成上一行的信息；表格格子仍按「正上方 6」。只保护触发控件与它所在的行：列头标签被暂时盖住可以接受（用户正停在这一行上，此刻最不需要列头）。格子：正上方 6px、水平居中于格子；**允许暂时盖住上一行的邻格，只保护悬停的那一格和它所在的那一行**；首行放不下时放格子正下方。表格外元素（按钮、标签）：上方 6px、水平居中，居中会出窗时对齐外侧边，上方放不下才放下方。
- **提示框只说屏幕上没说的**（① 信息只说一次；产品负责人：已经显示的信息，为什么还要悬浮提示）：触发它的文字已经完整显示在屏幕上，就不给提示框——完整值只在**真被截断时**才出（悬停那一刻量一次是否溢出，统一用「截断才提示」的 `TruncTip`）；提示框要么补看不到的信息（完整路径、禁用原因、点了会怎样），要么不出现。
- **可悬停但不可点的标识不加任何装饰线**（D21；原「点状下划线」删除——网页 `<abbr>` 惯例，macOS 用户不认得）：只有说明的 `同名`、`Codex 不支持` 是纯 `tag-weak` 字，悬停照出提示框；`2 份不一样` 也是纯文字记号（12 `ink-mute`，2026-09-25 评审：名称格里不放键），点它拉开这一行的抽屉看差异（见 `DESIGN.md`「产品裁决 › 问题在哪看得见、在哪处理」）。全应用没有下划线；离开 Sophia 的动作是浅键 + `↗`。
- **时机**：表格内停留 **700ms** 才出现，在格与格之间移动时不出现、不追着鼠标（追着走是噪音）；键盘焦点到达后 700ms 出现。表格外的按钮 / 标签 400ms。移开立即消失。**按下（点击、空格、回车）立即消失，移开再进来之前不再出现**——按下是决定，结果提示就出在触发控件旁，提示框还挂着会把它盖住（产品负责人真机：点工具行的 Codex 项后，提示框盖住了刚出的批量提示条）。点了做不了的格子另说：那时立刻出的是这一格的说明（见下）。
- **所有点了做不了的控件，按下当即说明原因**（产品负责人：开关禁用时悬停才出提示、点击不出，可它是开关，用户一定会去点——这个问题之前在格子上出过）：禁用的按钮、开关、勾选框、图标键，点下去（或空格 / 回车）不改任何东西，但**当即弹出原因提示框**，不等悬停延时；「按下即收起」只对能点的控件成立。组件层统一实现（`Button` / `Switch` / `IconButton` / `Checkbox` / `Chip` 给了 `disabledReason` 就经 `ReasonTip` 自带这一行为），不靠各页自己包一层。下一条是它在格子上的原型。
- **点了做不了的格子，立刻说明**（⑪ 按下是决定，回应要明确）：受阻（⊘：无法写入、同名占位、agent 不支持这种写法）、整个文件夹是链接这几种格子点下去（或空格）不改任何东西，但**当即弹出这一格的提示框**（不等 700ms），停留约 3 秒或移开即消；内容说为什么 + 去哪做。只靠悬停出说明，点击会被读成没反应。原件格不在此列：它点了是删原件，先弹确认框（见 `DESIGN.md`「产品裁决 › 删除原件」）。表格格子的提示框同样走 `Tooltip`（受控打开、700ms、键盘焦点时才写快捷键），不另手写一份（2026-09-25 梳理）。
- **与悬停光晕配合**：光晕说「能点」，提示框说「点了会怎样」，同时出现。
- **可访问性**：内容同时作 `aria-describedby`，不依赖悬停。
- **按钮与浅键不用单字**（⑥）：`改` 读起来像半句话，写惯例两字 `编辑`（与 `保存 / 取消` 配对）。图标键以提示框文字计。
- **动作链不折行**：`打开 ↗` `只留这份` `再试一次` 这类动作整体一行；空间不够时截断旁边的标识文本（完整值进提示框），或按实际最长值定列宽。
- **路径一律把用户主目录写成 `~`**（`~/.agents/skills/defuddle`），提示框、展开区、铭牌同一写法。
- **承载后果或安全信息的文字一律不截断**（⑧）：限制说明、替换 / 删除的后果、安全提示先缩文案，仍放不下就折行，不用 `text-overflow: ellipsis`——被截掉的往往正是关键那半句（第三方模型「不支持图片」、替换说明）。可以截断的只有名字与路径这类可在提示框里看全的标识，且提示框必须给出全文。

### 提示条 `Toast`（放在 `FloatingToast` / `CornerToast` 里）

浮起、会自己走的一句结果。**一律是纸**：成功与失败同一种纸窗，靠句首记号（✓ / ⊘ / !）与**否定动词**分开，不靠颜色；墨色浮窗只给提示框（2026-09-25 产品负责人：「黑条提示都不要了，全局检查哪里还有用，黑条提示现在应该只在悬浮才出」）。档由 `kind` 决定：成功是 routine，其余是 notice。

| 档 | 长相 |
|---|---|
| routine：成功 | `paper` 面 + 1px `hairline` 边，`float` 12 圆角，浮层投影 `float`；单行定高 32、左右 12；字 13（`caption`） |
| notice：做不成、部分失败、单格失败原因 | 同一种纸窗，宽 ≤ 400；左侧 40×全高**记号栏**（右边 1px `hairline` 竖线）放 16px 状态记号（⊘ / !，`ink` 线稿）；正文区上下 10、左 12、右 6 |
| 忙碌（`BusyToast`） | 单格真要等（过 0.3 秒门槛）时，结果出来之前在同一个锚点先浮起一条 routine 纸窗：14 宽刻度 + 「正在…」 |

**写法**：主行 = **一个动词（600）+ agent 图标 + 名字（400）**：`清除 [Cursor] defuddle`、`写进 [Codex] excalidraw、notion`。**动词不能省**——文字只负责名字和动词，提示条 6 秒就消失，动词放 title 等于没有（第 5 轮评审：`✓ [Cursor] defuddle` 读起来和「开启了」一模一样）。名字至多两个，超过写 `+5`（12 tabular 500）；做不成必须带一句能行动的原因（可加副行路径），**动词带否定**：`没开启 [Codex] defuddle · 已有同名`——失败态里写「开启」会被一眼读成已加上。右侧 `撤销` 默认键紧凑 + `×`。

**四种内容**：成功与成功多项是例行一行（✓ + 动词 + agent 图标 + 名字，多于两个名字写 `+N`；`撤销` 只在没有顺手反操作时）；做不成（⊘ + 一句能行动的原因）与部分失败（! + `2 ✓ · 1 ⊘` + 哪里没成 + `查看`）用带记号栏的 notice 档。

**提示条里的动作（`撤销` `查看`）行内右置**，与 `×` 同一行，不掉到第三行。

**✓ 只有一种画法**（2026-09-25 产品负责人：「这里的对勾样式不对，应该和勾选的统一」）：界面上所有 ✓——成功纸窗句首、`✓ 已生效` `✓ 已启动` `✓ 已是最新版本`、菜单里当前项的对勾——都是勾选框里那一枚对勾图形（10px 视框、路径 `M2 5.3 4.1 7.4 8 2.8`、1.8 描边、圆头圆角、`ink`），与勾选框、拉手箭头同一套线形画法；不用字体里的 ✓ 字符（字形随字体变、笔画粗细对不上，同一个意思两种样子，⑤）。文中写作 `✓` 只是记法。

**放在哪**：`FloatingToast` 锚在触发控件上，`CornerToast` 在右下（只给后台发生的事）；一次只一条，同一范围里新的替换旧的；停留时长、悬停停表、淡出见 `DESIGN.md`「Patterns › 反馈」。

### 灰面板 `NoticePanel`

内嵌、不会自己走的提示：`surface` 实底、`face` 12 圆角、无边无投影；左侧 16px `!`（`IconAttention` 线稿），主句 `ink` + 原因 `ink-mute`——原因跟在主句后、同一行，不藏进悬停（原因决定下一步）；动作是默认键（紧凑 24，`paper` 面在灰上读得出是一颗键），可关的右端 `×`；要「以后再说」时加一颗 `稍后`（默认键紧凑）。与悬停行同色但形状不同（圆角、内缩、有内边距），不会被读成选中行。**大面积不用墨**（产品负责人：一整条黑太重；灰在机面与墨之间，够醒目又不抢），也不用橙、不新增颜色。宽度随网格：左右沿与所在内容一条线（见 `DESIGN.md`「Layout › 色块」）。

`scope` 分三档（2026-09-25 梳理：原 `ErrorBanner` 并入）：

| scope | 在哪 | 字与内边距 |
|---|---|---|
| `app` | 应用级故障：机面顶上、页面头之上，满内容宽 | 主句 15、内边距 12 16（原错误横幅的长相） |
| `section` | 挂在一节里（Codex 页「第三方模型」的行内待办条、设置「关于」的更新） | 主句 13、内边距 8 12 |
| `row` | 挂在一行下（某家网关拉不到模型） | 同 `section` |

忙碌走 `BusySlot`：面板里的键原位换成刻度 + 文字。

### 新手提示条 `HintStrip`

（2026-09-25 产品负责人：「界面上增加一些一次性提示，作为新手引导，比如用户第一次安装了应用，扫描完后，无论有没有载入 skill，都可以加这个提示说明」，参照一条横贯内容宽的细长提示条，右端 `×`。）

**是什么**：第一次走到某个地方时，在那里的内容上方铺一条说明「这里是什么、怎么用」的细条；关掉就再也不出。它教的是**第一次**需要知道的事，不报告状态，也不催你做事。

**长相：嵌在页面里的一条浅灰条**（2026-09-25 产品负责人：「我的意思不是这样悬浮，这样和我们现在的设计体系太不搭，还是之前那版本嵌入在页面里吧，只是可以用这种背景，不是之前白色 + 边框的……你来定吧」）：`shell` 底（#F4F4F2，机壳的颜色——像机面上开了一道窗、露出底下的机壳）、`face` 12 圆角、无边、无投影；高 40（两行时自适应，内边距 10 14）；宽同内容 776，左沿与表格左沿一条线。**上下各留 16**，与筛选行、表头都隔开，不挨着（原 10 挨得太近）。只有说明句 13 `ink`，不写「第一次用」之类的小标；右端 `×` 图标键（提示框「知道了，不再提示」）。
- **和灰面板分开**（⑤）：灰面板是 `surface`（#EFEFEC，更深一档）+ 左侧 `!` + 动作键，意思是「有问题，要你处理」；新手提示条是更浅的 `shell` + 没有左端记号 + 只有 `×`，意思是「第一次来，告诉你一声」。颜色、左端记号、右端动作三处都不同。
- 它推动下面的内容（嵌入就是占位）；收起时高度滑回 0，表格上移回原位。
- 不用橙、不用猫、不用图标（⑱ 不喧宾夺主）。

**何时出、何时不再出**（① ⑩ ⑮）：
- 每条只在**第一次**到达它说的那个地方时出现，一次只出一条；页面上已有别的提示条（灰面板、确认）时先让位，下次再出。
- **关掉（`×`）就永不再出**；**做了它教的那件事也算学会**，这条自动收起、不再出（例：首次扫描那条教「点格子加上 / 移除」，用户点过任意一格后它就收起）——学会了还挂着就是噪音。
- 记录存 core（`settings.json` 的 `seenHints`：提示 id 列表），换机或重装才会再出。没有「重新显示新手提示」（2026-09-25 产品负责人：「这个功能没必要」）。
- 出现、收起：淡入淡出 + 高度 0 ↔ 40 滑动（`--dur-drawer` 260ms、`--ease-mech`）；`prefers-reduced-motion` 下即时。
- **一个页面最多一条**；说明句**一行、只说结果**（机制——比如改的是哪个配置文件——留给需要据此判断的人去悬停看）。每一条在 `DESIGN.md`「产品裁决 › 新手提示条」的表里登记。

### 确认框 `Confirm`

纸浮层：`paper` + 1px `hairline` 边，`float` 12 圆角，浮层投影 `float`，不用黑框；宽 384、内边距 20 20 16。**一律在窗口正中，没有锚点参数**（2026-09-25 产品负责人：锚在靠下的格子时确认框出窗、键被截掉，「要不然这种弹窗都从页面中间出……不在锚点位置也是能接受的，因为其实就让用户看这个」——确认框出来时它就是唯一要看的东西）；遮罩 **`ink` 16%、整面压暗**，页面压暗一档、弹窗自然浮起（产品负责人：直角黑框「不够精致」，圆角 + 浮层阴影「明显更好看」）。

- **标题** `head` 16 / 600，一问、写明对象（`删掉 openrouter？` `从 Codex 删除 weibo-search？`，⑨）；汉字与专名原样、字距 0。
- **正文** `body` 15 `ink-mute`，**只说后果，不写路径**（2026-09-25 产品负责人：删原件确认框里的路径「这个不需要提示吧」）。唯一例外是只留这份：两份的路径是决定留哪份的依据——标题下两行 `留下` + 路径、`移到废纸篓` + 路径（`Mono`，主目录写 `~`，不截断、太长折行，不垫底色）。**承载后果与安全信息的句子必须留**（「这不是关掉一条链接，是把这个目录移走」「跨域会把请求头和令牌一并复制过去」）——那是功能。
- **键**：右对齐、间距 8、上距 18，键高 32、左右 16；主动作墨键在右、写动词（`删除` `删掉` `移除` `重启`），`取消` 默认键在左（D14，macOS 惯例）。焦点默认在 `取消`，Esc 收起。
- **窄面板形态**（托盘面板里，不开第二个窗口）：面板里当场展开一块 `recess` 面（`face` 12 圆角、内边距 10 12、左右外距 10），标题 13 / 600 `ink` + 12 `ink-mute` 后果 + 右对齐的 `取消`（默认键紧凑）与主动作墨键（紧凑）。

### 忙碌 `BusySlot` + `Spinner`

- **后台例行读取不显示任何忙碌**：页面刷新、文件监听重扫、网关轮询——用户没有在等，出现转动只会被读成出了问题（①）。**壳上没有全局忙碌指示。**
- **用户发起、正在等的操作，就地显示并带文字**（⑪ 回应强度与意图相称；门槛统一 0.3 秒——0.3 秒内完成就不出现，见 `DESIGN.md`「Patterns › 反馈」）：首次扫描「正在读 skill 目录」（内容区居中）、批量写入超过 0.3 秒时选择行里被按的点原位换成刻度 + 同一行「正在加到 Codex」、重启键原位「正在重启 Codex」、网关保存时按钮原位「正在拉模型」。指示器说在忙，文字说忙什么；没有文字的转动不允许。
- **指示器是一排刻度，亮的那根从左往右走**（2026-09-25 产品负责人：「基于现在的设计风格，重新设计加载按钮」；取代 D19 辐条）：一排短竖刻线（`ctl-border`，圆头），其中一根是 `ink`、前一根留一格 `ink-mute` 余晖，按格阶跃从左走到右，到头从左重来——Braun 收音机调谐刻度上指针扫过刻线的样子。尺寸 14 宽（行内、按钮内：5 根，1.5 × 7，间距 1.6）/ 24 宽（内容区居中：7 根，2 × 10，间距 1.7）；一趟 0.8s、`steps`，不做平滑滑动。完成即消失。**不用橙**：忙碌不是「在生效」。为什么不再用辐条：辐条是一个圆，界面里的圆已经全是格子状态（● ○ ⦿ ⊘ 虚线环），一个转动的圆放在表格旁边又是一个圆形记号（⑤）；刻线是这套界面自己的语言——开关的刻条、表头下的结构线、拉手箭头都是线——而且「一格一格读过去」正好是「正在读 skill 目录」在做的事（⑧）。旁边永远有一句「正在…」，没学过也读得懂（⑥ 的代价由文字补上）。
- `prefers-reduced-motion` 下刻度不走、全部 `ink-mute` 静止，文字后跟 `…` 每 500ms 增减一点。
- **`BusySlot`** 是 0.3 秒门槛的唯一实现（2026-09-25 梳理：原来四份），包在触发它的控件外面：原位换成刻度 + 文字；另有「变淡」（受影响控件 `opacity: .45`）与「浮起」（`BusyToast`：锚在触发处的一条纸窗，见「提示条 Toast」的忙碌档）两种形态。busy 期间受影响控件 `opacity: .45`，**五个豁免**：侧栏（含 `设置`）、筛选框、选择行的 `取消`、提示条关闭、表头排序——保持 `opacity: 1`，不加聚焦态，对比本身就说明它还能用。

## 选择

### 开关 `Switch`（物性之三）

**一个当场生效的布尔状态，对象就是它所在的那一行**，用开关，不用「启用 / 已启用」两态按钮。**开关旁边不写「已启用」**——它自己就是状态。

实物滑动开关，槽里一枚抬起的滑块（形状维持原来的圆角矩形；物性只加在投影、按压、弹簧与拖动上）：
- **槽** 34×20、`recess` 底（与页签槽、搜索框同一种凹面；2026-09-25 由更深的 `track` 改来：刻线变细后深槽显得笨重）、`track` 5 圆角、`recess-track` 内凹。
- **滑块** 16×16、`knob` 4 圆角、`paper` 面、`raise`（不画描边），上 2；关在 left 2、开在 left 16，移动距离 14。**面上无纹**：一块干净的白滑块（产品负责人 2026-09-24：按钮上的竖线去掉）。能拖靠抬起的投影与「位置＝状态」说明，不另加抓握记号（克制）。
- **刻线** 8×2、`scribe` 1 圆角，left 7、top 9：**开：滑块让到右边，左边露出一道 `accent` 橙线；关：滑块盖住它，看不见**（2026-09-25 取自拉姆斯版原型，产品负责人：「现在那条橙色的线太宽」——12×6 的刻条是一块色块，8×2 是一道线）。
- **两重表达**（⑧⑪）：滑块位置 + 刻条颜色——色弱用户靠位置不丢信息。开关旁**不再另点指示点**（2026-09-25：同一件事说两遍，①）。
- **点**：点槽或滑块任一处（没拖动）＝切换，滑块用 `--spring-slide` 200ms（`--dur-slide-knob`）滑到另一端停稳。
- **拖**：按住滑块或槽、横移超过 3px 进入拖动，滑块 1:1 跟手、夹在两端之间；**松手判定**：取松手前 50ms 的平均速度，|v| ≥ 0.3px/ms（300px/s，快速甩）按速度方向落；否则看位置——滑块移过全程一半（标准 7 / 紧凑 6，即行程 14 / 12 的一半）落到对侧，没过就回原位；再从松手处用同一条弹簧、200ms 停靠。落到对侧＝一次切换，与点击同一条路径（Codex「第三方模型」也一样：落到对侧就写配置，没写成才滑回）。拖动期间刻条颜色不跟手，判定后 120ms 换色。
- **不可用**：槽透明 + 1px `hairline` 环；滑块 `recess` 面 + 1px `hairline` 环、**无投影**（平贴：按不下的东西不离开机面）；刻条 `hairline`；不响应悬停、按住与拖。按下即出原因提示框。
- **reduced-motion**：点击即时到位；拖动时仍跟手，松手即时落位。
- 紧凑版 28×16（滑块 12×12，关 left 2 / 开 left 14，移动距离 12；刻线 8×2、left 4、top 7——与标准开关同一道刻线，2026-09-25 真机：6×2 在一列行里几乎看不见），四态见「控件有重量」。

开关都不需要确认（Codex「第三方模型」的开关也不确认：打断对话的是重启，重启另有确认，见 `DESIGN.md`「产品裁决 › agent 页」）：曾经「开启自动同步」要确认一道，是因为它会把来源里现有的几十个一次建完；现在规则只管以后新出现的，规模问题没了。

### 勾选框 `Checkbox` 与勾选行 `CheckRow`

**14 方、`mark` 4 圆角，记号是对勾；勾上是墨底白勾**（2026-09-25 真机走查：16 在 15 号字旁偏大，改 14，同 macOS；2026-09-25 产品负责人定稿勾选框的尺寸与圆角；同日问「那打了对勾是不是也用黑色」——是：选中在全应用一律是墨色，格子里的 `●`、选中的来源胶囊、勾上的框同一个颜色、同一个意思「这个在 / 这个选上了」，⑤）。

- **未勾**：平贴的白面——`paper` 底 + 1px `ink-faint` 内环，不抬起（2026-09-25 真机走查，产品负责人：「前面的选择框和文字不太协调」——`surface` 灰底加深环在一列字旁像一排灰砖；白面细环只剩一道线，是 macOS 勾选框的样子）。环用 `ink-faint` 而不是更浅的 `ctl-border`：行首这一列要让人看得出能多选，边对机面至少 3:1（WCAG 1.4.11，D8 ⑧ 优先于 ③）；
- **手靠近**：`raise-hover` 抬起迎手；
- **勾上**：`ink` 底、没有内环、平贴，中心一枚 10px `face` 对勾（1.8 描边）——墨底白勾是 macOS 勾选框的形（⑥），一列里勾没勾一眼分开（此前的「沉下去、`track` 底 + 墨勾」两档灰仍嫌不明显）；勾选中的行另有 `surface` 行带；
- **半选**（只有表头的全选框）：同样墨底，中心 8×2 `face` 短横。

记号用对勾而不是圆点：● ○ 在格子里说的是「加没加上」（⑤）。视觉 14、命中区 ≥ 24（见 `DESIGN.md`「Patterns › 命中区与视觉尺寸是两回事」），**全应用只有这一个尺寸**：表格行首、表头全选、设置页的 agent 列表、添加来源页的候选行、模型勾选列表、选目标浮层都用它。

**表格里勾选只经由这颗框**：表格行上满是能点的格子，点行的其余地方不勾选（避免误触）；`⌘` 点行、键盘焦点在行上按空格仍可加选。**列表**（设置页 agent 列表、模型勾选列表、选目标浮层）照旧整行可点——那里一行只有这一件事可做，用勾选行 `CheckRow`。不做「去掉这一列、点行即选」——没点之前看不出能选（⑧，产品负责人否决）。

**勾选行 `CheckRow`**（2026-09-25 梳理：`pages/CheckMark` 收进组件库，模型列表手拼的方框改用它）：整行是一个勾选项，方框只画状态。勾选框 + 10 + 可选 16px 图标（取不到用首字母方块）+ 名字（`body`）+ 可选行尾（模型 id 用 `Mono`；禁用原因作 12 `ink-mute` 副行）。整行命中；行上的 `data-checkrow` 让方框随整行悬停抬起迎手——这里点行就是勾，所以方框跟着行一起回应。悬停整行 `surface`、`control` 7 圆角，禁用的行不亮、按下即说原因。行高按所在处：设置页 agent 网格 36、网关里的模型列表 34、浮层菜单里 30（与 `MenuItem` 同高）。

### 页签 `Tabs`（物性之二）

位置页里切换两张表的是一条**页签滑槽**：浅灰**槽**——`surface` 底、`recess-tabs` 内凹、`tab-track` 10 圆角、内边距 3、连槽高 34；每个页签高 28、左右 16、`control` 7、`nav` Condensed 15 / 700 `ink-mute`、经 `Cap` 大写 + 1.17px（`SKILLS` `MCP`）；选中的页签是槽里一枚**抬起的滑块**：`paper` 面 + `raise`（不画描边）、字 `ink`，**字重不变（仍 700）**——选中靠滑块与墨色区分，字重不跳，切换时字宽不抖。

- **切换**：按下即切（⑰ 按下即响应；切页签天然可逆，不需要「移开取消」）——滑块被阻尼弹簧带到按下的页签，位移与变宽同一条 `--spring-slide`、260ms（`--dur-slide-tab`），停稳时过冲 1.5%；两个页签的字色 120ms 机械缓动换过来。按住期间滑块 `raise-pressed` + 按压变形，松开 180ms 弹簧回到 `raise`。
- **悬停**：未选中的字转 `ink`；指针在滑块上时滑块 `raise-hover`。
- **不能拖**：两个选项，点就够（⑩）。reduced-motion 下滑块即时到位。
- 页签之间没有竖线、没有下划线。

### 筛选片 `Chip`

**来源筛选＝一排浅胶囊，选中的是墨色**（2026-09-25 产品负责人多次纠正后定：抬起的波段键像动作键；滑槽读成「切换」；勾选框不对；只写字、选中才衬胶囊仍「还是乱，要不然就是不只是选中才像胶囊一样显示，默认就是有胶囊，只是颜色浅」）：放在胶囊行 `ChipRow` 里（行首标签 `来源`），第一颗 `全部`（默认选中、不带数），其后每个来源一颗胶囊，**名字 + 计数**（计数 12 tabular、离名字 6：没选 `ink-faint`，选中 `ctl-border`；2026-09-25 评审第二轮恢复——胶囊已有边界，数字不再和名字连成一片）：没选的 `recess` 底（比机面深一丝）、13 `ink-mute`；**选中的是墨色胶囊**：`ink` 底、`face` 字、字重不跳（2026-09-25 产品负责人：「要不然选中还是用黑色？现在两个颜色区分度不够，也不好看」——两档灰只差一点，选中读不出来）。墨色实心在表格里就是 `●`「这个在」，选中的来源＝「这个来源在表里」，同一个意思（⑤）；它平贴、是胶囊，与抬起的矩形墨键（主动作）分开。胶囊 `pill` 圆角、高 26、左右 10、无边无投影、不抬起；胶囊间 6，放不下折行。每一项有了自己的边界，一排名字不再连成一片（只写字时，项与项之间只靠空白分，名字里又有空格和 `·`，读不出边界）。**单选 + `全部`**（2026-09-25 评审第二轮，取代「多选纳入式、没有全部」）：点一颗＝只看这个来源，点 `全部` 回到全部，任何时候都有一颗亮着说出当前状态（⑧⑭；「一个都不选＝全部」时界面上没有东西亮着）；单选 + `全部` 是筛选最常见的样子（⑥）。再点已选中的那颗不变，所以**它悬停也不变**（2026-09-25 产品负责人：「选中后，每次会先出现一个灰色描边，然后才消失」——原来的选中再悬停内沿加一圈 `ink-mute`，点完手还停在上面，就先看到一圈灰；它许诺了一个不存在的动作，⑧）。它和另外两种控件分开：动作键是抬起的白色圆角矩形，页签是凹槽里一枚抬起的白滑块，来源筛选是一排平贴在机面上的灰胶囊——不抬起、不在槽里、不是白色（⑤）。手靠近没选的一颗：底转 `surface`、字转 `ink`。项上不点指示灯。

**禁用**：平贴、1px 实线 `hairline` 环、`ink-faint` 字；必须给原因（`disabledReason`，按下即出，2026-09-25 梳理补上）。

### 模型片 `ModelChip`

Codex 页「在用」一行（2026-09-25 恢复）：白胶囊——`paper` 面 + 1px `hairline` 环、`pill`、高 26、左 10 右 8、无投影、13 `ink`；右侧 9px `×`（1.4 描边线形，`ink-mute`，悬停 `ink`，左间距 6）。放在机面上、凹面上同一个样子，不必换底。**不用墨**：墨色是在一排选项里标出「选上的那几个」，这一行全是在用的，整排涂墨只是加重量（③）。显示友好名（`Kimi K2`），完整 id 进提示框；片间 6，折行不藏。筛选片＝选中，模型片＝在用、可移除，差别在 × 与颜色。

### 菜单 `Menu` + `MenuItem`

浮层里的一组选项，放在 `FloatingLayer` 里（面、投影、定位见「浮层」）。2026-09-25 梳理：取代侧栏排序、选目标浮层、同名挑选浮层、托盘菜单项四份各写的项。

- **项高 30、13 号字（`caption`）**（2026-09-25 裁决，取代「选项行高 34、`body` 15」：浮层菜单比页面列表紧凑是 macOS 惯例，⑥；原有四份实现都落在 28–30 / 12–13）。左右内缩 4（托盘面板里外距 6）、内距 10、`control` 7 圆角；高亮（悬停、键盘）`surface`。
- **三种项**：普通；单选——左侧 16 宽的 ✓ 列，当前项打勾（对勾同勾选框那一枚，macOS 菜单惯例）；多选——行首勾选框、整行可点（与勾选行同一套回应）。都可带一行 12 `ink-mute` 副行（来源位置、与其他份差在哪、禁用原因）。
- **组头** `label` 12 `ink-mute`，组名 600。
- **宽随内容**：设上限，超了在里面折行，左右留白对称；不设最小宽（排序下拉）；选目标最宽 280、同名挑选最宽 320。定宽配短项会在右边空出一大块。
- 点一项即生效并收起（多选不收）；点外面或 Esc 关；不配「保存」「关闭」。

## 输入

### 输入框 `TextField`

平的浅灰面——`recess` 底、1px `hairline` 边、不画内凹阴影、`control` 7、高 28、左右 10；字 `caption` 13，占位字 `ink-mute`；放大镜 16px 在框内左侧；聚焦边转 `ink-mute`；**键盘**聚焦时另加全局焦点环，指针点进去只转边色（与全应用焦点规则一致：焦点框只看 `src/inputModality.ts`）。浮层里的搜索框用 `face` 底（在 `paper` 浮层上仍读作凹面）。

**搜索形态**（位置页筛选、模型筛选）：放大镜在框内左侧；框内右端写快捷键提示 `⌘F`（12 tabular `ink-faint`）；有字时换成 ✕ 清除（8px 内）。位置页的筛选框定宽 200、表单输入框 360（宽按用途，不随字，见 `DESIGN.md`「Layout › 色块」）。只有外观与清除，不接 `⌘F` 命令、不含标签与校验。

## 容器与层

### 页面头 `PageHead`

机面顶上一行，高 34（容得下 28 高的页签外加槽的上下各 3），宽同内容 776。左端是这一页的主控件或页面名，右端是这一页的动作（间距 8）。页面名一律 `title` Condensed 20 / 700，原样、字距 0；推入页在页面名前放 `←`（图标键 28）+ 10。页面头里没有控件的空白处是拖窗区。各页放什么见 `DESIGN.md`「产品裁决」各屏。

### 推入页 `PushedPage`

在机面里推入一页（2026-09-25 梳理：取代死代码 `SubPage`，来源管理页与添加来源页原来各写一份外框）。

- **只替换机面**：侧栏留着、当前位置仍选中；从右推入、`←` 或 Esc 滑回，200ms（`--dur-push`）`--ease-mech`，只在机面里推、侧栏不动；`prefers-reduced-motion` 下即时。
- **下层不可交互**（inert）；进页时焦点落在页面名（`tabIndex={-1}`），返回时焦点还给入口的那颗键。回来时下层页面的筛选、滚动位置、拉开的抽屉照旧（⑨ 状态保持）。
- **页面头**：`←` + 10 + 页面名，右端可有这一页的动作。
- **可选贴底一行**：高 60、上 1px `hairline`、`face` 底，主动作右对齐到内容右沿；列表区在它上面滚动（边缘渐隐）；右下提示整叠抬到贴底行上面。
- 读屏：页面 `role=region`、名＝页面名；返回键 `aria-label=返回`。Esc 先关浮层与确认，其次才是返回。
- 不做盖满整窗、不渲染侧栏的二级页（D1、D6）。

### 能力节 `Section`

agent 页里一种能力一节。节头一行：节名（`head` 16 / 600，汉字与专名原样、字距 0）+ 12 + 开关（标准）+ 12 + 条件出现的一颗键（默认键紧凑 24；同一位一次只放一颗）。节里的内容与节头同一条左沿、宽同内容 776；行动作落在右端同一列。节与节之间 48。键引起的结果（`✓ 已生效`）锚在这颗键下、左对齐键。

### 区块小标 `SectionLabel`

一组内容的小标题，**全应用只有这一种**（2026-09-25 裁决，取代「贴 hairline 上方 6」与网关小标 12 / 500 两种写法）：`label` Condensed 12 / 600、`ink-mute`（墨面上 `ctl-border`）；汉字字距 0、不变换，拉丁结构词经 `Cap` 大写 + 0.96px（`AGENT`）。

- 可选**下 7 一条 1px `hairline`**，跨内容宽（设置、Codex 页 `网关`）。
- 可选**右端一颗键**，右沿对齐内容右沿（`+ 网关`；侧栏 `项目` 右端的排序下拉）。
- 上距由所在处定：设置页面头下 24、`关于` 上距 48；Codex 页 `网关` 上距 30；侧栏行高 26、左右 20、上距 14。
- 它不是节标题（那是 `Section` 的 `head` 16），也不是表格列头，也不是胶囊行的行首标签。

### 胶囊行 `ChipRow`

行首标签 + 8 + 一排胶囊（筛选片或模型片，由调用方放进来）；胶囊间 6，放不下折行、不收进下拉。行首标签是 12 / 500 `ink-mute`、行高 26（与胶囊同高、居中），不用 Condensed、不画下线——它说「这一排是什么」，不是区块小标。用在位置页的 `来源` 筛选行、Codex 页的 `在用` 一行（⑤ 同一种写法）。

### 列表行 `ListRow`

两行高的列表行，整行可点：点整行＝拉开 / 收起这一行的抽屉。

- **列**：可选勾选格 24 ｜ 拉手 18 + 6 ｜ 内容 ｜ 行尾动作列（间距 4，各行成一列）。内容第一行名字（`body` 15），第二行 12 `ink-mute`（上距 3），放不下截断、截断才提示。
- **行**：上下内距 10；行间 1px `row-line`（最后一行不画）；下挂 `Drawer`。
- **悬停**：整行出 `surface` 带（`control` 7 圆角；右键菜单开着时同样亮；拉开的那一行不再出）——整行能点就该有悬停回应（2026-09-25 裁决：网关行与添加来源候选行都有，取代候选行「不设悬停底色」）。
- **有勾选格时**：勾选只归那颗方框（命中区 28，不挪排版）；方框只在手靠近**它自己的命中区**时抬起，不随整行悬停抬起——这里点整行是拉抽屉，整行悬停就抬方框会被读成「点行就勾」；勾上不改行底色（勾选框就是状态）。拉手在悬停或键盘焦点到这一行时才出，拉开的那一行常显。
- **没有勾选格时**：拉手常显。
- 用在网关行与添加来源的候选行。表格行、来源管理页的来源行、侧栏项不是它（列与语义各不相同），只和它共用「拉手列同宽」「行尾动作成一列」两条规则。

### 抽屉 `Drawer`

**展开＝从机面里拉出一格抽屉**（2026-09-25 产品负责人定稿，取代 `▸ / ▾` 字符）：次要的东西收在里面，拉手露在外面——实物形式的渐进披露（①），从哪里拉出、就收回到哪里（⑨）。

- **拉手全应用一个形、一个位置：名字前，收起 ›、拉开转 90° 朝下 ˅**（2026-09-25 评审第二轮，⑤ 同一个动作只学一次；取代同日「名字后 ˅ / ˄」与「按位置取惯例」）：名字前留 18 + 6 的拉手列（勾选框 ｜ 拉手 18 ｜ 6 ｜ 名字），没有抽屉的行这一格留空，各行名字对齐、列头 `名称` 也对齐；表格面板宽 776 不变，这 24 由名称列让出。行首的 › 是访达 / 树形列表的展开三角（⑥）。**出现时机随行不同，形与方向处处一样**：有勾选框的行（表格、添加来源候选行）**平时不画，悬停这一行（或键盘焦点到这一行）时出现**，拉开的那一行常显；没有勾选框的行（网关行）常显。**只有箭头，没有键面**（2026-09-25 产品负责人：「可以简单点，只要箭头就够了」）——整行已有悬停色带回应，箭头再套一颗键是第二遍回应（①）。点名字、点整行仍能拉开。名字后的 `×2` / `2 份不一样` 是纯文字记号（算名字的一部分），跟在名字后面，点记号也拉开抽屉；名称格里不放键——顺序是「› 名字 ×2」，行内的动作（`只留这份`、看差异）在抽屉里。
- **拉手的样子**：只有一枚 10px 线形箭头（1.4 描边，`ink-mute`，与图标同一套画法——不用排版字符 ▸），没有键面、不抬起；命中区 18 方。收起朝右 ›，拉开时用 `--spring-slide` 260ms 转 90° 朝下 ˅。
- **抽屉**：这一行下面拉出来的详情，**不垫底色块、不画阴影**（2026-09-25 产品负责人：「尽量只在必要的时候使用阴影来体现层次」「再审视下全局各种背景色块的使用」——详情缩进到名字的左沿、夹在这一行和下一条行线之间，归属已经清楚），上 6 下 12；左沿对齐这一行的名字（拉手列之后；由行给出 `inset`，页面不覆盖抽屉的内部类）。高度从 0 滑出（260ms `--ease-mech`），收起时滑回；`prefers-reduced-motion` 下即时。抽屉下 1px `row-line`。
- **谁开抽屉**：点拉手；表格行点名字、列表行（网关、添加来源页的候选）点整行，与原来一致。Esc 收起；表格一次只开一格。
- 「抽屉」只指这种行下拉出的详情；从窗边滑出来的侧滑面板本产品不做（它是弹层，见 `DESIGN.md`「Patterns › 页面还是弹层」）。

### 浮层 `FloatingLayer` + `FadeViewport` / `useEdgeFades`

锚在一个控件上的小浮层（菜单、选目标、同名挑选）：`paper` + 1px `hairline` 边，`float` 12 圆角，浮层投影 `float`——**浮层阴影在全应用只有这一个值**（提示框同投影、`control` 7 圆角、无边）。定位走同一个锚定函数（`layerPlace`），出窗时翻到另一侧、贴窗边留 16；点外面或 Esc 关。

里面能滚时用 `FadeViewport`：被裁掉的边缘 16px 渐隐，从它所在那一面的底色到透明（机面 `face`、浮层内 `paper`、侧栏 `shell`），提示那边还有内容。量「哪一边还有被裁掉的内容」只有 `useEdgeFades` 一份（2026-09-25 梳理：原来五处各写一份监听）。

### 空态 `Empty`

一块区域完全没有内容时：插图 + 一句现状（15 `ink`，可带一行 13 `ink-mute`）+ 至多一个动作。图不带边框，图在上、文字与按钮在下，间距 8 / 16，整体在内容区居中。动作用默认键，离开 Sophia 的（带 ↗）用浅键；动作已在页面头的（`+ 来源` `+ 网关`）空态里不重复。插图的用法与画法见 `DESIGN.md`「标志与插图 › 图像」，各屏有哪几种空态见 `DESIGN.md`「产品裁决」里各屏的空态。

### 灰字一句 `Note`

一句 13 `ink-mute`，可在句后跟一颗默认键紧凑（`清除筛选`）或浅键（`去发布页 ↗`）；不带图、不居中，左沿对齐它说的那块内容。用在筛选无结果（表头下一句 + `清除筛选`）、`还没有网关，先加一家`、`别处还没有可加的来源`、设置里检查更新失败的说明（2026-09-25 梳理：原来五处 `*__none / *__empty / *__note` 各写一份）。

## 状态记号

### 格子记号 `StateDot`

格回答两件事：**填充＝这个 agent 能不能用它，外环＝它在这儿是原件还是一条软链。**

| 状态 | 形 |
|---|---|
| `linked` 已加上 · 软链 | 10px 实心 `ink` |
| `missing` 未加上 | 10px 外径、1.3px `ink-mute` 环（对机面约 8:1；比实心 ● 退后一层，一整表的 ○ 不和 ● 抢眼） |
| `own` 已加上 · 原件 | 10px 外径 1.3px `ink-mute` 环 + 4px `ink` 实心芯 |
| 无格 | 8×1.5 短横 `ink-faint`，不可点 |

**前三行是状态，第四行不是**：「无格」说的是这儿根本没有这一格，不是某种状态。异常态用同一个 10px 环骨架的记号，由提示框说原因：**虚线环**＝链接失效（4 段、段间 1.5px 空）；**斜杠环 ⊘**＝受阻，这一格放不进去（无法写入、同名占位、agent 不支持这种写法；环 1.3px `ink-mute`、斜线 1.3px `ink`——「受阻」靠斜线说，不靠加粗整个记号）；整个文件夹是链接用整列记号。**没有环内短横 ⊝**（D22：同名占位合进 ⊘——那一行名字后已有 `×2`，⊝ 是第二遍；10px 下与 ⊘ 也难分）。格子记号从 7 种减到 6 种。

**光标**：所有格子（能点的、原件、受阻、无格）一律箭头光标，不出手形（D23，见 `DESIGN.md`「Patterns › 光标与文字选取」）；能不能点由悬停光晕与提示框说。

勾选中的行用 `surface` 底，圆点不变色。格点**没有凹坑、不上色**；悬停时点本身不变，只在下层出 22px `hairline` 圆形光晕（在 `surface` 底上改用 `track`；见 `DESIGN.md`「产品裁决 › 位置页 › 表格」）。选择行上的点与格子同形同尺寸。

### 标识 `Tag`

名字后面**不可点的纯文字标识**，12px，没有框、没有任何装饰线（D21；框只属于能点的东西）：强的 `ink` 600（`无法连接`），弱的 `ink-mute` 400（`同名` `Codex 不支持` `2 份不一样`）。悬停照出提示框说明。同名的 `×2`（`DupMark`）是它的一种：12 tabular `ink-faint`；它自己不可点，「点 `×2` 拉开抽屉」由所在的行承担。

### 指示点 `Indicator`

6px `accent` 圆点，外一圈 2px 同色 14% 的灯罩环（`box-shadow: 0 0 0 2px var(--accent-halo)`，token `--accent-halo` = `rgba(224, 101, 42, 0.14)`，lint 在指示点上放行；平的色环；2026-09-25 取自拉姆斯版原型——像装在灯座里的一盏指示灯，⑯ 细节到位）。**不模糊、不发光**：「别做」里禁止的是发光 LED 的拟物光晕，这是一圈实色。

**橙只在这里，和它的指示点上。** 指示点只有一处：侧栏 agent 名后，**始终**表示「这个 agent 上有能力开着」，是导航上的常驻状态——在哪一页都一样亮，不随你所在的页面熄灭（2026-09-25 评审提出「在 Codex 页开关就在眼前，点还亮着是说了两遍」：改成进了这一页就灭，点的意思就随位置变了，更难读，⑤；点与开关一个在导航、一个在内容，各说各的层级）。来源筛选片上不点灯（2026-09-25，见「筛选片 Chip」）。开关刻条与指示点以外任何地方出现橙都是缺陷。

只在看不到开关的地方出现；开着才画，什么都没开时不画——不画灰点。

## 图标与排版原语

### 图标 `icons.tsx`

所有图标同一套画法：16px 画布、`currentColor`、1.4 描边。**设置的入口必须是有齿圈的齿轮**——第一版画成圆心加八根放射线，那是太阳，用户看成了「切换日间模式」。看不懂的图标比没有图标更糟，这条和列头灯是同一课。

**词表——只有这几个动作有图标，别的一律写字**：

| 动作 | 图形 | 提示框 |
|---|---|---|
| 设置 | 8 齿齿轮 | `设置` |
| 编辑 | 铅笔（45° 斜置） | `编辑` |
| 删掉 | 垃圾桶（带盖） | `删掉` |
| 添加 | `+` | `添加网关` 这类带宾语的全名 |
| 关掉 / 移除一片 | `×` | `关掉` |
| 返回 | `←` | `返回` |
| 搜索 | 放大镜（输入框内） | — |

判据：**离开这个界面，用户在别的软件里见过同一个图形做同一件事**。「重启」没有这样的图形（循环箭头是"刷新"），「拆开」「再试一次」更没有——这些写字。

词表之外只有几枚**记号**，也都在 `icons.tsx` 里、同一套画法：`↗`（浅键末尾，10px）、拉手箭头（10px 线形，收起 ›、拉开 ˅，不用排版字符 ▸ ▾）、对勾（勾选框、提示条句首、菜单当前项）、状态记号 ⊘ / !。页面里不自画 SVG（2026-09-25 梳理：×、+、↗、›、放大镜原来各有散落的自画版本）。

### agent 图标 `AgentIcon`

单色 inline SVG，`currentColor` 取色。**不用品牌色，也不用橙。** **Codex 用 OpenAI 绳结标志**（识别特征：中心六边形空洞 + 六段逐段旋转 60° 的交织弯折）：第一版六瓣软轮廓在 16px 下读成云 / 齿轮，认不出比没有更糟，又不能退回首字母（「C」已给 Cline）。取官方 SVG 转单色；16px 糊时宁少一层交织，保住中心六边形与外轮廓六个圆角。所有出现处走同一个定义。光学补偿：Claude Code 的星形是放射实线，同尺寸下比其他线性图标重——描边降到 1.2、视觉尺寸比其他小 1px。实现时用各项目官方 SVG 转单色路径，不手画。取不到的用**首字母方块**（14px、`mark` 4 圆角、1px `ctl-border` 边、`ink` Barlow Condensed 11 / 600 大写字母（经 `Cap`，与列头名字同一种写法）；未启用时字母随名字退到 `ink-mute`）——它是图标缺席时的占位，**永远和名字一起出现**：已安装的 9 个里首字母就撞了 3 个 C、2 个 G。

尺寸：列头、设置页、托盘 16，侧栏 15，Codex 页页面头 24。

### 大写结构词 `Cap`

按脚本把文本切成 run，只给拉丁 run 套 Condensed + 大写 + 字距，汉字 run 原样、字距 0；数据本身不改。档位：`nav`（15 / 700 / 1.17px）、`label`（12 / 600 / 0.96px）、`head`（16 / 600 / 1.1px）。`text-transform: uppercase` 与非 0 `letter-spacing` 全应用只许出现在它的样式里。用在哪、不用在哪见 `DESIGN.md`「Typography › 大写是结构的语言」。

### 等宽路径 `Mono`

路径、id（模型 id、服务名）、版本号、命令：IBM Plex Mono 12 / 400（`mono`），默认 `ink-faint`；**可选中拷走**（放开 `user-select`、文本光标）；主目录写 `~`；放不下中段省略、完整值进提示框（截断才提示）。skill 名与计数不用它。2026-09-25 梳理：取代四份页面自写的路径样式。
