# MCP 页的前置材料

这不是 spec，是画稿阶段查证出来的事实，写第二份 spec（MCP 页）时直接用，不要重新查。

## 1. `Conflict` 不能当格状态（已验证）

`mcp.rs:412-430` 的 `scan()` 是**遍历全部位置的全部条目**建行的：每个持有同名条目的位置都产出自己的一行，`source_id` 是它自己。`mcp.rs:439` 判 `target.id == entry.source_id ⇒ Own`。

推论：某行在列 X 上是 `Conflict`，说明**列 X 自己也持有同名条目**，于是 X 也产出了自己的一行、带自己的 `Own` 格。

**所以同一个服务名在冲突时会在矩阵里出现两行**，各有一个 `Own` 和一个指向对方的 `Conflict`。把「两份不一样」画成格状态，等于把行级事实塞进格里，必然自相矛盾。

**做法**：两行照旧各画自己的环，差异做成**行级标记**——服务名后挂零圆角方标签「2 份不一样」（不可点，组件规范 §3.1），并进待处理栏，动作 `看两边差在哪` / `忽略`。

**它和 skill 的 `Duplicate` 不同**：`Duplicate` 是用户自己扔在那儿的文件、我们读不懂，说一次就够；这里两份都是我们能读的 MCP 配置，用户有真实取舍，而且不会自行消失。

**待处理栏里不给「覆盖 / 合并」**：`mcp.rs:522-540` 的 `prepare` 对目标已有同名条目一律跳过。覆盖是新的破坏性能力，要像「删本体」那样单独定 spec，不在这一期凭空发明。

## 2. MCP 页有四处**不该**跟 skill 页一样

1. **格是单向的。** skill 的格是开关，MCP 只有「写进去」、没有「拿掉」（core 只新增，不删条目）。所以选择条上的位置片不是「灯亮＝全开、点一下关」，而是「还缺几处、点一下写进去」；全有的片走不可选态。
2. **实心不是一条链接，是一份独立副本。** 每一处都是别人配置文件里的一段真实内容。§2 的「本体 vs 软链」平移成「来源 vs 另一份一样的」；§4.1 的「撤销」不能照抄——MCP 写入从 UI 上不可逆，要给撤销得新增「按备份回滚」的能力。
3. **差异是行级、不是格级**（见上）。这是 MCP 独有的第四种记号。
4. **列的身份是文件，不是 agent。** 同一个 agent 在一个域里可能有多个 MCP 位置（Claude Code · User / Local / Project），项目域里会出现同图标两列。列头按 §9.1 堆叠图标 + 名字，但名字是**位置名**。

## 3. 三个动作的人话（现有代码的真实语义）

- **引入**＝这个域里根本还没有这个服务，从别处搬一份完整定义过来。入口是二级页面。矩阵里遇到「有好几份不等价的同名来源、必须指定用哪份」（`sourceForMissing` 返回 null）时也跳这里。
- **补齐**＝本域已经有这份定义了，只是某些位置还缺——把已有那份复制到缺的位置，不用选来源。入口是点空心格，或勾几行后点选择条上的位置片。
- **同步**＝**界面上不出现这个词**。`proposeMcpSync` 和 `previewKind` 初值 `"同步"`（`McpTab.tsx:71`）是残留，`openPreview` 只会传「补齐」「引入」。而且「同步」是双向词，这里只新增、从不覆盖也不删除，用它会骗人。

## 4. 其余功能的落位

| 现有东西 | 归到哪 | 理由 |
|---|---|---|
| `overview.issues` 扫描问题 | **列头灯加斜杠 + 待处理栏**，不是错误横幅 | 它是位置级的（某个文件读不出），错误横幅只留给应用级故障 |
| `report` 写入结果 | 提示条，汇总一句 + 等宽副行（处数、备份文件名） | |
| `preview.issues` 跳过的项目 | 留在确认弹层内 | 是做决定所需的信息 |
| 传输 / 来源位置 | 矩阵两列，紧跟服务名 | `不支持` 那行整行不可选 |
| 「刷新」按钮 | **去掉** | 聚焦、切项目、改设置都会自动重扫（`refreshKey`），再留一个按钮是噪音 |

## 5. 需要在 spec 里定掉的

- **`matrixHidden` 与「文件不存在也成列」冲突**。skill 页已定「目录不存在的 agent 照样成列」；MCP 这边 Claude Code 的 Local、未创建的 `.mcp.json` 现有实现不成列、只能在引入页当显式目标。两条规则对不上，必须定掉一个。
- **MCP 单格写入要不要确认**。画稿口径：同域单格直接写（提示条给备份名），批量与跨域才确认（跨域那道就是现有 `allowCrossDomain`）。
- **撤销**。画稿按「不可逆」处理，改成 `看看备份` + 等宽备份文件名。要真给撤销，得新增按备份回滚的能力。
