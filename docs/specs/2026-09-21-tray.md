# 菜单栏入口：关窗不退出，一键开关模型注入

> 依据：`docs/DESIGN.md`。参照对象是 ollama 的菜单栏面板。仅 macOS（模型注入本身只支持 macOS）。

## 问题

模型注入是个开关：额度用完想关，要测试想开，切换很频繁。现在拨它得先找到窗口、切到「模型」页。
而且关窗就是退出，应用没有常驻的入口。

## 需求

- **R1** 菜单栏常驻一个图标。左键弹出面板，右键给原生菜单兜底（打开、退出）。
- **R2** 面板里一行 Codex：图标、名字、一句现状、一个开关。开关是 ghost pill 两态，反色＝已启用。不用滑动开关（DESIGN「Don't」）。
- **R3** 开关按不动时必须说原因（`title`），并给一条去「模型」页的路。
- **R4** 「重启 Codex」只在有改动等着生效时出现（启用或停用之后、Codex 还开着旧配置），重启完自己消失——平时摆着是噪音，还多一个误触的机会。它会中断进行中的对话，确认一道（DESIGN「确认」三处之一），确认就在那一行上完成，不另弹窗。
- **R5** 面板里的动作做不成时，不在面板里解释：把主窗口带到前面、切到「模型」页，由那里说原因。面板放不下一段话，一件事只在一个地方说。
- **R6** 关主窗口＝藏起来，不退出。第一次关时说一次「还在菜单栏里」。点 Dock 图标把窗口带回来。
- **R7** 「退出」真的退出应用。路由是系统后台服务，不受影响——注入状态不因退出而变。
- **R8** 面板每次弹出都重读状态；面板改了状态，主窗口的「模型」页跟着刷新。

## 设计

- 面板是应用自己的一个无边框小窗（标签 `tray`），和主窗口同一份前端产物，按窗口标签分流到 `TrayPanel`。系统原生菜单套不上设计规范，所以不用它做主入口。
- 面板零圆角、1px `ink` 描边、无阴影；失焦即收起。位置取菜单栏图标正下方、水平居中，超出屏幕右缘时往回收。
- 文案复用 `modelsView.ts` 的 `statusSentence` / `enableDisabledReason` / `factsLine`，面板与模型页说同一句话。
- 窗口的显示、隐藏、退出走自己的命令（`tray_open_main` / `tray_hide` / `tray_quit`），不给面板窗口开放通用的窗口权限。
- 菜单栏图标是单色模板图（系统按深浅色自动着色），零色彩。
- Dock 图标保留：应用主体仍是 Skill / MCP 的管理界面，不是纯后台工具。

| AC2 (R3) | Given 没保存密钥，When 面板弹出，Then 开关禁用、`title` 是原因、动作区出现「去配置」 | 真机 | 同上 |

## 范围外

Windows / Linux 托盘；隐藏 Dock 图标；在面板里选模型或改配置；多 agent 行（目前只有 Codex 支持第三方模型）。
