# Sophia 设计系统

**本文件是实现的唯一依据。** 画布「SymSync 界面重构」（改名前的画布，名字未改）是视觉参照，两者不一致时以本文件为准；改组件先改这里，再改代码，再同步画布。`scripts/lint-ui.mjs` 把本文件的硬性约束变成了可执行断言，接在 `make lint` 里。

历史裁决与每条规则背后的推理在 `docs/specs/2026-09-21-ui-decisions-log.md`，本文件只写结论。

## Overview

**像一件器物，不像一张线框图。** 参照 teenage engineering TP-7：极简、现代、机械感、工艺品。色调仍是黑白、零色彩零阴影零渐变，logo 不动。2026-09-22 产品负责人判定前两版「过于简陋」——提示条是白底 1px 线框盒，全产品只有一种材料（白底上的 1px 线），规则再严也像没上材质的草图。下面「材料与工艺」一节是这一版的总纲，其余各节与它冲突时以它为准。

## 设计原则：尊重用户的注意力与判断

**这是此后一切评审的标尺**（产品负责人，2026-09-22）。用户依次付出注意力 → 理解 → 行动 → 信任，对应四根支柱、13 条原则。下文「材料与工艺」「视觉优先」和各节裁决都是它们的具体化；冲突时以本节为准。

| 支柱 | 原则 | 在 Sophia 里意味着 |
|---|---|---|
| **一 不浪费注意力** | ① 信息在对的时间、对的位置出现：就近出现、就近不遮挡、局部就近全局全局、严重程度决定打断程度；判断标准是「此时此刻对这个用户重不重要」 | 单格提示就出在被点的那一行里；批量提示贴在按下的那一项下；新问题只提示一次；只在挑模型时有用的说明放进模型下拉 |
| | ② 视觉权重与重要性一致，一个界面一个主角 | 表格是主角；图标键、开关都让位于主动作 |
| | ③ 默认值本身就是设计，复杂度由设计者承担 | 见「默认值」表 |
| **二 降低理解成本** | ④ 统一性：相同形式承载相同含义，不同含义不长得一样 | 黑色体块＝机器在说话；黑色小键＝已按下或已选中——实心黑不再加新义 |
| | ⑤ 符合用户已有心智模型，用用户的语言 | 界面说「原件」不说「本体」、说「同名」不说「撞名」、说「整个文件夹是链接」不说「整个文件夹是链接」（lint 旧词表拦回潮） |
| | ⑥ 外观说明如何操作，文字提供确定性 | 格子悬停出光晕表示能点、点本身不变；文字确定性由「提示框」承载，不用原生 title |
| | ⑦ 保持上下文连续，用户始终知道在哪，认出而非回忆 | 确认框不盖掉正在决定的那一行 |
| **三 行动轻松且安全** | ⑧ 操作成本与频率、风险匹配，为熟练用户提供高效方式 | 见「键盘」 |
| | ⑨ **产品在和用户对话，而不是静态地等待**：用户做了什么，系统回应「收到了、正在处理、成功了或失败了」；用户想做什么（悬停、聚焦、靠近），系统也回应「这里能做什么、做了会怎样」。回应强度与意图的确定程度相称：悬停是试探，回应要轻；按下是决定，回应要明确；完成要确认。最好的回应常常是足够快 | 格子十字带 + 悬停光晕、列头悬停（轻）；按下 1px 压扁（明确）；刚点亮反色闪 120ms（确认）；地球绕太阳 + 一句忙什么（持续）；乐观更新 |
| | ⑩ 预防错误优先于处理错误 | 添加时就地解决同名，不把冲突推进待处理 |
| | ⑪ 允许犯错，能撤销就不弹确认，只有不可逆才打断 | 删原件进废纸篓＝可逆 → 直接删 + 撤销；确认只剩两件 |
| **四 守护信任** | ⑫ 诚实不操纵 | 问题一直在那一行上看得见，不藏；一次性提示看过即止，不反复催；「只建链接，不动源文件」 |
| | ⑬ 用户始终保有控制权 | 自动规则的每次动作可见可撤销；重启给「稍后」 |

### 怎么用这套原则

- **地基**：核心理念「尊重用户的注意力与判断」。四层：理念 → 支柱 → 原则 → 具体准则（本文件其余各节）。
- **原则冲突时，向上裁决**：两条原则矛盾，或体验与商业目标冲突时，回到理念问——哪种做法更尊重用户的注意力与判断？是在帮用户判断，还是在干扰用户判断？
- **新经验出现时，向上归位**：先问它属于哪条原则、服务哪根支柱；找不到归属，要么它不重要，要么体系有缺口、值得补——作为「体系缺口」上报产品负责人。
- **评审与改动说明都标原则编号**（①–⑬）。

已裁决的冲突：

| 冲突 | 裁决 |
|---|---|
| ⑥ 对 ⑤：自创的格内异常记号偏离惯例 | 保留——它帮用户一眼扫完 56×4 个状态；**成立前提**是格子悬停光晕 + 提示框兜底（这两条从改进升为前提） |
| ⑨ 对 ①：单格操作要不要提示条 | **要，出例行一行**（产品负责人真机：加软链、删软链的反馈不足）。格子一闪只在视线正盯着那一格时有效；点完视线已移开、或连点几格时，120ms 闪烁看不到。一行白底墨字不抢注意力（①），又给了撤销入口（⑪）。黑块仍只给失败 |
| ⑪ 对 ①：删原件要不要确认 | 撤销代替确认 |
| ① 对 ⑨：回应的边界 | 没有意图就没有回应——空闲时界面静止，无呼吸、无循环动画、无吸引注意的晃动，回应只由用户唤起；`prefers-reduced-motion` 下动效退化为即时状态变化，信息不减 |
| ③ 对 ⑬：要不要自动重启 Codex / 做成设置项 | 都不做——重启的是用户正在用的另一个应用，看似空闲也可能有未发草稿与上下文，替用户选中断时机是被产品裹挟（⑬）；做成设置项是回避决策（③）。重启时机归用户，Sophia 把键放在对的地方、如实说出代价 |
| ⑫ 对 ①：「改动待生效」怎么表达 | 不给稍后、不用黑块、不配读数、不做可关闭提示——按钮即状态，Codex 重启后自动消失 |
| ① ④：要不要收件箱 | **不要**（产品负责人：问题已在行上就地显示与处理，收件箱是同一件事的第二处）。曾是「顶栏收件箱 + 待处理页 + 忽略」，删除；换成**就地常显 + 一次性提示**：新问题出现时右下提示一次，看过（`查看` 或关闭）即不再提示，因为页面里那一行一直显示着它。页签计数、`待处理` 筛选也不做——常驻的数字会一直催处理不了的事 |
| ① ② ④：圆角与阴影（形与层） | **圆角随尺寸（3 / 6 / 8 / 12 / 胶囊），阴影只给浮层**（产品负责人：全直角 + 黑框的弹窗「不够精致」，对照后「明显圆角的更好看」）。原「零阴影、0 圆角」让浮层只能靠黑框或大块黑与白底分开，要么像表单、要么太重；给浮层一档柔和阴影后，阴影只表示「在上面」，平铺内容仍完全平，同形同义不破 |
| ⑪：删网关连带删钥匙串密钥、本身不可逆 | **二次确认**（产品负责人真机）：曾做成延迟提交 + 撤销，但删后弹一条带 ✓ 的「删掉 X · 撤销」读成删成功了、还把连接摘要往下推；密钥删了找不回，属于不可逆，按 ⑪ 本就该确认；网关一两家、低频，确认一次不费事 |
| ⑪ ② 对 ⑬：可撤销的删除用黑条撤销还是确认 | **删用户内容一律先确认、不再延迟提交 + 撤销**（产品负责人：删后弹黑色大条「删掉 X · 撤销」突兀，又读成删成功了；既然要打断一次，不如确认）：删网关、只留这份确认；添加页替换以显式选择为确认。黑块只剩「需要停下来看」的失败；所有成功（含自动规则在背后做的事）用例行一行。延迟提交机制随之删除 |
| ① 就近：待重启提示锚在哪 | 触发有两个（开关、改模型），锚在它们共同的对象——agent 名字下 |
| ① 逐行就近 对 ⑤ 固定动作列 | 多行列表的动作成一列（句子列定宽、动作列紧随），不逐行贴句尾 |
| 产品负责人第 1 轮「待处理栏贴底」 对 ① ④ ② | 本轮推翻，删除贴底待处理窗：它的「就地带动作」已搬进表格行，只剩导航；它和顶栏收件箱是同一信息却放在对角两端（④ 同一信息两种形态、① 远离问题本身），又是页面上最重、信息最少的元素（②） |
| ⑥ 视觉优先 对 ⑤ 惯例：规则开关 | 须带文字限定「以后新出现的」——不带会被读成「一键开关整组」，误判代价高时文字必要（⑥）；与添加页「以后新出现的也加」同一措辞（④） |
| ⑥ 视觉优先 对 ⑤ 惯例：同名怎么标 | 自创括线「[」没有足够理由，改用惯例 `×2`；动作「只留这份」按用户在想的事命名 |
| ① 就近 对 ① 不遮挡：格子提示框放哪 | 只保护正在操作的格与行，其余允许暂时遮挡——紧贴光标、移开即消失，比放到 170px 外更尊重注意力 |
| ⑤：「本体」一词 | 已改为用户语言「原件」（产品负责人定）；代码标识符（`own` 等）不动 |
| ① 对 ⑤⑧：同一功能放几个入口 | **信息只说一次（①）；功能可以有多个入口**——入口长在用户自然产生这个念头的地方（⑤⑧），各入口同组件、同状态、同行为（④ 是多入口的前提，不是反对它的理由）。产品负责人：「同样一个功能可以在两个地方有，只要用户不觉得奇怪；只放在一个地方，用户反而奇怪。」据此：多入口的前提是每个入口都长在念头产生处——自动添加规则的念头产生在添加页挑来源时，主视图不是，所以规则只在添加页（见下一行）；选模型在模型下拉与网关页（首次在网关页，以后在下拉）；重启生效在模型页与托盘 |
| ⑦ ① ④：网关放在什么容器里（最终裁决） | **二级页**。演变：独立页 → 抽屉 → 行内展开 → 二级页。抽屉是弹层，违反「弹层只用于确认」；行内展开在多个 agent 时一展开就把下面每行推下去一大截、收起又弹回，布局跳变违反 ⑦——就地展开只适用于几行的小配置；网关是多段带列表的完整任务，走二级页骨架（④⑤）。最早那版网关页的三个问题这次解决：转场（推入 / 滑回，⑦）、无常驻右栏（单列，①）、模型两处都能选且同一份状态（⑦⑧④） |
| ⑦ ⑬ ⑤ 对 ①：来源用分组还是「原件位置」列 | **恢复列、取消分组**（产品负责人确认）：位置信息常驻视线，认出而非回忆（⑦）；同名两行一眼看出在哪两个目录；控制感（⑬）；文件类工具惯例（⑤）。第 1 / 3 轮「删列改分组」只算了逐行重复的成本（①），没算位置离开视线的成本。分组 + 列会逐行重复，所以换结构而不是叠加；按位置筛选用工具行的筛选片 |
| ④⑥⑧ 对 ⑤：自动添加规则的主视图入口 | **只在添加页**。演变：组头开关 → 列头下拉（随恢复原件位置列）→ 仅添加页。列头下拉那版把导航（筛选）和配置（规则）塞进一个外观像筛选的控件（④⑥），`▾` 被读成排序、`→` 在同一处有三种意思；规则的念头产生在添加页挑来源时，主视图不是念头产生处，多入口准则的前提不成立；规则低频（⑧），一处管好。规则在后台做事时的提示条保留（⑨⑬） |

## 材料与工艺

**总约束（产品负责人原话）：「依然服务于功能，易用，给人惊喜又符合直觉，剔除不增加价值的任何元素。」** 每个元素都过一道检验：**拿掉它，用户会少知道什么、或少能做什么？答不上来就删。** 每个交互先满足惯例（开关像开关、链接像链接、可点的看得出可点、不可点的不像可点），再在手感和响应上超预期。惊喜放在**行为**上——点格时指示灯即时点亮（乐观更新）、失败时弹回并由黑窗说明原因、撤销一键复原、停转的阻尼——不是多一个图形。任何需要用户学习的新图形语言都算缺陷，除非它换来明确的效率。

**TP-7 的极简不是少画，是：两种材料的大块对比、一个会动的主角、极小而精确的刻字、每个控件都有行程。** 翻译成界面，不拟物——没有金属渐变、螺丝、内阴影、发光灯、橙色点缀。

### 两种材料

| 材料 | 是什么 | 给谁 |
|---|---|---|
| **白面板**（`canvas`） | 放内容、放数据的面 | 表格、表单、列表、对话框的板 |
| **实心黑体块**（`ink`） | 机器在跟你说话的显示窗 | **提示条、错误横幅**（功能理由：「机器对你说话」与「你的数据」用材质分开，一眼可辨、显著性够）；主动作键；删原件弹窗的路径「铭牌」（路径是这次决定里最关键的信息，给它最高显著性） |

**实心黑只有两种意思，不再加新义**：黑色体块＝机器在说话（显示窗、铭牌、提示框）；黑色小键＝已按下或已选中（主动作、点亮的键、选中片、刚变化的格子闪一下）。靠形状分得开。

黑是体块，不是墨水。黑面上的字：主 `canvas`，次 `ink-faint`；黑面上的分隔线 `ink-mute` 1px；黑面上的按钮是 **白描边键**（1px `canvas` 描边、`canvas` 字，2px 圆角）。

- **侧栏是白的**（产品负责人看定调稿后裁定：「黑侧边栏不如白的舒服」）。实心黑只给显示窗、路径铭牌、主动作键与点亮的键。
- **提示条 = 显示窗**：`ink` 实心板，`layer` 8px 圆角，无外框，浮层阴影 `tip`，宽 ≤ 400。左侧 40×全高**指示窗**（右边 1px `ink-mute` 竖线）放 16px 状态记号（✓ / ⊘ / !，`canvas` 线稿）。主行 = **一个动词（600）+ agent 图标 + 名字（400）**：`清除 [Cursor] defuddle`、`写进 [Codex] excalidraw、notion`、`开启 [CC][Codex][C] obsidian-cli`。**动词不能省**——文字只负责名字和动词，提示条 6 秒就消失，动词放 title 等于没有（第 5 轮评审：`✓ [Cursor] defuddle` 读起来和「开启了」一模一样）。名字至多两个，超过写 `+5`（等宽 15/500）；做不成必须带一句能行动的原因（可加副行路径），**动词带否定**：`没开启 [Codex] defuddle · 已有同名`——失败态里写「开启」会被一眼读成已加上。右侧 `撤销` 白描边紧凑键 + `×`。
- **没有收件箱、待处理页和「忽略」**（产品负责人：问题都在行上显示了，收件箱没有存在的必要）。问题只在两处出现：
  1. **就地常显**：在它发生的那一行、那一格上一直看得见，并且就在那里处理，见下表。
  2. **新问题提示一次**：每次扫描后（启动、文件变化重扫、模型状态刷新），如果有**还没提示过**的问题，右下出一个黑显示窗（需要注意，⑪ 的黑块）：一条时 `! defuddle 有两份 · 查看`，多条时 `! 发现 3 处要你拿主意 · 查看`，带 `×`。**不自动消失**。点 `查看`：切到第一条所在的页签（和侧栏位置），滚到那一行并让它闪两下（`surface` 行带亮灭各 240ms，整列的问题闪列头；不用黑）。点 `查看` 或 `×` 都把这次提示里的问题记为**看过**，以后不再提示——页面里那一行一直显示着它。没点就退出了应用，下次打开再提示。已有提示显示时又发现新问题，合进同一个窗（改计数），不叠第二个。
  - **看过记的是这一条具体状况**：key 与原「忽略」同一公式（类别 + 涉及位置排序后拼接，`tests/issue-key-contract.test.ts` 与 `store.rs` 两边钉死），位置一变就是新问题，会再提示一次。记录存 core（原忽略表改作「看过」表）；模型类问题同样存 core，不再用本机 localStorage。
  - **写不进**不进一次性提示：它只由写入失败当场产生，当场已经报过。
  - 顶栏只剩设置图标；页签上不加计数。

### 提示与反馈锚在触发它的控件上（① 硬规则）

**提示与反馈的锚点 = 触发它的控件；间距 ≤ 16px（1x）；只保护触发控件与其所在行不被遮挡。** 逐张测量后的落实：

- **自动添加规则只在添加页管理**（「以后新出现的也加」开关）；添加页来源列表里，开了规则的来源在名字后加小字 `自动`（`ink-mute` 12，不加框；「以后新出现的会自动开启」画不出来，用字，不用箭头——箭头已有排序义），提示框补充目标「以后新出现的会自动加到 Claude Code · Codex」（同行放不下时可省略）。主视图不放规则入口（见冲突表）。开关提示框「只管以后新出现的，现有的不变」。
- 批量提示条：左对齐到**被按下的那颗键**，超出面板右沿时右对齐到该键右沿。
- 行内动作跟在描述后面（网关「再试一次」紧跟「连不上」8px）。**列表里多行各有动作时，动作成一列**：句子列宽取最长一句的实际宽度（不为假想长句预留，超出换行），行线止于动作列右沿 + 24，动作列紧随其后、固定起点（离句子列右沿 16）——既就近又对齐，扫一列决定时眼睛不用逐行找键（⑤ 惯例压过逐行贴句尾）。
- 模型页 / 托盘：`名字 + 开关 + 配置网关` 一组。
- 添加页：`以后新出现的也加` 开关离目标键组 16。
- 筛选无结果：筛选框内 ✕ 清除（8px 内），空态按钮只是次要入口。
- 明确的跳转（贴底窗 `›`）、页面级提交（`添加 N 个`）、主从布局（网关「改」→ 右栏表单）不受 16px 限制。 开关、它控制的对象、它引起的提示三者落在同一处（模型页：agent 名 + 开关成组，待重启黑窗挂在名字格下方）。第 8 轮曾把格子提示框挪到面板外 170px，是用具体准则「不盖任何数据点」压过了它服务的原则「就近出现」——没有向上裁决，已撤回。

- **列头悬停**：整列出列带（与格子十字带同一语言），提示框 `Claude Code · 41 个已加上`。


### 格子悬停光晕（⑥ 外观说明如何操作）

核心操作「点格开关」必须看得出能点，但**悬停时点本身一点不变**（产品负责人真机：点的颜色或填充一变，就被读成已经点了——先是 ● 预览成空环、后改 40% 浓度仍被读成点过）。悬停只在点后面出一圈**圆形光晕**（直径 22，`--hairline` 实底，在点的下层——行带和列带本身是 `surface`，同色的光晕压在交叉处会完全看不见），和图标按钮悬停出浅灰底是同一个惯例：「你在这上面、它能点」，不预告结果。结果由提示框的动词说（`加到 Claude Code · 空格`），按下后点才变。键盘焦点同样出光晕，外加焦点环。原件格、无此格、异常格悬停时不出光晕（它们点了不是开关），`cursor: default`，由提示框说明；可点的格 `cursor: pointer`。

### 提示框（⑥ 文字提供确定性）

原生 `title` 是系统灰底小框、约 1 秒延迟、位置不受控、无法排版——**不再作为唯一说明**，只作 aria 兜底。提示框是组件：

- **材质**：黑窗，白字 12/400，重点词 600；`control` 6px 圆角；浮层阴影 `tip`；无箭头；内边距 6 8；最大宽 240，超出换行。
- **内容**：表格格子只一行 = **动词 + 快捷键**：`加到 Claude Code · 空格` / `从 Claude Code 移除 · 空格`——agent 由列头与列带说明、能点由悬停光晕表示。表格外元素：一行「是什么」+ 可选一行「按下会怎样」+ 可选快捷键（等宽 12 `ink-faint`，右对齐）。例：禁用键 `Claude Code · User` / `已选的都定义在这里`；待处理记号 `同名：有两份`。
- **位置**（① 就近）：**锚点是触发它的控件，间距 ≤ 16px**。**列表行（模型勾选列表、添加页列表、下拉里的行）的提示框放在该行同一行的右侧空白处**（行尾对齐、不越出列表框），不放到上一行——放到上一行会被读成上一行的信息；表格格子仍按「正上方 6」。只保护触发控件与它所在的行：列头标签被暂时盖住可以接受（模型页重启提示框右对齐、盖住 `agent` 列头——用户正停在这一行上，此刻最不需要列头）。格子：正上方 6px、水平居中于格子；**允许暂时盖住上一行的邻格，只保护悬停的那一格和它所在的那一行**；首行放不下时放格子正下方。表格外元素（按钮、标签）：上方 6px、水平居中，居中会出窗时对齐外侧边，上方放不下才放下方。
- **可悬停但不可点的触发点用点状下划线**（1px dotted `ink-faint`，同 abbr 惯例）：`同名`、`2 份不一样`、`Codex 不支持`。实线下划线只属于文字链（可点）。
- **时机**：表格内停留 **700ms** 才出现，在格与格之间移动时不出现、不追着鼠标（追着走是噪音）；键盘焦点到达后 700ms 出现。表格外的按钮 / 标签 400ms。移开立即消失。
- **点了做不了的格子，立刻说明**（⑨ 按下是决定，回应要明确）：原件、写不进、同名被挡、整个文件夹是链接这几种格子点下去（或空格）不改任何东西，但**当即弹出这一格的提示框**（不等 700ms），停留约 3 秒或移开即消；内容说为什么 + 去哪做，如原件格「这就是原件，不需要链接 · 要从 Claude Code 移除，只能删掉原件」。只靠悬停出说明，点击会被读成没反应。
- **与悬停光晕配合**：光晕说「能点」，提示框说「点了会怎样」，同时出现。
- **可访问性**：内容同时作 `aria-describedby`，不依赖悬停。
- **按钮与文字链不用单字**（⑤）：`改` 读起来像半句话，写惯例两字 `编辑`（与 `保存 / 取消` 配对）；`配置` 留给首次设置（`配置网关`）。图标键以提示框文字计。
- **动作链不折行**：`打开 ↗` `只留这份` `再试一次` 这类文字链整体一行；空间不够时截断旁边的标识文本（完整值进提示框），或按实际最长值定列宽。
- **路径一律把用户主目录写成 `~`**（`~/.agents/skills/defuddle`），提示框、展开区、铭牌同一写法。
- **承载后果或安全信息的文字一律不截断**（⑥）：限制说明、替换 / 删除的后果、安全提示先缩文案，仍放不下就折行，不用 `text-overflow: ellipsis`——被截掉的往往正是关键那半句（第三方模型「不支持图片」、替换说明）。可以截断的只有名字与路径这类可在提示框里看全的标识，且提示框必须给出全文。

### 键盘（⑧ 熟练用户的快捷路径）

`⌘F` 筛选、方向键在格间移动、空格切换当前格、`⌘Z` 撤销、`⌘A` 全选当前组、`Esc` 取消选择 / 关浮层。键盘焦点在格子上时：1px `ink` 焦点环在格上（偏移 2），十字带跟随焦点。快捷键写进对应控件的提示框，不给新手增加负担。

### 自动发生的事要交代（⑨⑬）

规则在背后建了链接时：出例行一行提示条 `✓ 自动加到 [Codex] 3 个 · 撤销`（右下，白底无框——加链接无害、可逆，不必用黑块抢注意），格子直接变成新状态（不闪、不依次）；添加页该来源的规则记号提示框可看最近一次自动操作（`2 分钟前 · 开启 3 个`）。

### 提示条分两档（① 严重程度决定打断程度；② 处处强调等于没有强调）

黑块只表示「这里需要你注意」：

| 档 | 形 | 给谁 |
|---|---|---|
| **需要注意** | 黑显示窗 | **只给要停下来看的事**：错误横幅、部分失败、做不成、单格失败原因、悬停提示框（小、短，深色提示框是惯例）。成功一律不用黑块 |
| **例行成功** | 一行文字：`✓ 写进 [Codex] excalidraw、notion · 撤销`，墨色字直接落在白底上，无框无底，贴触发控件；`撤销` 是文字链 | 所有成功：写进 / 加上 / 移除 / 清除 / 拆开、自动规则在背后做的事、确认过的删除的结果（无撤销）——结果已由格子闪烁表达，这行只提供撤销入口或交代一声 |

### 提示条的位置（① 就近）

- **单格操作出例行一行，不带撤销**：点格子加上 / 移除（skill 的 `加到` / `从 … 移除`）成功后，格子照旧闪一下（120ms 反色），同时出一行 `✓ 加到 [Codex]`。**不给 `撤销`**（产品负责人：再点一下就恢复了）——格子本身就是开关，撤销入口就在光标底下，再放一个文字链是重复（④）。`⌘Z` 照旧可用。造句与批量共用 `toastFor`，组件同一个 `Toast tier="routine"`。
  - **例外：MCP 单格写进保留 `撤销`**：MCP 格写进之后，再点那一格不能移除（只增不删），格子替代不了撤销，所以这一行仍是 `✓ 写进 [图标] · 撤销`，并保留悬停不计时。
  - **位置：就在被点的那一行里，紧跟名字**（有 `×2` 就跟在 `×2` 后，间距 12）。这一行已经说明了对象，所以只写 `✓ 加到 [Codex]`，不重复 skill 名；列由格子闪烁和图标指明。名字太长放不下时，可以暂时盖住同一行的原件位置格（用该行当下的底色），不越过第一个 agent 列。这一行显示期间，行上的悬停动作（`只留这份` `打开 ↗`）先让位，淡出后恢复。（曾放在列头行左段：离被点的格子太远，产品负责人真机「从这里出来非常奇怪」，滚动后还会压住列头文字。）
  - **一次只一条**：连点几格时新的一句替换旧的，不排队。`⌘Z` 只撤最新那一次操作（一级撤销，与批量一致）。
  - **约 4 秒后淡出**（比批量的 6 秒短：单格高频，结果格子本身已经画出来）。
  - **失败不变**：格子弹回，格子下方就近出一个小黑窗说原因；这时不出例行一行。
- **批量操作**：提示条是单行（高 32）、内容宽，贴在**被按下的那颗键**正下方 4px，**右对齐该键右沿、向左展开**——不盖住被按下的键所对应那一列的列头（用户按完正要确认是哪一列变了），可以暂时盖住其他列头；被改动的格子同时闪一下，键上的读数随之翻转（`○ Cursor +2` → `● Cursor −2`）。提示条的动词必须和按下的键一致（按 `−2` 是移除、按 `+2` 是写进）。
- **无关位置的全局事**（自动规则、后台失败）：右下，右沿对齐面板右沿。

### 视觉优先：文字只负责名字和动词

**状态、关系、后果、进度、位置，一律画出来；文字只负责名字和动词。**（产品负责人：「尽量通过视觉就能理解操作，而不是文字」。）不是把按钮都换成图标——认不出的图标比文字更糟，图标词表之外的动作继续写字。要换掉的是「用句子描述一个本可以看见的东西」。底线：**每个新图形在设计资产板有图例、悬停 `title` 给出文字、屏幕阅读器文本不减**。

### 一种数字

**计数一律等宽（IBM Plex Mono）、tabular；不写别处已有的分母**（列头只写 `41`，不写 `41/56`——56 已在「全部 56」上）——功能理由：计数在片与列头里上下对齐、变化时不抖。**不零填充**（`026` 更难读，是装饰）。等宽只给数字、路径、ID——正文不换等宽。

### 刻字

- 区块小标（`位置` `来源` `已连的网关`）：12，拉丁 Condensed 大写 +0.96px / 汉字 600 字距 0，`ink-mute`（黑面上 `ink-faint`），**贴区块 2px 结构线下沿 6px**。
- **只删重复控件已表达的句子**；机器信息（路径、大小、条数）写成等宽读数而不是散句。

### 表格 = 面板

- **通道条表头**：每个 agent 列头三层——16px 图标 / Condensed 大写名字 / 等宽计数 `41`（`ink-faint`，这个 agent 下开着几个——真实信息）；下面是 2px 结构线。
- **面板要紧凑、有四条边**：`名称` 列定宽 280，`原件位置` 120 紧随，agent 列各 88；**所有横线、悬停带止于最后一个 agent 列右沿 + 24**，工具行的 `+ skill` 右对齐到同一条边——右侧留白是真正的留白，不是空列。agent 多到放不下时面板才长到窗口宽、横向滚动。**悬停内容不越过面板右沿**。同名两行名字后写 `×2`：悬停任一行两行同亮；判断用读数（`改于 9月20日 · 3 个文件`）与 `只留这份` 写在各自行的名称格里，放不下时改在 `×2` 的提示框里同时列两份读数（`这份 改于 9月20日 · 3 个文件` / `WeiboAP 那份 改于 8月30日 · 2 个文件`），`只留这份` 留在名称格。
- **行高 34**（原 40）：一屏多看几行是功能；整格仍是命中区。
- **悬停十字带**：悬停一格时，这一行和这一列同时出 `surface` 带——宽表格里读「这个点属于哪个 agent」的真实辅助。
- **指示灯**：三种外径一致 **10px**，中心对准列头中线：已加上＝10 实心；未加上＝10 外径 1.5px 环 `ink`；原件＝10 外径 1.5px 环 + 4px 实心芯；无此格＝8×1.5 短横 `ink-faint`。

### 忙碌指示：只在用户等的地方，带文字

- **后台例行读取不显示任何忙碌**：页面刷新、文件监听重扫、网关轮询——用户没有在等，出现转动只会被读成出了问题（①）。**顶栏没有全局忙碌指示。**
- **用户发起、正在等的操作，就地显示并带文字**（⑨ 回应强度与意图相称）：首次扫描「正在读 3 个位置」（内容区居中）、批量写入超过约 500ms 时触发项旁的转动指示 +「正在加到 Codex」、重启键原位「正在重启 Codex」、网关保存时按钮原位「正在拉模型」。指示器说在忙，文字说忙什么；没有文字的转动不允许。
- **指示器是「地球绕太阳」**（产品负责人选定）：中心一颗实心太阳（`ink`，约占直径 40%），一颗小地球（`ink`）沿看不见的圆轨道匀速转，1 圈 / 1.2s 线性；尺寸 14（行内、按钮内：太阳 5.5、地球 2.5）/ 24（内容区居中：太阳 9、地球 4）。**不画轨道线**——环 + 中心点是原件记号 ⦿，画轨道会撞形（④）；太阳大、地球小，运动本身让它读成「在转」（⑤）。轨道＝周期＝时间，等待就是等时间过去（①）。完成即消失，不做停转动画。
- `prefers-reduced-motion` 下地球停在 12 点钟方向，文字后跟 `…` 每 500ms 增减一点。
- busy 期间受影响控件的处理见「空态与忙碌态」。

### 控件有行程

| 控件 | rest | hover | pressed | focus |
|---|---|---|---|---|
| 主动作键（实心黑） | `ink` 底 | 键面内缩 1px 的 `canvas` 内描边（键帽边缘反光） | **下移 1px 且高度压扁 1px**，像键帽被压下 | 外 2px 处 1px `ink` 环 |
| 默认键（描边） | 1px `ink` 描边 | `surface` 底 | `surface` 底 + 下移 1px | 同上 |
| 开关 | 见下 | 轨外缘 1px `ink-mute` | 旋钮压扁 1px | 同上 |
| 复选框 | 12 方 | 描边转 `ink` | `surface` 底 | 同上 |

- **紧凑开关 24×14**（旋钮 8）给行内的规则状态——添加页的「以后新出现的也加」。它是一条规则的状态，不是本页主角；标准 32×18 只给页面级开关（模型页启用）。
- **开关保持一眼认得出是开关的形态**（胶囊轨 32×18 + 圆旋钮 12，符合直觉优先于像拨杆）；机械感只做在行程和停靠上：切换 120ms、末端 1px 过冲回弹，按下时旋钮压扁 1px。
- 所有状态变化 80–120ms 机械式缓动（`cubic-bezier(.2,.8,.2,1)`），不要弹性果冻，不要 300ms 淡入淡出。

### 别做

拟物（拉丝、螺丝、内阴影、发光 LED、有彩色点缀）；装饰性编号「01」「02」；装饰性网格线、对位刻度、满屏十字准星；数字零填充；对话框装饰边；为了「科技感」把正文换等宽；为了「机械感」把开关换成要想一下的造型。

## Colors

**整个界面零色彩。** 七个**中性**灰阶（R=G=B），没有任何有彩色的值。第一版灰阶照搬 SpaceX 的偏蓝灰（`#f0f0fa` `#e0e0e8`…），评审指出那是「零色彩」里唯一的色相——要么承认它，要么换中性。换了。规范规定色彩全部来自照片，工具里没有照片，所以一个色都不用。

强调只有三种手段，按强度递增：**次要文字（`ink-mute`）→ 加粗 → 反色（`ink` 底 `canvas` 字）**。红色不是其中之一。

**破坏性操作靠信息和文案承担分量，不靠颜色。** 删除弹窗给出完整路径、目录大小、受影响的链接数、git 状态；按钮写「删到废纸篓」而不是「确定」——用户读完就知道会发生什么，再涂红就是吓唬人。

| Token | 用途 |
|---|---|
| `canvas` | 画布 |
| `surface` | 次级面：侧栏选中、悬停、**勾选中的行**（不反色——多选列表里反色行太重） |
| `hairline` | 分隔线、选择片描边、无格态短横 |
| `ink` | 主文字、实心圆点、按钮描边 |
| `ink-mute` | 次要文字、文字链 |
| `ink-faint` | 弱文字、空心圆点描边、hover 前的排序箭头 |
| `disabled` | 禁用描边 |

## Typography

### 三个字族都没有中文字形：字距与大写只给纯拉丁

界面绝大部分文字是中文，会落到系统 CJK 字体（macOS 苹方）。Condensed 大写 + 字距是给 `SKILLS` `MCP` `CLAUDE CODE` 这种**纯拉丁标签**用的工业感；套到汉字上，「删 通用仓库 的」字字散开，「添加 SKILL 到「全局」」窄体大写挨着常宽苹方，同一行像两套系统。评审第 1 轮的最大字体问题。规则：

1. **`letter-spacing` 与 `text-transform: uppercase` 只作用于纯拉丁的 run。** 汉字一律 `letter-spacing: 0`。实现：`<Cap>` 组件按脚本把文本切成 run，只给拉丁 run 套 Condensed + 字距 + 大写；画板里等价于只给拉丁 `span` 写这些属性。lint `cjk-tracking` 查这条。
2. **按钮不走 Condensed。** 界面是中文，按钮几乎都含汉字：`button` 档 = Barlow / 苹方 13 / 600 / 字距 0 / 不大写。专名嵌进去原样写（`删 WeiboAP 的`），不再需要开洞。
3. **页面名 `display` 不大写、字距 0**：`添加 skill 到「全局」`、`Codex 的网关` 原样写。28 / 700，拉丁部分落到 Barlow Condensed，汉字落到苹方。
4. **中文句子里的拉丁词不大写**：`在以下 agent 开启` `哪些 agent 出现在列表里`——句子是内容，只有独立成词的结构标签（页签、agent 列头、模型页的 `AGENT` 列头）才 Condensed 大写。
5. **表头不混排**：我们自己写的列头一律中文（`名称` `原件位置` `传输`），走 `micro-cap` 的字号字重、字距 0。agent / 位置列头是专名，纯拉丁，走 Condensed 大写——它们自成一组（图标在上名字在下）。
6. 顶栏页签 `模型` `SKILLS` `MCP`：汉字页签字距 0，拉丁页签 Condensed 大写 + 1.17px。
7. **例外：agent 图标键跟随列头字体。** 添加页底部的 agent 键、选择条动词键里的 agent 名，和表格列头是同一个对象（agent 身份，④ 同形同义），是可切换的身份键、不是动作按钮——agent 名用 Condensed 大写，与列头一致；键里的中文动词（`开启` `关闭`）仍是按钮字。

### 层级：五档，相邻至少差一倍的视觉重量

| Token | 字号 / 行高 | 用在哪 |
|---|---|---|
| `display` | 28 / 1.1 | 二级页面名、区域大标题 |
| `wordmark` | 20 / 1.0 | 顶栏 wordmark |
| `body` | 15 / 1.6 | 表格、说明、条目名、选择片文字 |
| `button` / `caption` | 13 | 按钮（600）；副行、文字链、选择片、提示条副行 |
| `micro-cap` | 12 / **2.0** | 区域标签、列头、方标签 |
| `mono` | 12 / 1.6 | 路径与计数（嵌在 body 行里，行高跟行走，不撑 2.0） |

**五档之外有两个 `body` 档的变体，它们不是第六档**——字号行高与 `body` 完全一致，变的是字族、字重、字距与大小写：

| 变体 | 写法 | 用在哪 |
|---|---|---|
| `nav-cap` | Condensed 15 / 700 / +1.17 / 大写（只给拉丁页签） | 顶栏页签（一级导航），可点高度 32，在 56 内容区里居中，选中下划线离底 12 |
| `head-cap` | Condensed 15 / 600 / +1.1（`--track-head`） | 区域小标题、弹窗标题 |

**第一版的错**：20 / 15 / 14 / 13 / 12 五档挤在 8px 里，14 与 15、13 与 12 眼睛分不出来，整页读起来像一张密排的表。参照 `DESIGN-spacex.md`：display 到 body 是三倍以上的跳跃，小字靠**行高 2.0** 撑出呼吸感而不是靠字号。所以：页面名拉到 28；砍掉 14 这一档；12px 的标签行高 2.0（占 24px 高，与 SpaceX 的 `micro-cap` 一致）。

### 大写是结构的语言，不大写是内容的语言

大写只给**我们自己写的、纯拉丁的结构词**：页签 `SKILLS` `MCP`、agent 列头。被谈论的对象一律不大写——agent 名出现在选择片、行标题、页面名、句子里时都写 `Claude Code`。

**文件系统来的名字一律原样，不做大小写转换。** `defuddle` 转成 `DEFUDDLE` 后跟表格里的名字对不上。

**skill 名用 `body`，不用 `mono`。** 等宽的理由是路径要对齐、要分得清 `l` 与 `1`；skill 名在列表里是当词读的。`mono` 只给路径与计数。

## Layout

基准 8px，子单位 4 / 12 / 16 / 18 / 24 / 32 / **48**。

### 壳

**顶栏的 wordmark 用 `assets/logo/wordmark.svg`，不用纯文本。** 字标的首字母带和图标同样的重影——那是这个标志的识别点，写成 `<h1>Sophia</h1>` 就丢了。高度 **26px**——20px 时首字母后面那层灰影只有 1px 位移，读起来像套印错位；重影要么大到明显刻意，要么不要。产品负责人要它，所以放大（顶栏内容区 56 高放得下），`currentColor` 取色。

**字标动效：黑猫与玻璃**（产品负责人定稿，原型 claude.ai/artifact/2fcVo2BxLPdNQrrcskYAYq 第 21 版）。这是 ① 里「值得」的那一处细节：只属于字标，不延伸到别的控件（④）；平时完全静止，只由用户在字标上停留唤起（① 回应的边界）。
- **触发**：鼠标在字标上停 0.4 秒才开始，从不自动播放。开了 `prefers-reduced-motion` 时猫不出现，点击也不碎，字标保持静止。
- **猫**：一只黑猫从右边走进来，在字母间穿梭：S、P、I 在猫后面，O、H、A 在猫前面。猫身有一圈白描边，和黑字母分开。
  - 造型只用黑、白、灰，矢量绘制：大圆头、脸微侧露出一大一小两只白眼、大三角耳、细灰须子（`ink-mute`，不描白边）、灰鼻头、身子修长、腿细长配圆爪、尾巴上翘末端卷成螺旋。大小为字标高度的 0.52 倍。
  - 行为：四拍慢步，着地的脚不打滑；走到随机位置停下，约 0.35 秒后坐下；鼠标在身后时转身看你，瞳孔跟着鼠标，偶尔眨眼，停下时歪一下头；鼠标靠近会被吓到、快走几步；点到猫附近它会跳一下。
- **敲玻璃**：点击字标就是敲在玻璃上，从点击处沿放射加同心环方向裂开，裂纹逐步蔓延，并带次级裂纹。随机敲 2～4 下后字标碎开，猫受惊跑走，碎片带物理效果落到顶栏底线上。碎片沿真实裂纹切分，恰好铺满整个字标。
- **复原**：鼠标移开时——
  - 没碎：裂纹淡去；
  - 碎了：等碎片落定（最多 1.2 秒），按离敲击点的距离错开托起，用阻尼弹簧弹回原位；基本到位后，完整字标在上面约 0.8 秒渐显，裂纹愈合，全程没有突变。
- **边界**：只在顶栏字标这一处；动画只在悬停和复原期间跑，静止时不占帧。字标区不当拖窗区，否则点击会变成拖窗口。画布对读屏隐藏，`alt="Sophia"` 照旧。原型里的慢放开关、状态读数和说明文字只是演示，不进产品。

**窗口标题栏不显示产品名**（macOS：`titleBarStyle: Overlay` + `hiddenTitle`）。顶栏自己已经有 wordmark，系统标题栏再写一遍 "Sophia" 是重复。

红绿灯浮在窗口左上角那 28px 里——**那一排留空**，只当拖动区；字标与页签在它下面的 56px 里。第一版把字标和红绿灯挤在同一排，用户反馈"太靠上"。顶栏总高 84 = 28 空 + 56 内容，整条可拖动窗口。**二级页面的头同一条规矩**（它是 `position: fixed` 盖满整窗的）。

**侧栏底部 `+ 项目`**：默认按钮（见「添加只有两种长相」），不带省略号。第一版是带省略号的胶囊，"和其他的格格不入"；第二版降成灰色文字链，评审指出独立的创建动作权重过低。

## Elevation & Depth

**渐变只用于功能，不做装饰**（产品负责人放开渐变；装饰性渐变——按钮、面板、背景底色——仍属拟物，不用）：可滚动区域被裁掉的边缘 16px 渐隐（表格横向放不下、长列表），提示那边还有内容；内容图像（首次扫描的地平线）。**阴影只有一个意思：这层浮在页面上面**（④ 同形同义）——只给浮层：弹窗、下拉 / 选择器浮层、提示框、提示条。两档：`layer`（一圈 8% 墨描边 + 12/32 柔和投影 + 2/6 近投影，弹窗、下拉）、`tip`（4/12 投影，提示框、黑色提示条）。**平铺的内容一律无阴影**：表格、列表、表单、按钮、片、面板。阴影是唯一允许出现 `rgba()` 的地方，只能取这两个 token。

确认弹窗的背景罩是 **黑 18% 遮罩、触发行在罩上**（见「材料与工艺 › 对话框」）。

## Shapes

**形状承担语义，四种形各管一件事**：

| 形 | 值 | 给谁 | 语义 |
|---|---|---|---|
| 描边矩形 | `control` 6px | 动作按钮、输入框、图标按钮的悬停底、提示框、行悬停底 | **点了会执行一个动作 / 在这儿输入** |
| 浮层 | `layer` 8px / `dialog` 12px | 下拉与选择器浮层、列表框（模型勾选列表）、提示条 8；弹窗 12 | 浮在上面的一块（配浮层阴影） |
| 胶囊 | `pill` 32px | 来源筛选片、分段片（网关页）、模型片、开关轨道 | **一个可切换 / 可移除的状态** |
| 圆 | `dot` 50% | 状态点、开关旋钮 | 只读状态 |
| 小方 | `mark` 3px | 复选框、首字母方块 | 记号 |
| 直角 | `none` 0 | 表格、横幅、分隔线、黑色体块（选中行反色等） | 平铺的结构，不是一块 |

**圆角随尺寸变大**（产品负责人：原来全直角「不够精致」）：记号 3 → 控件 6 → 浮层 8 → 弹窗 12，比例一致才和谐；不在这张表里的值不用。

第一版「pill＝可点」把动作按钮、筛选片、添加项目、设置页 agent 片全做成 32px 胶囊，评审指出"会执行动作"与"已选状态"形状不可分、胶囊泛滥。现在：**胶囊只留给片**，动作一律 2px 矩形。**有框的都能点。** 不可点的标识（`同名` `2 份不一样` `连不上` `已添加`）是**没有框的 12px 文字**：强的 `ink` 600，弱的 `ink-faint` 400。第 2 轮评审指出，靠 0 圆角对 2px 圆角区分「标签」和「按钮」不成立——1px 黑框的 `同名` 和行内按钮 `清除` 肉眼不可分。

## Components

### 按钮

2px 描边矩形，高 28（行内、提示条、选择操作条里 24），`button` 档文字。三个变体加一个禁用：

| 变体 | 形 | 给谁 |
|---|---|---|
| 主动作 `button-primary` | `ink` 底 `canvas` 字 | 一个面里**至多一个**：确认弹窗的主动作、添加页的 `添加 N 个`、表单的 `保存` |
| 默认 `button` | `ink` 描边、透明底 | 其余动作：`重启` `配置网关` `清除` `拆开` `删 WeiboAP 的` |
| 文字链 `button-link` | 13 `ink-mute` 下划线；**命中区高 24、左右各 6**（视觉不变） | 退路与次级：`取消` `撤销` `稍后` `取消选择` `显示未安装的 32 个` |
| 禁用 | `disabled` 描边与文字 | **必须同时给 `title` 说明原因**，类型上强制 |

**同一行里的控件同高。** 工具行与选择操作条是 28 的一行：输入框、动词键、图标按钮、按钮全是 28。表格行、提示条、行内待办条是 24 的一行：按钮 24、模型片 24。胶囊片和矩形按钮并排时靠形状区分，不靠高度差。

**文字链有两种，长得不一样。** 应用内的次级动作（`取消` `撤销` `稍后` `添加项目`）：13 `ink-mute` 下划线。**离开 Sophia 的链接**（`打开目录` 去访达、`检查更新` 去网页）：同样的字，末尾跟一个 10px 的 `↗` 线性箭头（1.4 描边，`ink-mute`，左间距 3）。旧规范写「离开 App 是唯一可以用文字链的地方」，这一轮把次级动作也降成了文字链，所以要靠 `↗` 把两种分开。

**没有 hairline 描边的按钮。** 线上画布一度有一档 `#e0e0e8` 描边的「次级按钮」，评审指出它比旁边的开关弱一档、读起来像禁用态。次级就是文字链，不再有第三种描边。

**按钮里的专名不靠空格断词**：`删通用仓库的`、`删 WeiboAP 的`（中西文之间一个普通空格是排版惯例，汉字之间不加）。

**按钮上只写动词，不写宾语。** 宾语是它所在的那一行：Codex 行上写 `重启`。宾语只在按钮离开了它的对象、或单一个动词说不清去哪时才回来——空态 `添加 skill`、`配置网关`、`添加网关`。

**能画出来的动作不写字**，见「图标」词表。

### 图标按钮 `button-icon`

16px 图形、**1.4 描边**、**28×28** 命中区（与按钮同高）、无描边无底、悬停 `surface` 底 `control` 6px 圆角。**必须带 `title`**（同时是 `aria-label`）。顶栏的待处理入口与设置齿轮是同一个组件、同一个尺寸；待处理数用 `mono` 12 跟在图标右侧 4px。

### 开关 `Switch`

**一个当场生效的布尔状态，对象就是它所在的那一行**，用开关，不用「启用 / 已启用」两态按钮。轨道 32×18 pill、旋钮 12px 圆：关＝白底 ink 描边、旋钮 ink 在左；开＝ink 底、旋钮 canvas 在右。零色彩，无过渡以外的动效（120ms 位移）。**开关旁边不写「已启用」**——它自己就是状态。

用在哪：模型卡的启用、自动同步 / 自动添加那一行、添加页顶部的「新出现的自动添加」规则。**不用在哪**：选择（那是 12px 方形复选框——方＝我选的，开关＝它开着）、需要一次提交的多输入。

开关都不需要确认：曾经「开启自动同步」要确认一道，是因为它会把来源里现有的几十个一次建完；现在规则只管以后新出现的，规模问题没了。

曾经的 Don't 写「不用滑动开关（iOS 语言，必带圆角）」，作废：胶囊在这套系统里是「一个可切换的状态」，开关正好落在这个语义上。

### 状态与动效

| 项 | 取值 |
|---|---|
| 可点元素高度 | `--control-h: 28px` / `--control-h-compact: 24px`，**一律偶数**——奇数高会让 pill 端帽只有 75% 覆盖，同一圈描边一半实一半虚，读起来就是「锯齿」 |
| 命中区下限 | `--hit-min: 24px` |
| 焦点 | 只认 `:focus-visible`：1px `ink` 外框、偏移 2px；反色面上转 `canvas`。**不要系统默认的蓝色焦点环**——那是零色彩界面里唯一闯进来的彩色 |
| 过渡 | 只有一档 `--motion-fast: 120ms`，且 `prefers-reduced-motion` 下全部关掉 |
| 数字 | `font-variant-numeric: tabular-nums`，计数跳动时不抖 |
| 字形渲染 | `-webkit-font-smoothing: antialiased`，关掉 macOS 次像素渲染的彩边（零色彩系统里它是真能看出来的） |

### 选择片 `Chip`

胶囊，高 28，文字 `caption` 13（不大写，内容是专名），计数 `mono` 12。未选中 hairline 描边，选中**反色**，不可选灰描边灰字。图标 14px 在左，间距 6px。用在：主视图工具行第二行的来源筛选片、网关页的分段。选择操作条是动词键（见「选择操作条」），不是片。**不用来选「哪些 agent」这类设置**——那是复选框列表（见「设置页」）。

### 状态点 `StateDot`

格回答两件事：**填充＝这个 agent 能不能用它，外环＝它在这儿是原件还是一条软链。**

| 状态 | 形 |
|---|---|
| `linked` 已加上 · 软链 | 9px 实心 |
| `missing` 未加上 | 9px 空心 `ink-faint` |
| `own` 已加上 · 原件 | 13px 外环 + 6px 内实心 |
| 无格 | 8px `hairline` 短横，不可点 |

**前三行是状态，第四行不是**：「无格」说的是这儿根本没有这一格，不是某种状态。常驻的状态只有那三种。异常态（链接失效、指向别处、同名被占、整个文件夹是链接、写不进去）**画成空心**，但点击行为与文案分叉——由提示条说原因，需要拿主意的进待处理栏。

勾选中的行用 `surface` 底，圆点不变色。空心圈描边 `ink-faint` 1.4px（第一版用 `disabled`，白底上过淡）；「无格」短横 8×1.4px `ink-faint`（第一版用 `hairline`，融进了行分隔线）；原件点 13px 外环 + **6px** 内芯。

### 矩阵列头

**16px 图标在上、名字 `micro-cap` 在下，堆叠。** 列宽约 84px。

**列头没有灯。** 曾经在图标右上角放一盏 6px 的灯表示目录状态，用户看不懂。目录不存在这件事在点击那一刻由提示条说（「已经建出来」），写不进去的进待处理栏——列头不需要再说一遍。

### 图标

所有图标同一套画法：16px 画布、`currentColor`、1.4 描边。**设置的入口必须是有齿圈的齿轮**——第一版画成圆心加八根放射线，那是太阳，用户看成了「切换日间模式」。看不懂的图标比没有图标更糟，这条和列头灯是同一课。

**词表——只有这几个动作有图标，别的一律写字**：

| 动作 | 图形 | `title` |
|---|---|---|
| 设置 | 8 齿齿轮 | `设置` |
| 编辑 | 铅笔（45° 斜置） | `编辑` |
| 删掉 | 垃圾桶（带盖） | `删掉` |
| 添加 | `+` | `添加网关` 这类带宾语的全名 |
| 关掉 / 移除一片 | `×` | `关掉` |
| 返回 | `←` | `返回` |
| 搜索 | 放大镜（输入框内） | — |

判据：**离开这个界面，用户在别的软件里见过同一个图形做同一件事**。「重启」没有这样的图形（循环箭头是"刷新"），「拆开」「再试一次」更没有——这些写字。

### agent 图标 `AgentMark`

单色 inline SVG，`currentColor` 取色。**不用品牌色。** **Codex 用 OpenAI 绳结标志**（识别特征：中心六边形空洞 + 六段逐段旋转 60° 的交织弯折）：第一版六瓣软轮廓在 16px 下读成云 / 齿轮，认不出比没有更糟，又不能退回首字母（「C」已给 Cline）。取官方 SVG 转单色；16px 糊时宁少一层交织，保住中心六边形与外轮廓六个圆角。所有出现处走同一个定义。 光学补偿：Claude Code 的星形是放射实线，同尺寸下比其他线性图标重——描边降到 1.2、视觉尺寸比其他小 1px。 实现时用各项目官方 SVG 转单色路径，不手画。取不到的用**首字母方块**（14px，hairline 描边、`ink` 字母；未启用时字母随名字退到 `ink-faint`）——它是图标缺席时的占位，**永远和名字一起出现**：已安装的 9 个里首字母就撞了 3 个 C、2 个 G。

### 选择操作条

勾选一个以上 skill 后，**工具行第一行**（选择条顶替筛选框与 `+ skill`）：`已选 3 个` + `所有 agent` + 每个 agent 一项 + `取消选择`（文字链）。第二行来源筛选片保留。

- **每一项 = 状态点 + 名字**：`● Claude Code` `○ Codex`，**与格子同一套圆点语言**（④，产品负责人）：● 实心＝选中的在这个 agent 里全都有，○ 空心＝否则（一个没有或只有部分——点下去效果相同，逐行谁有谁没有由格子画出）。名字是正文字（Barlow 13，不走列头的 Condensed），图标省略（名字已足够，且点的语言与格子统一）。
- **点它＝点格子**：○ 点一下＝全部加上 → ●；● 点一下＝全部移除 → ○。**悬停同格子**：点本身不变，只出圆形 `hairline` 光晕，提示框列出受影响的 skill（`加到 Codex · 1 个：typesafe-ai`；超过 5 个「等 N 个」；不受影响的注明原因）。
- **`所有 agent`** 同一写法：所有 agent 都全有才 ●。
- **只按能改的格子算**：原件、写不进、同名被挡不计入，点完一定落到 ● 或 ○。**没有可改的格子时**该项禁用（点与字 `disabled` 色），提示框说原因。
- **按下后**：这一列受影响的格子**同时**变成新状态，不闪、不依次点亮（批量时逐格动画像多米诺骨牌，抢眼而不带信息，①；结果由提示条交代）；写入超过约 500ms 时这一项旁出转动指示 +「正在加到 Codex」；例行提示条 `✓ 加到 ⎔ 1 个 · 撤销` 贴在这一项下方（工具行下面是来源片，可暂时盖住）。
- **MCP**：只能写进——● 后该项禁用（提示框 `都已写进`）。
- 列头不出现任何选择控件（只有图标、名字、计数）。表头 `名称` 左边的「全选」框是选行用的，保留半选。
- 放不下时折行；再放不下 agent 名截断，完整名进提示框。

演变：胶囊片 → 状态点 + 增量 → 动词随状态翻转 → 列头上方 ＋ / － → 列头复选框 → **工具行里的状态点项**（与格子同语言，产品负责人）。

### 「添加」只有两种长相

- **提交一次添加**（`添加 6 个` `保存`）：主动作，反色。
- **开始一个添加流程**（添加 skill / MCP / 项目 / 来源 / 网关）：**默认按钮，`+` 图标 + 名词**：`+ skill` `+ MCP` `+ 项目` `+ 来源` `+ 网关`。`+` 是 12px 1.4 描边线性图形，与名词间距 6。它是独立的创建动作，不是次级——不用灰色文字链，也不用光秃秃的图标按钮。

### 图像（① 愉悦与归属感，② 不与数据抢主角）

- **只用在没有数据、等待、刚开始的时刻**：首次启动与首次扫描、还没有来源、这个位置没有 agent 目录、一个 skill 都没有；筛选无结果不放图。**设置页「关于」不放图**——一组标志不回答任何问题，还会被读成「只支持这几个」（⑫）。**有数据的表格视图不放图**——那时的「空」靠构图：工具行与列头结构线本身就是锚，表格保持紧凑。
- **两种风格**：
  - **类型学线稿（主）**：贝歇夫妇式——同一类物体以完全相同的正面角度与比例排成严格网格；**秩序来自完全相同的重复**，逐个变化读成装饰噪音；**只画真实存在的东西**（文件夹、链接、已画好的真实 agent 标志与首字母方块），不编「像标志的图形」（认不出的图标比没有图标更糟，⑫）；网格 4×2 或 3×2，**图高不超过 160**，让「一句现状 + 一个动作」仍是主角（②）；本体系线稿语言：1.4 描边、hairline、纯黑白、无填充无渐变。用于各种较小空态，与表格同构、不需要例外。
  - **地平线（仅首次启动）**：杉本博司《海景》式——一条海平线居中分割，灰阶天与海，长曝光细颗粒，无任何物体；取最低对比的雾白一张。**「零渐变」约束界面材质，不约束内容图像**，这是唯一例外。
- **构图**：图不带边框，与空态的一句现状 + 一个动作组成一块，图在上、文字与按钮在下，间距 8 / 16，整体在内容区居中；按各空态实际位置出图（类型学小图约 240 宽，地平线约 480 宽）。
- **禁止**：发光、景深、假金属、3D 质感、任何颜色、人物、画面内文字、动效（空闲静止）。

### 空态与忙碌态

四种空态（扫描中、这个域没有目录、筛选无结果、一个都没有）各自说明现状与下一步；两个动作时**只有一个是按钮**，另一个降文字链。busy 期间受影响控件 `opacity: .45`，**五个豁免**：设置、筛选输入框、取消选择、提示条关闭、表头排序——保持 `opacity: 1`，不加聚焦态，对比本身就说明它还能用。

### 表头排序

默认无箭头（`visibility: hidden` 占位，hover 时行不跳）、hover 出 `ink-faint` 箭头、激活转 `ink`。busy 期间不禁用。

## Patterns

**这一节只放与产品无关的组织法**——换一个产品、换一批对象，这些规则照样成立。
凡是「本产品叫什么、算什么、显示几个」的裁决，一律去 `## 产品裁决`。

### 说结果，不说机制

软链是我们的实现手段，不是用户的目的。**只在用户需要据此判断时才提软链**——删原件的弹窗要说「2 条链接会因此失效」，因为那正是他要权衡的；其余时候说他能看见的结果。

| 别写 | 写 |
|---|---|
| 添加＝在选中的 agent 下建软链接 | 让这些 skill 出现在「全局」的列表里 |
| 没有需要建立的链接 | `<agent>` 下已经有同名的 `<skill>`，没有覆盖它 |
| 操作失败，请重试 | `<agent>` 的 skills 目录写不进去 |

### 命中区与视觉尺寸是两回事

**视觉可以小，命中区不能小于 24×24。** 12px 的方形复选框、片上 9px 的 `×`、6px 的圆点——它们的**视觉**尺寸由层级决定，但点击目标要用透明外圈撑到 24px 以上；列表行里的选择记号更进一步：**整行可点**，记号只是告诉你点了会发生什么。

**撑命中区不能改变视觉尺寸。** 用 `padding` 撑的话 `border` 会画在 padding 盒外沿，12px 的框就成了 24px——模型选择器里的复选框就是这么变大的，和 skill 列表里的一比就露馅。正确做法：视觉元素保持自身尺寸，命中区用伪元素或透明 `outline`/负外边距的包裹层撑，不动 border。**同一个记号在全应用里只能有一个尺寸。**

### 可点的面：hover 怎么表示

零色彩系统里能用的只有描边和反色，按面的形态分两种：

| 面 | 静息 | hover |
|---|---|---|
| 有 `hairline` 描边的块（区块、输入框、未选中的片） | `hairline` 描边 | 描边转 `ink`，**底色不变**——换底色会把里面 canvas 底的片糊掉 |
| 无描边的列表行（侧栏项、表格行） | 无描边 | 底色转 `surface` |
| **静息就已经是 `ink` 描边的面**（按钮、选中的片） | `ink` 描边或反色 | 描边已经到顶，**改底**：ghost pill 铺 `surface`、按下转 `hairline`；反色面退到 `ink-mute` |

第三行是前两条规则的盲区：描边只有 hairline → ink 一档可升，升满了就没有下一档，所以只能改底。

### 什么时候才有按钮

**界面里的改动默认当场生效。** 勾选、开关、改名、删片、筛选——点了就是结果，不需要第二步去确认它。这条原则曾散在四处注释里（「返回即保存」「改一个生效一个」「切换开关即保存」「不给拉取模型单独按钮」），从没被正面写出来，于是新写的浮层又长出一对「保存 / 关闭」。

只有三种情况配得上一个按钮：

1. **要离开当前语境去做一件外部的事**：`配置网关`、`重启`、`添加 skill`（启用不在这里——它是当场生效的布尔状态，走开关）
2. **多个输入必须一次提交、中途状态没有意义**：网关地址 + 密钥 → `保存`（且保存即拉取）
3. **真会丢东西、需要确认一道**：删原件、MCP 的批量或跨域写入、重启 Codex——与「页面还是弹层」那三处确认同源

**「关闭」「取消」「确定」不是动作。** 浮层点外面或 Esc 关；二级页面 `←` 或 Esc 回；离开即提交。唯一例外是确认弹窗里的 `取消`——那是在回答一个问题，不是在关一个面。

一句判据：**操作本身已经说明了结果，就不要再放一个按钮教用户怎么完成它。**

### 反馈：四个地方会说话，一件事只在一个地方说

| 说什么 | 在哪 | 形 |
|---|---|---|
| 刚做完了什么（会消失） | 提示条 `toast` | 右下浮层（**右沿对齐面板右沿**，没有面板的页面对齐页边 32；底 16）；有触发控件时按「提示与反馈锚在触发它的控件上」），一次操作汇总成一句，不排队。6 秒（做不成 8 秒）。可逆的给 `撤销` |
| 应用级故障（不会消失） | 错误横幅 `banner-error` | 顶栏之下通栏反色 |
| 要你拿主意，散在几十行里 | 就地记号 + 新问题一次性提示 | 行上 `×2` / 格内异常记号就地处理；新出现时右下黑窗提示一次，`查看` 跳到那一行，看过不再提示 |
| 要你拿主意，就挂在这一行上 | 行内待办条 `row-notice` | 一句话 + 紧凑按钮 + `稍后`（文字链） |

**二级页面自己渲染提示条**。壳上的提示条只服务主视图。二级页面里上游服务够不着这类失败（网关拉不到模型列表）走错误横幅——它不是某次点击的结果，是那条链路此刻不通，用户得读完再走。

**提示条里的动作（`撤销` `查看`）行内右置**，与 `×` 同一行，不掉到第三行。

**MCP 写入的撤销**（⑪ 能撤就给撤销，⑫ 撤不了就说实话）：MCP 写入前 core 用 atomicfile 在同目录留一份快照备份；提示条给 `撤销`，从快照原子还原——**只有目标文件仍等于写入后的指纹（写完没人改过）才能撤**，还原同样走 atomicfile（写用户配置文件的唯一通道）。指纹对不上时 `撤销` 禁用，提示框「写入之后文件又被改过，没法安全撤销」，提示条里另出一个次要文字链 `在访达中显示备份 ↗` 作手动兜底（能撤时不出现）。备份只保留最近一份：**撤销窗口＝提示条存活期，且在下一次写入同一文件之前**。批量写入涉及多个文件时先查全部指纹，任一对不上整笔不撤。「看看备份」一词删除。

**提示条的四种形态**：成功与成功多项是例行一行（✓ + 动词 + agent 图标 + 名字 + `撤销`，多于两个名字写 `+N`）；以下两种是黑显示窗：做不成（⊘ + 一句能行动的原因）、部分失败（! + `2 ✓ · 1 ⊘` + 哪里没成 + `查看`）。

**每一类问题在哪处理**：见「材料与工艺」里「没有收件箱、待处理页和「忽略」」那张表。同名原件：**两份原件各自在列表里成行**，行视角的事（删哪个）在行上问；格视角的事（这一格为什么点不动）由格子提示框说。

### 页面还是弹层

**弹层只有一种用途：确认一个决定。** 设置、添加、网关是二级页面。**属于某一行的小配置就地展开在那一行下面**（MCP 差异、同名替换、skill 详情这类几行的）；**多段、带列表的任务进二级页**，与设置 / 添加 / 待处理同一骨架（网关）。不做抽屉——抽屉也是弹层。弹层把用户困在一个小框里，挤出来的信息密度低。

**主动作用反色，`取消` 是文字链**——第一版两者只差一档描边，主次不分。**确认只给真正不可逆的事**（⑪ 能撤销就不弹确认）：**删网关要确认**——地址与钥匙串里的密钥一起删、找不回；锚在垃圾桶旁的确认框「删掉 openrouter.ai？」+「地址和钥匙串里的密钥一起删掉，删了找不回来」+ 主动作 `删掉` / `取消`，确认后直接删、不再出撤销条（曾做成延迟提交 + 撤销，带 ✓ 的「删掉 X · 撤销」读成删成功了，见冲突表）。**只留这份（删掉另一份原件）要确认**——删的是用户的原件文件夹、低频；进了废纸篓也只能找回文件夹，改指过的链接回不来；确认框写清哪份进废纸篓、几条链接改指，确认后直接执行、结果用例行一行。添加页的 `替换现有的` 以那一行的显式选择 + `添加 N 个` 为确认。确认只有：**删网关**、**只留这份**、MCP 的**批量或跨域**写入（跨域会把请求头和令牌一并复制过去）、**重启 Codex**（会结束正在运行的进程）。开关链接、清除失效链接、**MCP 同域的单格写入**都不确认。

## 产品裁决

下面几节是 Sophia 自己的决定，**不是设计系统的一部分**。做别的产品时照搬这里的结论没有意义，
该照搬的是上面的 Foundations / Components / Patterns。

### 术语

**把一样东西放进一个位置，全应用一个动词：「添加」。** `添加 skill` `添加 MCP` `添加项目` `添加网关`。曾经 skill 叫「导入」、MCP 叫「引入」，用户先要求统一，再问"要不要干脆不叫导入"——「导入」暗示从外面拷一份进来，实际做的是建链接 / 写一条配置，用户看到的结果就是"这里多了一个"，那就说「添加」。没选「新增」：它和自动规则那句里的"新出现"撞词（`此来源新出现的 skill 自动新增`）。

**页签是名词，不是动作**：`模型` `Skills` `MCP`。第一版 MCP 页签叫「导入 MCP」是为了和二级页「导入 skill」错开，现在动作只在按钮上出现，页签就不用扛它。

**界面文案里不说「矩阵」，说「列表」。** 「矩阵」是我们对那张表的叫法（行 × 列），用户看到的是一个 skill 列表，每行后面几个开关。设置页那句是 `哪些 agent 出现在列表里`。

界面文案里**不出现「harness」**，一律 agent。代码标识符不动（`disabled_harnesses` 是已落盘的键、`matrix` 是组件名）。

### 来源的名字

来源的标签是**用户认得的名字**，不是路径：

| 来源 | 标签 |
|---|---|
| 通用仓库 | `通用仓库` |
| agent 的全局目录 | agent 名 |
| 项目 | 项目目录名 |
| 应用包内的目录（`/Applications/ego lite.app/…/ego-skills`） | **应用名** `ego lite`——从 `.app` 那一级取，去掉后缀 |
| 应用数据目录（`~/Library/Application Support/WeiboAP/…`） | **应用名** `WeiboAP`——`Application Support` 下一级 |
| 其余外部目录 | 从末尾往上找**第一个不是泛称的分量**：`~/.local/share/ego/skills` 叫 `ego` 不叫 `skills`。末尾一级几乎总是 `skills` 这类泛称，光取它三个来源会撞成一个名字 |

路径放 `title`。绝对路径**不出现在任何可见文案里**，除非用户正要据此做判断（删原件的确认弹窗）。

**矩阵「原件位置」列不给外部来源挂「外部」标签。** 用户要知道的是它叫什么、在哪，`ego lite` 这个名字已经说完了；「外部」是我们的分类词，对用户没有信息量。添加页的来源栏保留分类，那里是在挑来源、分类有用。

### 主视图：表格是主角，表头在第一屏的上四分之一

评审第 1 轮量过：待处理横幅 + 说明横幅 + 筛选行 + 自动同步框四层叠在表格上面，首行数据落在窗口高度 54% 处，56 个 skill 只露 8 行。现在内容区从上到下只有**两样**：

1. **工具行，两行**：第一行（高 28，上 16）筛选框（弹性，最小 200，放大镜在框内，占位 `筛选`）+ 右端 `+ skill` / `+ MCP` 按钮，右沿对齐面板右沿；第二行（上 8，下 16）**来源筛选片平铺**：`全部 56` 在最前、默认选中，每片 `来源名 N`，选中反色（⑦ 选项保持可见，⑧ 一步筛选，⑨ 当前筛选常显）；放不下折到下一行，不超出面板宽度；同名来源用最短区分片段，放不下截断，悬停同行右侧提示框给完整值。总数也写在 `名称` 列头（`名称 56`，计数 `mono` `ink-faint`）。MCP 同理。
2. **表格**：表头紧跟工具行。1100×720 的窗口里表头 y ≤ 200。

其余三样各归其位：

- **列头只排序**（④ 一个控件一个职责）：点列头文字＝排序，**当前的排序依据列常显 `↑ / ↓`**（默认按名称升序时 `名称 56 ↑` 也显示，Finder 惯例）；所有可排序列头统一此规则。`原件位置` 点文字即按位置排序（同来源聚拢）。
- **点 skill 名字，该行就地展开详情**（不做右侧常驻详情栏）：名字前 12px `▸ / ▾`；展开区左沿与名字对齐、不跨进 agent 列，内容：描述（取自 `SKILL.md` frontmatter 的 `description`，`ink-mute` 13，不截断）、原件路径（`mono` `ink-faint`）+ `打开 ↗`、`改于 9月20日 · 3 个文件`。再点或 Esc 收起；一次只展开一行。读不到描述时这一行不写，不写「无描述」。**行已展开时，这一行的原件位置格悬停只出路径提示框、不再出 `打开 ↗`**——展开区里已有同一入口，同时可见就是重复（①）。
- **工具行、列头吸顶**（⑦ 长列表滚动后仍知道每列是哪个 agent；工具行与选择条共用槽位，滚动时要够得着）：工具行在最上，列头连同 2px 结构线紧贴其下。吸顶时不加阴影，靠 `canvas` 底色盖住下面的行。
- **勾选了 skill 时，选择操作条顶替工具行**，同一个 28px 槽位：`已选 2 个` + 动词键 + `取消选择`（文字链），**选择条只顶替工具行第一行**（筛选框 + `+ skill`，选择期间用不到；按 agent 的操作是工具行里的状态点项），第二行来源筛选片保留可见——选择常发生在某个筛选之内，要看得见当前筛选（⑦⑨）；批量提示条锚在按下的键下方，可以暂时盖住来源片。不另起一行。**默认一行不选，选择条不出现。**
- **没有待处理栏**：问题在行上就地显示与处理；新问题右下提示一次（见「材料与工艺」）。
- **没有常驻说明条。** 「列表里只出现两种 skill：原件…软链…」是机制说明，放列头 `名称` 的 `title`。

**MCP 的表头与 Skills 同高**：全局位置下 scope 恒为 User，位置列头只写 agent 名一行（图标在上）；项目位置下才出现第二行 `LOCAL` / `PROJECT`。**MCP 恢复「来源位置」列**（与 Skills 的「原件位置」同理：写位置名、悬停出完整路径与 `打开 ↗`），工具行筛选片按位置筛选；自动添加规则只在添加页。侧栏项只写项目名（`CardBox`），「位置」小标题下本来就都是项目，不加 `项目 ·` 前缀。

**表格列**：`名称` 280；`原件位置` 120，紧挨 agent 列；agent 列各 88。第一版 `原件位置` 到第一个 agent 列之间一大段死白。MCP 的 `传输` 列只写真实的传输方式（`HTTP` `stdio`）；「某位置不支持」不是传输方式，在服务名后挂 `tag-weak`。

### 计数口径

一页上出现的数字口径必须一致。侧栏域名右侧＝该域有格可点的 skill 行数；列头 agent 名下＝该 agent 下能用的格数；添加页来源栏「未添加」列＝未添加数，列表头 `· N 个原件`＝原件总数，**两个数不共用位置**；自动同步行＝下一轮会新建的条数，**带单位写成 `N 条待建`**，裸的 `+N` 会被读成「还有 N 个 agent」。

### 列的存废

看「用户还有没有别的入口」，不看「文件存不存在」。Skill：目录不存在的 agent 照样成列（藏了用户就没别的地方能把目录建出来）。MCP：Claude Code 在一个项目里的第二个空位置藏起来（它仍是「添加」的显式目标，入口没丢）。

### 模型页

**一张表，一个 agent 一行**，与 Skills / MCP 同一种列表语言（线上画布评论里定的：卡片在只有一个 agent 时很丑、满宽卡内容撑不满）。页面上没有解释段落。

表头 `AGENT` ｜ `生效模型` ｜ `启用`。一行：

| 列 | 内容 |
|---|---|
| agent（232） | 24px 图标 + 名字（`wordmark` 档 20/700，不大写）+ **启用开关紧跟名字右侧**（名字 + 开关成组）；待重启黑窗挂在名字格下方 |
| 生效模型（504） | 一个常驻的 hairline 框，里面是模型片（显示友好名 `Opus 4.6`，完整 id 进 `title`；带 `×`）；框尾端等宽 `103`（可选模型数，`title` 写全）+ 展开记号——放在下拉框尾自然读成「这里有 103 个可选」；整框可点，点开时框线转 `ink`，选择器浮层从框下方展开、**与框同宽左对齐** |
| 行尾 | `配置网关`（默认按钮，紧凑 24） |

**三个主视图怎么对齐**：左沿与顶部结构线（列头底 2px）一致；**右沿随各自内容**——Skills / MCP 随 agent 列数变，模型页的「生效模型」列随内容区变宽（最小 360，最大 640——常见窗口下两个模型片排一行，再宽就难读），横线止于框右沿 + 24；agent 列 324 不变。第 5 轮的「模型页右沿对齐 MCP」已放弃：真实数据下 MCP 只有两列（552），对齐就放不下模型框。

**没有版本、路由状态、网关几家**这些内部事实。**「改动待生效」由一个按钮表达，按钮即状态**：`needsCodexRestart` 比的是 Codex 启动时加载的配置与现在——用户用任何方式重启 Codex 都会自动变回一致，Codex 没在跑也不出现，它永远说实话。所以 agent 同一行、`配置网关` 之后 12 放一个紧凑描边键 `重启生效`（同高 24）；提示框「重启 Codex 桌面应用让改动生效，进行中的对话会中断」（只写点击的后果与代价，不替设计解释为什么关不掉；「桌面应用」是 ⑫ 分支——目前只检测得到桌面应用拉起的 Codex，终端里的 `codex` 检测不到也不会被重启，**CLI 检测补上后去掉「桌面应用」**）；点击出锚定确认（打断对话，⑪），次按钮 `取消`；确认框不重复提示框原话——能检测到进行中的对话就写「有 2 个对话正在进行，会中断」，检测不到写「会结束 Codex 正在运行的进程，进行中的对话会中断」；Codex 被以任何方式重启后键消失。不配读数、不给「稍后」、不用黑块、不做可关闭的提示——按钮出现 / 消失本身就是状态。（不加 ↻ 图形：循环箭头是「刷新」，图标词表之外写字。）

**点了「重启生效」之后**（⑨）：确认后键位原地换成 14px 地球绕太阳 + 「正在重启 Codex」；成功——键消失，原位一行例行成功文字 `✓ 已生效`，约 4 秒后淡出（reduced-motion 下直接消失）；失败——黑块「做不成」+ 原因（`Codex 没能在 15 秒内重新打开`）+ `再试一次`。状态规则不变：Codex 被以任何方式重启或退出 → 键消失；Sophia 重开时若 Codex 仍在用旧配置 → 键照常出现（⑫）。

**选择器**：搜索框 + 列表，已选置顶，12px 方形复选框；整行可点，勾选当场写盘，没有保存 / 关闭按钮；底部不再写 `已选 N 个模型`（已选组头 `已选 · N` 已经说了）。

**网关配置是二级页** `Codex 的网关`（与设置 / 添加同一「← 标题」骨架）：模型页 `配置网关`、模型下拉里的 `管理网关 ›` / `还没有网关 · + 网关 ›` 都进这一页。**转场**：新页从右侧推入、返回滑回，200ms 机械缓动（`cubic-bezier(.2,.8,.2,1)`），reduced-motion 即时（⑦ 动效解释空间关系）。**没有常驻右栏**：与设置页同样单列、内容宽度，自上而下三段（①）：
- **网关切换**：分段片`ap-gateway 103 · openrouter 连不上 · + 网关`，选中反色。片上写网关短名（与模型列表行尾同一规则，`openrouter.ai` → `openrouter`）。**新加网关（⑥⑦⑩）**：点 `+ 网关`，它**原位变成**选中反色的 `新网关` 片，下方出表单——点的东西变成了结果；草稿存在期间不渲染 `+ 网关`（从源头防止两个草稿）；保存成功，`新网关` 换成真实名称 + 模型数（`api.deepseek.com 12`），其后重新出现 `+ 网关`；取消，`新网关` 变回 `+ 网关`，回到之前选中的网关；草稿未保存时点别的网关片，就地「新网关没保存」+ `保存` / `丢弃`（与离开时的拦截同一组件）。地址为空时 `保存` 禁用，提示框「先填地址」。
- **连接**：已连上的只显示一行摘要 `https://ap-gateway… · 已连 · 编辑`（行尾垃圾桶），点 `编辑` 才展开 `地址` `密钥` 表单（`保存` 主动作、保存才生效、保存即拉取，保存中原位转动指示 +「正在拉模型」；`取消` 文字链复原）+ 只读 `本机端口` `协议`。新加网关直接显示表单。连不上：`连不上` + 8px `再试一次`。删网关：点垃圾桶出锚定确认「删掉 openrouter.ai？」，确认后直接删（见「页面还是弹层」）；最后一家还在供模型时垃圾桶禁用，提示框说原因。
- **从这个网关选模型**（段头下是限制说明，不截断）：与模型下拉同一组件的勾选列表，只列本网关的模型，勾选即生效；超过约 8 行在自身范围内滚动，带筛选框。**首次**在这里选：新加网关保存成功拉到模型后，这一段原地出现，新模型各闪一次。
- **两处都能选模型，同一份状态**（⑦⑧④）：首次在网关页选，以后调整在模型页下拉（全部网关的全部模型）；网关页勾上的回到模型页已在框里，下拉里去掉的网关页同步取消。
- 页头标题后按状态出现 `重启生效`（与模型页同组件、同规则、同提示框与确认）。
- **离开（点 `←` 或 Esc）时** `连接` 有未保存的改动：拦下，段内就地一句「地址改动没保存」+ `保存` / `丢弃`（⑪⑫）。
- 模型页的 `配置网关` 是普通默认键，不带展开箭头。**没有「选模型 ›」跳转**。

**模型列表的写法**（下拉与网关页同一组件，①⑤⑥）：真实网关多半不给友好名，`azure/gpt-4.1` 与 `default-azure-gpt-4.1` 并排是同一串字的重复，`default-azure-` 还是网关内部路由命名。
- **一列名称，行上不出提示框**（产品负责人：挑模型时完整 id 没有意义——id 是网关内部路由名；且悬停提示框会盖住用户正在看的这一行）。
- **行尾写来源网关的短名，只在列表跨多个网关时**（产品负责人）：模型页下拉汇总所有网关的模型，同一个 `gpt-4.1` 可能来自两家，行尾右对齐写 `openrouter`（12 `ink-faint`，UI 字体，不截断；有行尾 id 时排在 id 之后、间距 12）。已选组和服务商分组里都写。只有一个网关时不写（每行都一样就是重复）；网关页只列本网关，也不写（页头分段片已有）。**短名**：网关的显示名；没有显示名时取地址主机名的主体——去掉 `api.` `www.` 和顶级域，`https://openrouter.ai/api/v1` → `openrouter`。

## Do's and Don'ts

### Do

- 一次操作只汇总成一句提示条
- 禁用的按钮同时给 `title` 说原因
- 需要用户拿主意的事就地显示、就地处理，新出现时提示一次
- 数字带单位
- 用反色表示"现在开着"（选择片）；布尔状态用开关
- 图标按钮带 `title`

### Don't

- 不涂红。破坏性靠信息承担分量
- 不在按钮上写宾语（`重启 Codex` → `重启`）
- 不给词表之外的动作发明图标
- 不在列头放灯。看不懂的记号比没有记号更糟
- 不把选择操作条退化成两个总按钮，「针对某个 agent」这一维不能丢
- 不显示绝对路径，除非用户正要据此做判断
- 不写「操作失败」「请重试」「没有需要建立的链接」
- 不给「拉取模型」「改选模型」单独的按钮——保存即拉取，整块区域可点
- 不给浮层配「保存」「关闭」——点了就生效，点外面就关
- 不让命中区跟着视觉尺寸缩——12px 的记号，24px 的目标
- 不说「同步」（MCP 页）——它只新增、从不覆盖也不删除
- 不在文案里说「矩阵」「导入」「引入」「harness」
