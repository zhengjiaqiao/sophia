# Sophia 设计系统

**本文件是实现的唯一依据。** 画布「SymSync 界面重构」（改名前的画布，名字未改）是视觉参照，两者不一致时以本文件为准；改组件先改这里，再改代码，再同步画布。`scripts/lint-ui.mjs` 把本文件的硬性约束变成了可执行断言，接在 `make lint` 里。

历史裁决与每条规则背后的推理在 `docs/specs/2026-09-21-ui-decisions-log.md`，本文件只写结论。

## Overview

**像一件器物，不像一张线框图。** 参照 teenage engineering TP-7：极简、现代、机械感、工艺品。色调仍是黑白、零色彩零阴影零渐变，logo 不动。2026-09-22 产品负责人判定前两版「过于简陋」——提示条是白底 1px 线框盒，全产品只有一种材料（白底上的 1px 线），规则再严也像没上材质的草图。下面「材料与工艺」一节是这一版的总纲，其余各节与它冲突时以它为准。

## 材料与工艺

**总约束（产品负责人原话）：「依然服务于功能，易用，给人惊喜又符合直觉，剔除不增加价值的任何元素。」** 每个元素都过一道检验：**拿掉它，用户会少知道什么、或少能做什么？答不上来就删。** 每个交互先满足惯例（开关像开关、链接像链接、可点的看得出可点、不可点的不像可点），再在手感和响应上超预期。惊喜放在**行为**上——点格时指示灯即时点亮（乐观更新）、失败时弹回并由黑窗说明原因、撤销一键复原、停转的阻尼——不是多一个图形。任何需要用户学习的新图形语言都算缺陷，除非它换来明确的效率。

**TP-7 的极简不是少画，是：两种材料的大块对比、一个会动的主角、极小而精确的刻字、每个控件都有行程。** 翻译成界面，不拟物——没有金属渐变、螺丝、内阴影、发光灯、橙色点缀。

### 两种材料

| 材料 | 是什么 | 给谁 |
|---|---|---|
| **白面板**（`canvas`） | 放内容、放数据的面 | 表格、表单、列表、对话框的板 |
| **实心黑体块**（`ink`） | 机器在跟你说话的显示窗 | **提示条、贴底待处理栏、错误横幅**（功能理由：「机器对你说话」与「你的数据」用材质分开，一眼可辨、显著性够）；主动作键；删本体弹窗的路径「铭牌」（路径是这次决定里最关键的信息，给它最高显著性） |

黑是体块，不是墨水。黑面上的字：主 `canvas`，次 `ink-faint`；黑面上的分隔线 `ink-mute` 1px；黑面上的按钮是 **白描边键**（1px `canvas` 描边、`canvas` 字，2px 圆角）。

- **侧栏是白的**（产品负责人看定调稿后裁定：「黑侧边栏不如白的舒服」）。实心黑只给显示窗、路径铭牌、主动作键与点亮的键。
- **提示条 = 显示窗**：`ink` 实心板，0 圆角，无外框，宽 ≤ 400。左侧 40×全高**指示窗**（右边 1px `ink-mute` 竖线）放 16px 状态记号（✓ / ⊘ / !，`canvas` 线稿）。主行**图标与读数优先于句子**：agent 图标 + 读数 `+2`（等宽 15/500，显示窗里的读数是主信息，不用 12）+ 至多两个名字，超过写 `+5`；做不成必须带一句能行动的原因（可加副行路径）。右侧 `撤销` 白描边紧凑键 + `×`。
- **待处理显示窗**（内容区左下，贴底，**内容宽**的一块黑窗，不是通栏地板）：当前这条的异常记号（与格内 / 括线同形）+ 对象名 `defuddle` + 等宽 `1/3` + `›`。点它滚到那两行，`›` 看下一条。不写问句。
- **对话框**：无外框。全窗 `surface` 实色遮罩 + 纯白板（遮罩与白板已足够分层，不加装饰边）。删本体的路径写在**铭牌**里：`ink` 底、等宽 12 `canvas` 字、内边距 10 12。**承载后果与安全信息的句子必须留**（「这不是关掉一条链接，是把这个目录移走」「跨域会把请求头和令牌一并复制过去」）——那是功能。
- **忙碌态**：转盘 + 一句「忙什么」（见「转盘」）。

### 视觉优先：文字只负责名字和动词

**状态、关系、后果、进度、位置，一律画出来；文字只负责名字和动词。**（产品负责人：「尽量通过视觉就能理解操作，而不是文字」。）不是把按钮都换成图标——认不出的图标比文字更糟，图标词表之外的动作继续写字。要换掉的是「用句子描述一个本可以看见的东西」。底线：**每个新图形在设计资产板有图例、悬停 `title` 给出文字、屏幕阅读器文本不减**。

| 以前用句子说的 | 现在画出来 |
|---|---|
| 贴底栏「defuddle 有两个本体，删掉哪个？」 | **表格里那两行自己被标出来**：两行在表内、复选框左侧 8px 各一段 2px `ink` 括线（上下横脚 6px），只连两行本身；跨组时在分组线处断开 4px 的口，表示「跨组的两行」；动作键长在这两行各自的行尾（`删这个`，紧凑键）。贴底黑窗只剩异常记号 + `1/3` + `›`，点了滚到那两行。 |
| 链接失效 / 写不进 / 同名被挡：格里不常驻，事后提示条解释 | **在它发生的那一格看得见**，同一个 10px 环的骨架：**失效＝虚线环**（4 段、段间 1.5px 空）——单缺口环像转到一半的加载圈，而「转」是全产品唯一的忙碌语言；虚线在空态里已经教过「虚线＝目标不在」（虚线列头＝这一列还没有目录），链接失效就是「指向的东西不在了」，同一个视觉词只学一次；**写不进＝斜杠环**；**同名被挡＝环内一短横**。悬停出黑窗说原因，点击就是修复动作。 |
| 规则句「新出现的自动同步到 Claude Code · Codex」 | 图式：**来源片 → 箭头 → agent 图标组 + 开关**，不写字（`title` 写全句）。添加页底部的规则同样画成「来源 → 目标」。 |
| 添加页「在以下 agent 开启 ☑ Claude Code ☑ Codex」 | 一排 **agent 图标键**：图标在上、名字在下，与表格列头同一造型；按下＝点亮（反色）。表格里已学会「这个图标＝这一列」，这里复用。 |
| 「本体位置」列 12 行重复「通用仓库」 | **按来源分组**：组头一行（来源名 + 计数 + 该来源的规则图式），行内不再重复。去掉「本体位置」列，名称列更宽。 |
| 删本体确认的三句后果说明 | **一张小示意**：本体 ■ 连出线到两个 agent 图标，线上打断开标记，一条虚线改指到留下的那个本体。路径铭牌保留；安全信息留一句「删到废纸篓，可以从访达恢复」。 |
| 提示条「已把 excalidraw、notion 写进 Claude Code」 | 黑窗：agent 图标 + `+2` 读数 + `撤销`；刚变化的格子同时闪一下（120ms 反色再回落），眼睛直接落到变化处。 |
| 忙碌「正在开启 obsidian-cli…」 | 转盘 + 被写入的格子依次点亮——那就是进度；句子降为 `title`。**首次扫描例外**：还没有格子可亮，转盘旁保留一句「正在读 3 个位置」。 |
| 待处理页左列类别文字 | 与格内异常**同形的记号**，类别名进 `title`。格里、贴底窗、待处理页三处同一个记号，只学一次。 |

### 三种线（层级是功能：哪里是区块边界、哪里只是行）

| 线 | 规格 | 给谁 |
|---|---|---|
| 结构线 | **2px** `ink` | **只给表头底**（面板的上沿） |
| 分组线 | 1px `ink` | 表格里来源分组之间、区块起止 |
| 刻度线 | 1px `hairline` | 行与行、顶栏底（顶栏不是面板） |

### 一种数字

**计数一律等宽（IBM Plex Mono）、tabular；不写别处已有的分母**（列头只写 `41`，不写 `41/56`——56 已在「全部 56」上）——功能理由：计数在片与列头里上下对齐、变化时不抖。**不零填充**（`026` 更难读，是装饰）。等宽只给数字、路径、ID——正文不换等宽。

### 刻字

- 区块小标（`位置` `来源` `已连的网关`）：12，拉丁 Condensed 大写 +0.96px / 汉字 600 字距 0，`ink-mute`（黑面上 `ink-faint`），**贴区块 2px 结构线下沿 6px**。
- **只删重复控件已表达的句子**；机器信息（路径、大小、条数）写成等宽读数而不是散句。

### 表格 = 面板

- **通道条表头**：每个 agent 列头三层——16px 图标 / Condensed 大写名字 / 等宽计数 `41`（`ink-faint`，这个 agent 下开着几个——真实信息）；下面是 2px 结构线。
- **面板要紧凑、有四条边**：`名称` 列定宽 280，agent 列紧随其后各 88；**所有横线、分组线、悬停带止于最后一个 agent 列右沿 + 24**，工具行的 `+ skill` 右对齐到同一条边——右侧留白是真正的留白，不是空列。agent 多到放不下时面板才长到窗口宽、横向滚动。撞名行的 `删这个` 紧跟在名字后面（名字 + 键一组）。
- **行高 34**（原 40）：一屏多看几行是功能；整格仍是命中区。
- **悬停十字带**：悬停一格时，这一行和这一列同时出 `surface` 带（列带跳过组头行——组头不是数据行）——宽表格里读「这个点属于哪个 agent」的真实辅助。
- **指示灯**：三种外径一致 **10px**，中心对准列头中线：已开启＝10 实心；未开启＝10 外径 1.5px 环 `ink`；本体＝10 外径 1.5px 环 + 4px 实心芯；无此格＝8×1.5 短横 `ink-faint`。

### 转盘：唯一的忙碌指示

TP-7 中间的马达转盘在这里是一枚 **转盘**：**一个盘面 + 轴毂 + 一个偏心的手指窝**（像 TP-7 转盘上的凹点）：外圆与轴毂小圆线稿 1.4 + 盘面上的偏心小实心点（只有外圆加一个大点时 64px 读成眼睛），旋转时靠偏心点的位移被感知。静止帧不能像任何现成图标——第一版「同心圆 + 径向线」64px 读成钥匙孔（在会报「权限不足」的工具里是误读），16px 像钟表。同一造型在 14 / 18 / 64 都成立。
- **只在真的有活干时出现并转动，空闲时不占位。** 全产品所有忙碌态（扫描、同步、写入、拉模型列表）只用它一种，替掉一切转圈和灰字占位。
- 位置：顶栏右侧待处理入口左边 18px（全局忙碌）；行内操作就在那一行里 14px。
- 旁边一句「忙什么」保留：`正在读 3 个位置下的 skill 目录…`——转盘说在忙，句子说忙什么。
- 匀速转（1 圈 / 1.2s，线性）；完成时带阻尼停转（`cubic-bezier(.2,.8,.2,1)` 600ms 减速，末端过冲 2° 回弹），然后淡出。
- 首次扫描的空态里放大到 **64px** 居中，下面那句「忙什么」。
- 它呼应 logo 首字母的重影——那道重影就是这枚转盘的运动残像。品牌故事到这里闭合。
- `prefers-reduced-motion` 下不转，刻线改为每 400ms 跳 45°。

### 控件有行程

| 控件 | rest | hover | pressed | focus |
|---|---|---|---|---|
| 主动作键（实心黑） | `ink` 底 | 键面内缩 1px 的 `canvas` 内描边（键帽边缘反光） | **下移 1px 且高度压扁 1px**，像键帽被压下 | 外 2px 处 1px `ink` 环 |
| 默认键（描边） | 1px `ink` 描边 | `surface` 底 | `surface` 底 + 下移 1px | 同上 |
| 开关 | 见下 | 轨外缘 1px `ink-mute` | 旋钮压扁 1px | 同上 |
| 复选框 | 12 方 | 描边转 `ink` | `surface` 底 | 同上 |

- **紧凑开关 24×14**（旋钮 8）给行内的规则状态——分组头、添加页的「以后也自动」。它是一条规则的状态，不是本页主角；标准 32×18 只给页面级开关（模型页启用）。
- **开关保持一眼认得出是开关的形态**（胶囊轨 32×18 + 圆旋钮 12，符合直觉优先于像拨杆）；机械感只做在行程和停靠上：切换 120ms、末端 1px 过冲回弹，按下时旋钮压扁 1px。
- 所有状态变化 80–120ms 机械式缓动（`cubic-bezier(.2,.8,.2,1)`），不要弹性果冻，不要 300ms 淡入淡出。

### 别做

拟物（拉丝、螺丝、内阴影、发光 LED、有彩色点缀）；装饰性编号「01」「02」；装饰性网格线、对位刻度、满屏十字准星；数字零填充；对话框装饰边；为了「科技感」把正文换等宽；为了「机械感」把开关换成要想一下的造型。

界面回答两个问题：**这东西在这个 agent 下现在能不能用**；**点了没成的话，是什么挡住了**。第二个问题必须给出用户能据此行动的话，不是错误码。

## Colors

**整个界面零色彩。** 七个**中性**灰阶（R=G=B），没有任何有彩色的值。第一版灰阶照搬 SpaceX 的偏蓝灰（`#f0f0fa` `#e0e0e8`…），评审指出那是「零色彩」里唯一的色相——要么承认它，要么换中性。换了。规范规定色彩全部来自照片，工具里没有照片，所以一个色都不用。

强调只有三种手段，按强度递增：**次要文字（`ink-mute`）→ 加粗 → 反色（`ink` 底 `canvas` 字）**。红色不是其中之一。

**破坏性操作靠信息和文案承担分量，不靠颜色。** 删除弹窗给出完整路径、目录大小、受影响的链接数、git 状态；按钮写「删到废纸篓」而不是「确定」——用户读完就知道会发生什么，再涂红就是吓唬人。

| Token | 用途 |
|---|---|
| `canvas` | 画布 |
| `surface` | 次级面：侧栏选中、悬停、**勾选中的行**（不反色——多选列表里反色行太重） |
| `hairline` | 分隔线、选择片描边、无格态短横 |
| `ink` | 主文字、实心圆点、按钮描边 |
| `ink-mute` | 次要文字、文字链 |
| `ink-faint` | 弱文字、空心圆点描边、hover 前的排序箭头 |
| `disabled` | 禁用描边 |

## Typography

### 三个字族都没有中文字形：字距与大写只给纯拉丁

界面绝大部分文字是中文，会落到系统 CJK 字体（macOS 苹方）。Condensed 大写 + 字距是给 `SKILLS` `MCP` `CLAUDE CODE` 这种**纯拉丁标签**用的工业感；套到汉字上，「删 通用仓库 的」字字散开，「添加 SKILL 到「全局」」窄体大写挨着常宽苹方，同一行像两套系统。评审第 1 轮的最大字体问题。规则：

1. **`letter-spacing` 与 `text-transform: uppercase` 只作用于纯拉丁的 run。** 汉字一律 `letter-spacing: 0`。实现：`<Cap>` 组件按脚本把文本切成 run，只给拉丁 run 套 Condensed + 字距 + 大写；画板里等价于只给拉丁 `span` 写这些属性。lint `cjk-tracking` 查这条。
2. **按钮不走 Condensed。** 界面是中文，按钮几乎都含汉字：`button` 档 = Barlow / 苹方 13 / 600 / 字距 0 / 不大写。专名嵌进去原样写（`删 WeiboAP 的`），不再需要开洞。
3. **页面名 `display` 不大写、字距 0**：`添加 skill 到「全局」`、`Codex 的网关` 原样写。28 / 700，拉丁部分落到 Barlow Condensed，汉字落到苹方。
4. **中文句子里的拉丁词不大写**：`在以下 agent 开启` `哪些 agent 出现在列表里`——句子是内容，只有独立成词的结构标签（页签、agent 列头、模型页的 `AGENT` 列头）才 Condensed 大写。
5. **表头不混排**：我们自己写的列头一律中文（`名称` `本体位置` `传输`），走 `micro-cap` 的字号字重、字距 0。agent / 位置列头是专名，纯拉丁，走 Condensed 大写——它们自成一组（图标在上名字在下）。
6. 顶栏页签 `模型` `SKILLS` `MCP`：汉字页签字距 0，拉丁页签 Condensed 大写 + 1.17px。

### 层级：五档，相邻至少差一倍的视觉重量

| Token | 字号 / 行高 | 用在哪 |
|---|---|---|
| `display` | 28 / 1.1 | 二级页面名、区域大标题 |
| `wordmark` | 20 / 1.0 | 顶栏 wordmark |
| `body` | 15 / 1.6 | 表格、说明、条目名、选择片文字 |
| `button` / `caption` | 13 | 按钮（600）；副行、文字链、选择片、提示条副行 |
| `micro-cap` | 12 / **2.0** | 区域标签、列头、方标签 |
| `mono` | 12 / 1.6 | 路径与计数（嵌在 body 行里，行高跟行走，不撑 2.0） |

**五档之外有两个 `body` 档的变体，它们不是第六档**——字号行高与 `body` 完全一致，变的是字族、字重、字距与大小写：

| 变体 | 写法 | 用在哪 |
|---|---|---|
| `nav-cap` | Condensed 15 / 700 / +1.17 / 大写（只给拉丁页签） | 顶栏页签（一级导航），可点高度 32，在 56 内容区里居中，选中下划线离底 12 |
| `head-cap` | Condensed 15 / 600 / +1.1（`--track-head`） | 区域小标题、弹窗标题 |

**第一版的错**：20 / 15 / 14 / 13 / 12 五档挤在 8px 里，14 与 15、13 与 12 眼睛分不出来，整页读起来像一张密排的表。参照 `DESIGN-spacex.md`：display 到 body 是三倍以上的跳跃，小字靠**行高 2.0** 撑出呼吸感而不是靠字号。所以：页面名拉到 28；砍掉 14 这一档；12px 的标签行高 2.0（占 24px 高，与 SpaceX 的 `micro-cap` 一致）。

### 大写是结构的语言，不大写是内容的语言

大写只给**我们自己写的、纯拉丁的结构词**：页签 `SKILLS` `MCP`、agent 列头。被谈论的对象一律不大写——agent 名出现在选择片、行标题、页面名、句子里时都写 `Claude Code`。

**文件系统来的名字一律原样，不做大小写转换。** `defuddle` 转成 `DEFUDDLE` 后跟表格里的名字对不上。

**skill 名用 `body`，不用 `mono`。** 等宽的理由是路径要对齐、要分得清 `l` 与 `1`；skill 名在列表里是当词读的。`mono` 只给路径与计数。

## Layout

基准 8px，子单位 4 / 12 / 16 / 18 / 24 / 32 / **48**。

### 壳

**顶栏的 wordmark 用 `assets/logo/wordmark.svg`，不用纯文本。** 字标的首字母带和图标同样的重影——那是这个标志的识别点，写成 `<h1>Sophia</h1>` 就丢了。高度 **26px**——20px 时首字母后面那层灰影只有 1px 位移，读起来像套印错位；重影要么大到明显刻意，要么不要。产品负责人要它，所以放大（顶栏内容区 56 高放得下），`currentColor` 取色。

**窗口标题栏不显示产品名**（macOS：`titleBarStyle: Overlay` + `hiddenTitle`）。顶栏自己已经有 wordmark，系统标题栏再写一遍 "Sophia" 是重复。

红绿灯浮在窗口左上角那 28px 里——**那一排留空**，只当拖动区；字标与页签在它下面的 56px 里。第一版把字标和红绿灯挤在同一排，用户反馈"太靠上"。顶栏总高 84 = 28 空 + 56 内容，整条可拖动窗口。**二级页面的头同一条规矩**（它是 `position: fixed` 盖满整窗的）。

**侧栏底部 `+ 项目`**：默认按钮（见「添加只有两种长相」），不带省略号。第一版是带省略号的胶囊，"和其他的格格不入"；第二版降成灰色文字链，评审指出独立的创建动作权重过低。

### 留白：往大了给

| 尺度 | 值 | 用在哪 |
|---|---|---|
| 区域之间 | `huge` 48 | 页面里的大区块（模型页的「agent 行区」与「限制说明」之间） |
| 组之间 | `xl` 24 | 筛选行与表格、表格与待处理栏、表单字段之间 |
| 行内 | `sm` 12 | 同一行里元素之间 |
| 页边 | `xxl` 32 | 内容区左右内边距（SpaceX 的 grid gutter） |

**矩阵行高 40px**，不是 30。密排的表格是"文字很密集"这个观感的主要来源——skill 名、位置名、圆点之间要有空气。

**壳**：顶栏 84 = 28 留空 + 56 内容，底边 hairline；侧栏与内容区之间 hairline；侧栏项高 36px。**二级页面**占满整窗、不渲染侧栏，顶栏换成 `←` + 页面名（`display` 28px）。

**待处理栏贴底**（形制见「产品裁决 › 主视图」）：`position: sticky; bottom: 0`，与内容区底边之间**没有缝隙**，上边一条 `ink` 描边，左右负边距铺满内容区、内边距与页边对齐。

## Elevation & Depth

零阴影、零渐变、零 `rgba()`。层级只靠描边与反色表达。

确认弹窗的背景罩是 **`surface` 实色遮罩**（见「材料与工艺 › 对话框」）——零色彩系统里没有半透明。

## Shapes

**形状承担语义，四种形各管一件事**：

| 形 | 值 | 给谁 | 语义 |
|---|---|---|---|
| 描边矩形 | `control` 2px | 动作按钮、输入框、图标按钮的悬停底 | **点了会执行一个动作 / 在这儿输入** |
| 胶囊 | `pill` 32px | 筛选片、模型片、选择操作条的 agent 片、开关轨道 | **一个可切换 / 可移除的状态** |
| 圆 | `dot` 50% | 状态点、开关旋钮 | 只读状态 |
| 直角 | `none` 0 | 复选框、卡、弹窗、横幅、其余一切 | 容器，不是记号 |

第一版「pill＝可点」把动作按钮、筛选片、添加项目、设置页 agent 片全做成 32px 胶囊，评审指出"会执行动作"与"已选状态"形状不可分、胶囊泛滥。现在：**胶囊只留给片**，动作一律 2px 矩形。**有框的都能点。** 不可点的标识（`同名` `2 份不一样` `连不上` `已添加`）是**没有框的 12px 文字**：强的 `ink` 600，弱的 `ink-faint` 400。第 2 轮评审指出，靠 0 圆角对 2px 圆角区分「标签」和「按钮」不成立——1px 黑框的 `同名` 和行内按钮 `清除` 肉眼不可分。

## Components

### 按钮

2px 描边矩形，高 28（行内、提示条、选择操作条里 24），`button` 档文字。三个变体加一个禁用：

| 变体 | 形 | 给谁 |
|---|---|---|
| 主动作 `button-primary` | `ink` 底 `canvas` 字 | 一个面里**至多一个**：确认弹窗的主动作、添加页的 `添加 N 个`、表单的 `保存` |
| 默认 `button` | `ink` 描边、透明底 | 其余动作：`重启` `配置网关` `清除` `拆开` `删 WeiboAP 的` |
| 文字链 `button-link` | 13 `ink-mute` 下划线；**命中区高 24、左右各 6**（视觉不变） | 退路与次级：`取消` `忽略` `撤销` `稍后` `取消选择` `显示未安装的 32 个` |
| 禁用 | `disabled` 描边与文字 | **必须同时给 `title` 说明原因**，类型上强制 |

**同一行里的控件同高。** 工具行与选择操作条是 28 的一行：输入框、筛选片、agent 片、图标按钮、按钮全是 28。表格行、待处理栏、提示条、行内待办条是 24 的一行：按钮 24、模型片 24。胶囊片和矩形按钮并排时靠形状区分，不靠高度差。

**文字链有两种，长得不一样。** 应用内的次级动作（`取消` `忽略` `撤销` `稍后` `添加项目`）：13 `ink-mute` 下划线。**离开 Sophia 的链接**（`打开目录` 去访达、`检查更新` 去网页）：同样的字，末尾跟一个 10px 的 `↗` 线性箭头（1.4 描边，`ink-mute`，左间距 3）。旧规范写「离开 App 是唯一可以用文字链的地方」，这一轮把次级动作也降成了文字链，所以要靠 `↗` 把两种分开。

**没有 hairline 描边的按钮。** 线上画布一度有一档 `#e0e0e8` 描边的「次级按钮」，评审指出它比旁边的开关弱一档、读起来像禁用态。次级就是文字链，不再有第三种描边。

**按钮里的专名不靠空格断词**：`删通用仓库的`、`删 WeiboAP 的`（中西文之间一个普通空格是排版惯例，汉字之间不加）。

**按钮上只写动词，不写宾语。** 宾语是它所在的那一行：Codex 行上写 `重启`。宾语只在按钮离开了它的对象、或单一个动词说不清去哪时才回来——空态 `添加 skill`、`配置网关`、`添加网关`。

**能画出来的动作不写字**，见「图标」词表。

### 图标按钮 `button-icon`

16px 图形、**1.4 描边**、**28×28** 命中区（与按钮同高）、无描边无底、悬停 `surface` 底 2px 圆角。**必须带 `title`**（同时是 `aria-label`）。顶栏的待处理入口与设置齿轮是同一个组件、同一个尺寸；待处理数用 `mono` 12 跟在图标右侧 4px。

### 开关 `Switch`

**一个当场生效的布尔状态，对象就是它所在的那一行**，用开关，不用「启用 / 已启用」两态按钮。轨道 32×18 pill、旋钮 12px 圆：关＝白底 ink 描边、旋钮 ink 在左；开＝ink 底、旋钮 canvas 在右。零色彩，无过渡以外的动效（120ms 位移）。**开关旁边不写「已启用」**——它自己就是状态。

用在哪：模型卡的启用、自动同步 / 自动添加那一行、添加页顶部的「新出现的自动添加」规则。**不用在哪**：选择（那是 12px 方形复选框——方＝我选的，开关＝它开着）、需要一次提交的多输入。

开关都不需要确认：曾经「开启自动同步」要确认一道，是因为它会把来源里现有的几十个一次建完；现在规则只管以后新出现的，规模问题没了。

曾经的 Don't 写「不用滑动开关（iOS 语言，必带圆角）」，作废：胶囊在这套系统里是「一个可切换的状态」，开关正好落在这个语义上。

### 状态与动效

| 项 | 取值 |
|---|---|
| 可点元素高度 | `--control-h: 28px` / `--control-h-compact: 24px`，**一律偶数**——奇数高会让 pill 端帽只有 75% 覆盖，同一圈描边一半实一半虚，读起来就是「锯齿」 |
| 命中区下限 | `--hit-min: 24px` |
| 焦点 | 只认 `:focus-visible`：1px `ink` 外框、偏移 2px；反色面上转 `canvas`。**不要系统默认的蓝色焦点环**——那是零色彩界面里唯一闯进来的彩色 |
| 过渡 | 只有一档 `--motion-fast: 120ms`，且 `prefers-reduced-motion` 下全部关掉 |
| 数字 | `font-variant-numeric: tabular-nums`，计数跳动时不抖 |
| 字形渲染 | `-webkit-font-smoothing: antialiased`，关掉 macOS 次像素渲染的彩边（零色彩系统里它是真能看出来的） |

### 选择片 `Chip`

胶囊，高 28，文字 `caption` 13（不大写，内容是专名），计数 `mono` 12。未选中 hairline 描边，选中**反色**，不可选灰描边灰字。图标 14px 在左，间距 6px。用在：主视图的来源筛选片、选择操作条的 agent 片。**不用来选「哪些 agent」这类设置**——那是复选框列表（见「设置页」）。

### 状态点 `StateDot`

格回答两件事：**填充＝这个 agent 能不能用它，外环＝它在这儿是本体还是一条软链。**

| 状态 | 形 |
|---|---|
| `linked` 已开启 · 软链 | 9px 实心 |
| `missing` 未开启 | 9px 空心 `ink-faint` |
| `own` 已开启 · 本体 | 13px 外环 + 6px 内实心 |
| 无格 | 8px `hairline` 短横，不可点 |

**前三行是状态，第四行不是**：「无格」说的是这儿根本没有这一格，不是某种状态。常驻的状态只有那三种。异常态（链接失效、指向别处、同名被占、整目录链走、写不进去）**画成空心**，但点击行为与文案分叉——由提示条说原因，需要拿主意的进待处理栏。

勾选中的行用 `surface` 底，圆点不变色。空心圈描边 `ink-faint` 1.4px（第一版用 `disabled`，白底上过淡）；「无格」短横 8×1.4px `ink-faint`（第一版用 `hairline`，融进了行分隔线）；本体点 13px 外环 + **6px** 内芯。

### 矩阵列头

**16px 图标在上、名字 `micro-cap` 在下，堆叠。** 列宽约 84px。

**列头没有灯。** 曾经在图标右上角放一盏 6px 的灯表示目录状态，用户看不懂。目录不存在这件事在点击那一刻由提示条说（「已经建出来」），写不进去的进待处理栏——列头不需要再说一遍。

### 图标

所有图标同一套画法：16px 画布、`currentColor`、1.4 描边。**设置的入口必须是有齿圈的齿轮**——第一版画成圆心加八根放射线，那是太阳，用户看成了「切换日间模式」。看不懂的图标比没有图标更糟，这条和列头灯是同一课。

**词表——只有这几个动作有图标，别的一律写字**：

| 动作 | 图形 | `title` |
|---|---|---|
| 设置 | 8 齿齿轮 | `设置` |
| 改 | 铅笔（45° 斜置） | `改` |
| 删掉 | 垃圾桶（带盖） | `删掉` |
| 添加 | `+` | `添加网关` 这类带宾语的全名 |
| 关掉 / 移除一片 | `×` | `关掉` |
| 返回 | `←` | `返回` |
| 搜索 | 放大镜（输入框内） | — |

判据：**离开这个界面，用户在别的软件里见过同一个图形做同一件事**。「重启」没有这样的图形（循环箭头是"刷新"），「拆开」「忽略」「再试一次」更没有——这些写字。

### agent 图标 `AgentMark`

单色 inline SVG，`currentColor` 取色。**不用品牌色。** 光学补偿：Claude Code 的星形是放射实线，同尺寸下比其他线性图标重——描边降到 1.2、视觉尺寸比其他小 1px。 实现时用各项目官方 SVG 转单色路径，不手画。取不到的用**首字母方块**（14px，hairline 描边、`ink` 字母；未启用时字母随名字退到 `ink-faint`）——它是图标缺席时的占位，**永远和名字一起出现**：已安装的 9 个里首字母就撞了 3 个 C、2 个 G。

### 选择操作条

勾选一个以上 skill 后，**顶替工具行**（同一个 28 槽位）：`已选 N 个` + 每个 agent 一颗按钮 + `全部` + `取消选择`（文字链）。

每颗是**默认按钮（2px 矩形，28）**，内容 = **状态点 + agent 名**，语义是「已选的 skill × 这个 agent」：

| 按钮里的点 | 含义 | 点一下 |
|---|---|---|
| 实心 ● | 已选的在这个 agent 下**全部**开着 | 全部关掉 |
| 空心 ○ + 名字后 `mono` `+2` | 有 2 个还没开 | 把没开的开了 |
| 禁用（`disabled` 色，带 `title`） | 已选的都是本体、或这个 agent 整目录链走 | — |

第一版用胶囊片（反色＝全开），评审第 2 轮指出它和同一槽位上的**筛选片**（反色＝当前筛选）同形不同义。现在状态交给全产品统一的圆点语言，形状是按钮——点了就执行。「全部」对所有 agent 做同一件事。**不要**退化成只有「开启 N」「关掉 M」两个按钮——那丢掉了「针对某个 agent」这一维。

### 「添加」只有两种长相

- **提交一次添加**（`添加 6 个` `保存`）：主动作，反色。
- **开始一个添加流程**（添加 skill / MCP / 项目 / 来源 / 网关）：**默认按钮，`+` 图标 + 名词**：`+ skill` `+ MCP` `+ 项目` `+ 来源` `+ 网关`。`+` 是 12px 1.4 描边线性图形，与名词间距 6。它是独立的创建动作，不是次级——不用灰色文字链，也不用光秃秃的图标按钮。

### 空态与忙碌态

四种空态（扫描中、这个域没有目录、筛选无结果、一个都没有）各自说明现状与下一步；两个动作时**只有一个是按钮**，另一个降文字链。busy 期间受影响控件 `opacity: .45`，**五个豁免**：设置、筛选输入框、取消选择、提示条关闭、表头排序——保持 `opacity: 1`，不加聚焦态，对比本身就说明它还能用。

### 表头排序

默认无箭头（`visibility: hidden` 占位，hover 时行不跳）、hover 出 `ink-faint` 箭头、激活转 `ink`。busy 期间不禁用。

## Patterns

**这一节只放与产品无关的组织法**——换一个产品、换一批对象，这些规则照样成立。
凡是「本产品叫什么、算什么、显示几个」的裁决，一律去 `## 产品裁决`。

### 说结果，不说机制

软链是我们的实现手段，不是用户的目的。**只在用户需要据此判断时才提软链**——删本体的弹窗要说「2 条链接会因此失效」，因为那正是他要权衡的；其余时候说他能看见的结果。

| 别写 | 写 |
|---|---|
| 添加＝在选中的 agent 下建软链接 | 让这些 skill 出现在「全局」的列表里 |
| 没有需要建立的链接 | `<agent>` 下已经有同名的 `<skill>`，没有覆盖它 |
| 操作失败，请重试 | `<agent>` 的 skills 目录写不进去 |

### 命中区与视觉尺寸是两回事

**视觉可以小，命中区不能小于 24×24。** 12px 的方形复选框、片上 9px 的 `×`、6px 的圆点——它们的**视觉**尺寸由层级决定，但点击目标要用透明外圈撑到 24px 以上；列表行里的选择记号更进一步：**整行可点**，记号只是告诉你点了会发生什么。

**撑命中区不能改变视觉尺寸。** 用 `padding` 撑的话 `border` 会画在 padding 盒外沿，12px 的框就成了 24px——模型选择器里的复选框就是这么变大的，和 skill 列表里的一比就露馅。正确做法：视觉元素保持自身尺寸，命中区用伪元素或透明 `outline`/负外边距的包裹层撑，不动 border。**同一个记号在全应用里只能有一个尺寸。**

### 可点的面：hover 怎么表示

零色彩系统里能用的只有描边和反色，按面的形态分两种：

| 面 | 静息 | hover |
|---|---|---|
| 有 `hairline` 描边的块（区块、输入框、未选中的片） | `hairline` 描边 | 描边转 `ink`，**底色不变**——换底色会把里面 canvas 底的片糊掉 |
| 无描边的列表行（侧栏项、表格行） | 无描边 | 底色转 `surface` |
| **静息就已经是 `ink` 描边的面**（按钮、选中的片） | `ink` 描边或反色 | 描边已经到顶，**改底**：ghost pill 铺 `surface`、按下转 `hairline`；反色面退到 `ink-mute` |

第三行是前两条规则的盲区：描边只有 hairline → ink 一档可升，升满了就没有下一档，所以只能改底。

### 什么时候才有按钮

**界面里的改动默认当场生效。** 勾选、开关、改名、删片、筛选——点了就是结果，不需要第二步去确认它。这条原则曾散在四处注释里（「返回即保存」「改一个生效一个」「切换开关即保存」「不给拉取模型单独按钮」），从没被正面写出来，于是新写的浮层又长出一对「保存 / 关闭」。

只有三种情况配得上一个按钮：

1. **要离开当前语境去做一件外部的事**：`配置网关`、`重启`、`添加 skill`（启用不在这里——它是当场生效的布尔状态，走开关）
2. **多个输入必须一次提交、中途状态没有意义**：网关地址 + 密钥 → `保存`（且保存即拉取）
3. **真会丢东西、需要确认一道**：删本体、MCP 的批量或跨域写入、重启 Codex——与「页面还是弹层」那三处确认同源

**「关闭」「取消」「确定」不是动作。** 浮层点外面或 Esc 关；二级页面 `←` 或 Esc 回；离开即提交。唯一例外是确认弹窗里的 `取消`——那是在回答一个问题，不是在关一个面。

一句判据：**操作本身已经说明了结果，就不要再放一个按钮教用户怎么完成它。**

### 反馈：四个地方会说话，一件事只在一个地方说

| 说什么 | 在哪 | 形 |
|---|---|---|
| 刚做完了什么（会消失） | 提示条 `toast` | 右下浮层（**右沿对齐面板右沿**，没有面板的页面对齐页边 32；底 16——**有贴底待处理栏时底 = 40 + 16**，浮在它上面，不盖住它的动作），一次操作汇总成一句，不排队。6 秒（做不成 8 秒）。可逆的给 `撤销` |
| 应用级故障（不会消失） | 错误横幅 `banner-error` | 顶栏之下通栏反色 |
| 要你拿主意，散在几十行里 | 待处理栏 `pending-bar` / 待处理页 | 主视图底部贴底一条，一次一条；完整列表在二级页面 |
| 要你拿主意，就挂在这一行上 | 行内待办条 `row-notice` | 一句话 + 紧凑按钮 + `稍后`（文字链） |

**二级页面自己渲染提示条**（待处理页已经这么做）。壳上的提示条只服务主视图。二级页面里上游服务够不着这类失败（网关拉不到模型列表）走错误横幅——它不是某次点击的结果，是那条链路此刻不通，用户得读完再走。

**提示条里的动作（`撤销` `查看`）行内右置**，与 `×` 同一行，不掉到第三行。

**提示条的四种形态**（都是黑显示窗）：成功（✓ + agent 图标 + `+2` + 名字 + `撤销`）、成功多项（✓ + 多个 agent 图标 + 名字）、做不成（⊘ + 一句能行动的原因）、部分失败（! + `2 ✓ · 1 ⊘` + 哪里没成 + `查看`）。

**待处理栏里每一类都带自己的动作**：

| 类 | 一句话 | 动作 |
|---|---|---|
| 同名本体 | `<skill> 有两个本体，删掉哪个？` | `删 <位置A> 的` / `删 <位置B> 的` / `忽略` |
| 链接失效 | `<skill> 在 <agent> 下的链接指向的位置没了` | `清除` / `忽略` |
| 整目录链走 | `<agent> 的 skills 目录整个链到了别的本体，要逐条开关得先拆开` | `拆开` / `忽略` |
| 写不进去 | `<agent> 的 skills 目录写不进去` | `再试一次` / `忽略` |

同名本体那条：**两个本体各自仍在列表里成行**，待处理栏只负责问删哪个。不要用"指向别处、没有覆盖"这种格视角的话——那是点格时提示条说的，待处理栏说的是行视角的事。

**「忽略」记的是这一条具体状况**，不是记这个 skill：涉及的位置发生变化后重新提示。key 由前端与 core 按同一公式算（`tests/issue-key-contract.test.ts` 与 `store.rs` 两边钉死）。

### 页面还是弹层

**弹层只有一种用途：确认一个决定。** 设置、添加、待处理、网关配置全是二级页面。弹层把用户困在一个小框里，挤出来的信息密度低。

**主动作用反色，`取消` 是文字链**——第一版两者只差一档描边，主次不分。**确认只给这三件事，且只确认一道**：删本体（真会丢内容）、MCP 的**批量或跨域**写入（跨域会把请求头和令牌一并复制过去）、**重启 Codex**（会结束正在运行的进程）。开关链接、清除失效链接、**MCP 同域的单格写入**都不确认。

## 产品裁决

下面几节是 Sophia 自己的决定，**不是设计系统的一部分**。做别的产品时照搬这里的结论没有意义，
该照搬的是上面的 Foundations / Components / Patterns。

### 术语

**把一样东西放进一个位置，全应用一个动词：「添加」。** `添加 skill` `添加 MCP` `添加项目` `添加网关`。曾经 skill 叫「导入」、MCP 叫「引入」，用户先要求统一，再问"要不要干脆不叫导入"——「导入」暗示从外面拷一份进来，实际做的是建链接 / 写一条配置，用户看到的结果就是"这里多了一个"，那就说「添加」。没选「新增」：它和自动规则那句里的"新出现"撞词（`此来源新出现的 skill 自动新增`）。

**页签是名词，不是动作**：`模型` `Skills` `MCP`。第一版 MCP 页签叫「导入 MCP」是为了和二级页「导入 skill」错开，现在动作只在按钮上出现，页签就不用扛它。

**界面文案里不说「矩阵」，说「列表」。** 「矩阵」是我们对那张表的叫法（行 × 列），用户看到的是一个 skill 列表，每行后面几个开关。设置页那句是 `哪些 agent 出现在列表里`。

界面文案里**不出现「harness」**，一律 agent。代码标识符不动（`disabled_harnesses` 是已落盘的键、`matrix` 是组件名）。

### 来源的名字

来源的标签是**用户认得的名字**，不是路径：

| 来源 | 标签 |
|---|---|
| 通用仓库 | `通用仓库` |
| agent 的全局目录 | agent 名 |
| 项目 | 项目目录名 |
| 应用包内的目录（`/Applications/ego lite.app/…/ego-skills`） | **应用名** `ego lite`——从 `.app` 那一级取，去掉后缀 |
| 应用数据目录（`~/Library/Application Support/WeiboAP/…`） | **应用名** `WeiboAP`——`Application Support` 下一级 |
| 其余外部目录 | 从末尾往上找**第一个不是泛称的分量**：`~/.local/share/ego/skills` 叫 `ego` 不叫 `skills`。末尾一级几乎总是 `skills` 这类泛称，光取它三个来源会撞成一个名字 |

路径放 `title`。绝对路径**不出现在任何可见文案里**，除非用户正要据此做判断（删本体的确认弹窗）。

**矩阵「本体位置」列不给外部来源挂「外部」标签。** 用户要知道的是它叫什么、在哪，`ego lite` 这个名字已经说完了；「外部」是我们的分类词，对用户没有信息量。添加页的来源栏保留分类，那里是在挑来源、分类有用。

### 主视图：表格是主角，表头在第一屏的上四分之一

评审第 1 轮量过：待处理横幅 + 说明横幅 + 筛选行 + 自动同步框四层叠在表格上面，首行数据落在窗口高度 54% 处，56 个 skill 只露 8 行。现在内容区从上到下只有**两样**：

1. **工具行**（高 28，上下各 16）：筛选框（宽 ≥ 160，放大镜在框内，占位 `筛选`）+ 来源筛选片 + 右端 `+ skill` / `+ MCP` 按钮，与左边内容间隔 ≥ 32。
2. **表格**：表头紧跟工具行。1100×720 的窗口里表头 y ≤ 200。

其余三样各归其位：

- **自动同步规则并进工具行、紧跟被选中的来源片**（间距 8，与片成组）：**开关** + `自动 →` + 目标 agent 的 16px 图标（`title` 写名字）。有规则的来源片在计数后带一个 `自动` 小字（12，未选 `ink-mute`、选中 `canvas`）。不再有独占一行的带框块，也没有 `×`——第一版右端的 `×` 与提示条的 `×` 同款同位，一个关提示、一个删常驻规则。
- **勾选了 skill 时，选择操作条顶替工具行**，同一个 28px 槽位：`已选 2 个` + agent 片 + `取消选择`（文字链）。不另起一行。
- **待处理栏贴底、一行**：`position: sticky; bottom: 0`，白底、上边 1px `ink`，高 40，左右铺满内容区、内边距与页边对齐。内容：16px 圆圈感叹号 + 一句话 + 这一类自己的动作（紧凑按钮 24）+ `忽略`（文字链）+ 右端 `1 / 3` 与 `›` 图标按钮。它和顶栏待处理入口的分工：顶栏入口常驻（0 条也在），进完整列表；贴底这条只在有待处理时出现，就地处理当前这一条。
- **没有常驻说明条。** 「列表里只出现两种 skill：本体…软链…」是机制说明，放列头 `名称` 的 `title`。

**MCP 的表头与 Skills 同高**：全局位置下 scope 恒为 User，位置列头只写 agent 名一行（图标在上）；项目位置下才出现第二行 `LOCAL` / `PROJECT`。**MCP 没有「来源位置」列**——定义住在哪由本体环点表达（同一套圆点语言）。侧栏项只写项目名（`CardBox`），「位置」小标题下本来就都是项目，不加 `项目 ·` 前缀。

**表格列**：`名称` 吃掉剩余宽度；`本体位置` 120，紧挨 agent 列；agent 列各 84。第一版 `本体位置` 到第一个 agent 列之间一大段死白。MCP 的 `传输` 列只写真实的传输方式（`HTTP` `stdio`）；「某位置不支持」不是传输方式，在服务名后挂 `tag-weak`。

### 计数口径

一页上出现的数字口径必须一致。侧栏域名右侧＝该域有格可点的 skill 行数；列头 agent 名下＝该 agent 下能用的格数；添加页来源栏「未添加」列＝未添加数，列表头 `· N 个本体`＝本体总数，**两个数不共用位置**；自动同步行＝下一轮会新建的条数，**带单位写成 `N 条待建`**，裸的 `+N` 会被读成「还有 N 个 agent」。

### 列的存废

看「用户还有没有别的入口」，不看「文件存不存在」。Skill：目录不存在的 agent 照样成列（藏了用户就没别的地方能把目录建出来）。MCP：Claude Code 在一个项目里的第二个空位置藏起来（它仍是「添加」的显式目标，入口没丢）。

### 模型页

**一张表，一个 agent 一行**，与 Skills / MCP 同一种列表语言（线上画布评论里定的：卡片在只有一个 agent 时很丑、满宽卡内容撑不满）。页面上没有解释段落。

表头 `AGENT` ｜ `生效模型` ｜ `启用`。一行：

| 列 | 内容 |
|---|---|
| AGENT（232） | 24px 图标 + 名字（`wordmark` 档 20/700，不大写） |
| 生效模型（504） | 一个常驻的 hairline 框，里面是模型片（显示友好名 `Opus 4.6`，完整 id 进 `title`；带 `×`）；框尾端等宽 `103`（可选模型数，`title` 写全）+ 展开记号——放在下拉框尾自然读成「这里有 103 个可选」；整框可点，点开时框线转 `ink`，选择器浮层从框下方展开、**与框同宽左对齐** |
| 行尾 | `配置网关`（默认按钮，紧凑 24）+ **开关** |

**没有版本、路由状态、网关几家**这些内部事实。**`重启` 不常驻**：只有改了模型还没生效时，这一行下面挂一条行内待办条（`row-notice`）：`改动要重启 Codex 才生效` + `重启`（紧凑按钮）+ `稍后`（文字链）。第一版把它压成名字下面一句灰色 `mono`，和「103 个可用模型」这种只读事实同级，看不出要动手。

**选择器**：搜索框 + 列表，已选置顶，12px 方形复选框；整行可点，勾选当场写盘，没有保存 / 关闭按钮；底部一句 `已选 2 个模型`。

**网关配置页** `Codex 的网关`（页面名不大写）：二级页面，左右两栏画在同一页——左：已连的网关列表，一行 = 名字（`body`）+ 地址（`mono` `ink-faint`）+ `103 个可用模型`（`mono`）+ 铅笔、垃圾桶两个图标按钮；连不上时名字后挂 `tag` `连不上`。**行首不放状态点**——9px 实心点在列表里的意思是「已开启 · 软链」。列表上方右端 `+ 网关`（默认按钮）。右栏竖线从顶栏底线一直接到窗底，不悬空。右：表单（添加 / 改时出现）：`地址` `密钥` 两个输入 + `保存`（主动作，保存即拉取模型）+ 只读两行 `本机端口` `协议`。限制说明 `caption` 跟在列表下方 48px，**不钉窗底**。拉不到模型列表走二级页面自己的错误横幅。

**`重启`**：结束这个 agent 的常驻进程。会中断进行中的对话，**确认一道**——弹窗标题 `重启 Codex？`，正文说全后果，主动作只写 `重启`。没有禁用态。

### 添加页（skill 与 MCP 共用一套骨架）

二级页面，两列 + 底部一个块。两页**逐句对称**，只换名词：

| 位置 | skill | MCP |
|---|---|---|
| 页面名 | `添加 skill 到「全局」` | `添加 MCP 到「全局」` |
| 左栏列头 | `来源` / `未添加` | `来源` / `未添加` |
| 左栏一行 | 名字一行 + 范围第二行灰字（`全局` / `项目` / `外部`）+ 右端未添加数 | 同左，名字是位置名 `Claude Code · User` |
| 左栏底 | `+ 来源`（默认按钮） | — |
| 列表头 | `通用仓库 · 24 个` + `全选`（复选框） | `Claude Code · User · 5 个` + `全选` |
| 列表行 | 复选框 + 名字；已添加的灰掉、行尾 `已添加`；撞名的行尾 `tag` `同名` | 同左，另有一列 `传输` 灰字 |
| 底部块第一行 | `在以下 agent 开启`（agent 小写正文体，不 Condensed 大写） + agent 复选框（图标 + 名字）…… 右端 `添加 6 个`（**主动作**） | `写进以下位置` + 位置复选框 …… `添加 2 个` |
| 底部块第二行 | **开关** + `此来源以后新出现的 skill 也自动添加` | **开关** + `此位置以后新出现的服务也自动添加` |

- **页面只有两段**：上面挑什么，底部块说加到哪。规则开关和目标在同一个块里——规则的目标就是上一行勾的那些。它是开关不是复选框：当场生效的常驻规则，不随 `添加 N 个` 提交。
- **规则只管以后的**，拨开不批量添加现有的，所以不确认。
- 一个目标都没勾时 `添加 N 个` 禁用（`title` 说原因），不另写「至少选一个」。
- 没有 `取消`（`←` 或 Esc 回）；没有绝对路径；右上不重复写「N 个与已有同名」——行尾的 `同名` 标签已经说了。
- 列表行没有分隔线（两页一致）；左栏宽 268（skill）/ 300（MCP，位置名长）。
- 位置名全应用一个写法：`Claude Code · User`，不带 `MCPs` 后缀。

### 设置页

二级页面。**复选框列表，不是选择片**：第一版 5 个实心黑胶囊是全产品最重的视觉质量，承载的却是最不重要的设置；41 个 agent 也本来就适合列表。

`哪些 agent 出现在列表里`（区域标签，agent 小写正文体）下面三列排开，一行 = 12px 复选框 + 16px 图标 + 名字（`body`），行高 36；默认只列已安装的 9 个，下面 `显示未安装的 32 个`（文字链）。勾选当场生效。再往下 48px：`关于`——`版本 0.1.0`（`mono`）+ `检查更新`（文字链）。不展示路径。

### 托盘面板

与模型页同一行的缩小版：`24px 图标 + Codex + 开关`，没有状态句。`needsCodexRestart` 时开关那行下面挂行内待办条 `改动要重启才生效` + `重启`，确认在面板里当场展开。菜单三项 `打开 Sophia` `设置` `退出`，悬停 `surface` 底。

## Do's and Don'ts

### Do

- 一次操作只汇总成一句提示条
- 禁用的按钮同时给 `title` 说原因
- 需要用户拿主意的事进待处理栏，各带自己的动作
- 数字带单位
- 用反色表示"现在开着"（选择片）；布尔状态用开关
- 图标按钮带 `title`

### Don't

- 不涂红。破坏性靠信息承担分量
- 不在按钮上写宾语（`重启 Codex` → `重启`）
- 不给词表之外的动作发明图标
- 不在列头放灯。看不懂的记号比没有记号更糟
- 不把选择操作条退化成两个总按钮，「针对某个 agent」这一维不能丢
- 不显示绝对路径，除非用户正要据此做判断
- 不写「操作失败」「请重试」「没有需要建立的链接」
- 不给「拉取模型」「改选模型」单独的按钮——保存即拉取，整块区域可点
- 不给浮层配「保存」「关闭」——点了就生效，点外面就关
- 不让命中区跟着视觉尺寸缩——12px 的记号，24px 的目标
- 不说「同步」（MCP 页）——它只新增、从不覆盖也不删除
- 不在文案里说「矩阵」「导入」「引入」「harness」
