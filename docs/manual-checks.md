# 手动验证清单（每次改 App 层后跑）

启动：`make dev`

## Skills tab
- [ ] 侧栏为「全部」「全局」、各项目（含 WeiboAP 各 agent 目录，如 `WeiboAP · agent_1788`）+ 底部「设置」；没有独立的视图切换
- [ ] 「全局」页：通用仓库、Codex、WeiboAP 三个自有本体位置的全部 skill 都成行，且默认已引入（无需手动引入即可同步）
- [ ] `weibo_assistant · Claude Code`、`weibo_mini_program · Claude Code` 这类项目页：只显示已链接的行（分别 43 / 3 条），不把同一本体位置下的其他 skill 带进来
- [ ] 「引入来源…」弹层：可整个来源一次引入，也可只勾具体几个 skill；引入后表格里新增的行以 ○（未同步）出现，并计入顶部"待同步"计数
- [ ] 已引入来源标签行：每个标签可「编辑」（重开弹层调整名单）、「移除」（从该域的同步集里删除这个来源）
- [ ] 行首勾选取消后该行整行淡显（`tr.disabled`），不再计入待同步计数，也不会被"同步"创建
- [ ] "同步"只创建已引入且勾选（enabled）的行在缺失（○）状态下的项，不动未引入/未勾选的行
- [ ] "清理坏链"需二次确认，只删链接本身
- [ ] 「全部」页：把每个域的坏链、待同步计数聚合展示，"同步"按钮一键处理全局与所有项目
- [ ] 表头（skill / 本体位置 / 各目标列）可点击排序，再点切换升降序
- [ ] `weibo_assistant · Claude Code` 目标列头显示"整目录链接"徽标——**点"拆成逐项链接"前先在 WeiboAP 里确认它能否识别逐项软链**，确认后再执行拆分
- [ ] 执行结果框显示本次每条 outcome，6 秒后自动消失（也可手动关闭）
- [ ] 设置面板分三节：Harness（勾选增减）、项目（增删）、本体位置（增删手动来源）；关闭弹层后自动重扫

## 自定义同步 tab
- [ ] 新建、选源、切换整目录/指定子项、添加/移除目标、预览、执行、二次预览全"已链接"
- [ ] 同名真实文件显示"冲突"，执行后文件原样
- [ ] 删除源子项后预览出现"坏链"，清理需二次确认
- [ ] 退出重开记录仍在（`~/Library/Application Support/SymSync/rules.json`）
