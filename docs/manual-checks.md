# 手动验证清单（每次改 App 层后跑）

启动：`make dev`

## Skills 页
- [ ] 侧栏为「全部」「全局」、各项目（含 WeiboAP 各 agent 目录，如 `WeiboAP · agent_1788`）+ 底部「添加项目…」「设置」；没有 tab 导航，侧栏不会折叠
- [ ] 「添加项目…」选一个目录后它出现在侧栏；手动添加的项目条目末尾有 ×（title「移除项目」），点击后该项目从侧栏消失；自动发现的项目与 WeiboAP agent 域没有 ×；移除当前选中的项目后回落到「全部」
- [ ] 「全局」页：通用仓库、Codex、WeiboAP 自有本体位置的全部 skill 成行；WeiboAP custom 目录列显示 ●（本体在此）
- [ ] 项目页：自有 .agents/skills 全部成行；从别处链接进来的 skill 只显示被链接的那些
- [ ] 页面工具栏常驻「引入…」「清理坏链（K）」「刷新」；K = 渲染中各域坏链数，为 0 时「清理坏链」禁用
- [ ] 在「全部」页「引入…」禁用，title「请先在侧栏选一个域」；选中某个域后可点开该域的引入弹层
- [ ] 筛选行：搜索框（placeholder「筛选 skill」）大小写不敏感地按 skill 名过滤；每个域标题下一排筛选片 `label · n`，点击高亮可多选，无高亮 = 不筛；筛选只影响显示，不清空选择
- [ ] 行首勾选默认全空；表头全选框只勾/不勾当前可见行，部分选中时呈半选
- [ ] 先点筛选片「通用仓库」再点表头全选，正好选出该本体位置的行
- [ ] 按住 Shift 点行首复选框，把上次点击的行到本行之间（按当前显示顺序）的可见行设成与本次相同的状态
- [ ] 选择操作条在选中且可见的行 ≥ 1 时出现在页面工具栏下方：「已选 N 个 skill」「补齐缺失（M 处）」「清除软链（P 个）」「取消选择」；点「取消选择」后操作条消失
- [ ] 切换侧栏、改筛选都不清空选择；操作只作用于选中且可见的行
- [ ] 每行末尾有「补齐」「清除软链」两个按钮，始终显示；无缺失格时「补齐」禁用（title「没有缺失的链接」）
- [ ] 本体在本域的行（●）「清除软链」照样可点，只清它在其他 harness 下的链接；行内没有可清除的格时才禁用，title「没有可清除的软链接」
- [ ] 点行末「补齐」给该行所有缺失 harness 建链；点「清除软链」删掉它在本域所有 harness 下的链接
- [ ] 点 ○ 格当场建链；点 ✓ 格（目标非整目录链接）走清除确认条；点 ● / – / ✗ / → / ⚠ 只出提示条说明原因
- [ ] 「补齐缺失（M 处）」：M = 选中且可见的行的缺失格数（按路径去重），点击一次补齐
- [ ] 「清除软链（P 个）」：P = 这些行里有可清除格的行数（含本体在本域的行）；无可清除格时禁用，title「选中的行里没有可清除的软链接」
- [ ] 清链动作统一出确认条「将删除 N 条软链接，只删链接本身，不删任何真实文件。本体在本域的 skill 只清链接，本体目录不动。」，确认后链接消失、本体目录不动；与「清理坏链」的确认条互斥
- [ ] 清链结果框在逐条结果下面多一段按 skill 的说明：本体不在本域「「X」的软链已清除，已从列表移除。」；本体在本域「「X」的软链已清除；本体仍在 <路径>，…删掉本体后它才会从列表消失。」；只清了部分格「…它在其他 harness 下的链接还在。」；有失败「「X」有 n 条软链未能删除，见上方。」
- [ ] 没有可做的动作时出暂态提示条（「没有需要建立的链接」/「没有可清除的软链接」），6 秒后消失
- [ ] 「引入…」弹层三栏：左栏本体位置显示「未引入 n 个」；中栏上段是本域没有的 skill（含「全部」开关），下段灰字列出「已引入」的；右栏是本域各 harness 复选，默认全勾，整目录链接的禁用并提示「整目录链接，先拆成逐项链接」
- [ ] 引入按钮在 skill 或 harness 为空时禁用；所选组合全部已链接时提示「所选 skill 在所选 harness 下都已链接」且弹层不关
- [ ] 弹层左栏「手动」标签的本体位置末尾有「移除」，点击后该条消失；若它正被选中则改选列表第一项
- [ ] 坏链表与「清理坏链」不变；「全部」页聚合各域计数，动作一键处理全局与所有项目
- [ ] 整目录链接目标：列头显示"整目录链接"，可拆成逐项链接；拆分前该列不计入清除软链
- [ ] **点"拆成逐项链接"前先在 WeiboAP 里确认它能否识别逐项软链**，确认后再执行拆分
- [ ] 表头（skill / 本体位置 / 各目标列）可点击排序，再点切换升降序
- [ ] 执行结果框显示本次每条 outcome，6 秒后自动消失（带 skill 说明时 15 秒；也可手动关闭）
- [ ] 设置弹层只有 Harness 一节（勾选增减 harness）；关闭弹层后自动重扫

## 平台
- [ ] macOS：以上全部
- [ ] Windows：junction 建链、`readlink` 判定、删除（待有 Windows 机器时验证）
